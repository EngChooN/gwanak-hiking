산풍경 · 2026-11-02 · 코드 수정 완료 / 스크립트·생성·렌더 검증 미실행

**연주대 좌표의 원시 DSM 보간값은 약 605.6m다. 630m라는 가정은 현재 파일과 맞지 않는다. 정상 632m는 별도 경로 보정 기준으로 적용했다. 실제 입구 표고 ±10m 충족 여부는 자료가 없어 미검증이다.**

Overpass 분할·예비 서버·cityMissing, 재질·HDRI 코드는 수정하지 않았다. src/, 원본 TIFF, 기존 generated/ 파일도 수정하지 않았다. 현재 generated/ 값은 이전 실행 결과이며 새 코드는 대표 실행 후 반영된다. 저장소에 .git이 없어 git diff는 사용할 수 없었고, 해당 블록만 패치하고 파일을 다시 읽어 정적으로 확인했다.

## 가정과 한계

- 이번 지시의 정상 목표 632m를 경로 끝점의 보정 기준으로 우선 적용했다. 기존 원경 observation.ground=629는 이번 수정 범위에 포함하지 않았다.
- 실제 입구 기준표고가 없으므로 중심 DSM 약 49.6m를 잠정 사용했다. 이것을 실제 입구 표고로 확정하거나 ±10m 충족이라고 보고하지 않는다. 실제 기준 확보 후 alignRoute의 startHeight로 전달할 수 있다.
- 보정식은 `중심DSM + (1−t)×출발잔차 + t×정상잔차`이며 t는 수평 누적거리/총수평거리다. 지점 인덱스·GPX 고도 급변에 따라 보정량이 흔들리지 않는다. 중간 구간의 실제 표고가 검증된 것은 아니다.
- 경로만 보정하고 근경·원경 DSM 격자는 보존했다. 끝점에서는 경로가 원시 지형보다 약 26.4m 높다. 기존 cutHeight의 좁은 어깨에서 급한 법면이 생길 수 있으므로 **실사 지형·접지 검증 완료 상태가 아니다.** 렌더 확인 후 필요하면 신뢰할 수 있는 고해상도 DEM과 정상 지형 보완이 필요하다.
- 생성 검증은 추가했지만 실행하지 않았다. 화면 변경·촬영도 하지 않았다.

## 스크립트를 실행하지 않은 원시값 점검 증거

프로젝트 스크립트 대신 설치된 libtiff 명령으로 원본 메타데이터를 읽고, 2×2 픽셀만 임시 TIFF로 추출해 od로 읽었다. 원본은 그대로 두었다.

| 지점 | 0기준 보간 좌표(u,v) | 좌상·우상·좌하·우하 픽셀(m, 출력 반올림) | 손계산 보간 근삿값 |
|---|---|---|---|
| 연주대 | 3470.886, 1997.3376 | 595.4821, 603.6180, 602.7988, 612.3343 | 약 605.58m |
| 입구 | 3407.5008, 1915.092 | 48.68693, 51.16195, 43.04480, 50.69194 | 약 49.65m |

tiffcrop의 좌표는 1기준이며, 압축 해제한 임시 파일의 TileOffsets=8, TileWidth=1024를 tiffdump로 확인했다. od는 바이트 8·4104에서 각 행 두 float32를 읽었다.

임시 증거 파일: `/private/tmp/gwanak-summit-dem-20261102.tif`, `/private/tmp/gwanak-entrance-dem-20261102.tif`.

## 대표 확인 필요

사용자 지시로 아래 명령은 실행하지 않았다. 프로젝트 루트 `/Users/pc-2311001/gwanak-hiking`에서 순서대로 실행한다.

```sh
node assets/realistic/tools/prepare.mjs
node assets/realistic/tools/verify.mjs
```

- prepare는 생성 파일을 갱신하며 캐시에 없는 자료를 외부에서 받는다. 기존 Overpass 재시도·누락 기록 방식은 그대로다.
- 생성 후 `generated/elevation-audit.json`에서 정상 rawDem 약 605.6m / aligned 632m / correction 약 +26.4m와 입구 aligned 약 49.6m를 대조한다.
- 실제 입구 기준 표고를 확보해 약 49.6m와 ±10m인지 비교한다. 이 대조 전에는 출발점 목표 충족을 확정할 수 없다.
- 정상·입구·중간 경로의 법면과 발 접지를 실제 화면에서 확인한다. 격자 원시값은 바꾸지 않았으므로 정상 부근 지형 품질 확인이 특히 필요하다.
- 삭제·배포·push는 수행하지 않았으며 이 작업에 필요한 대기 명령도 없다.
