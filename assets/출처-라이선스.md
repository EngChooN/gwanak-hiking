# 관악산 실사풍 자산 출처·라이선스

확인일 2026-11-02. **이번에는 웹 문서와 이용 조건만 확인했다. 외부 바이너리 자료는 확보하지 못했다.** 소스·후보 목록과 실제 포함 파일을 구분한다. `realistic/status.json`의 releaseApproved는 false다.

## 실제 포함 파일

- 기존 GLB 9개 및 기존 캡처: 앞선 대화에서 자체 제작한 합성 기술 시범 자산. 외부 실측·스캔이 아니다. 이전 README·검증 기록을 보존했다.
- `realistic/geo.js`, `load-landscape.js`, `tools/prepare.mjs`, `tools/verify.mjs`, 설정·상태·인계 문서: 이번에 작성한 프로젝트 소스. 외부 모델·텍스처를 포함하지 않는다.
- GPX CSV는 프로젝트 제공 자료를 읽는 입력이다. 원본은 `data/GPX추출-계곡코스-상행.csv`; 원본 제공·이용 조건 기록은 `data/자료-출처-이용조건-기록표.md`를 따른다. 이번에 원본 라이선스를 새로 확정하거나 재라이선스하지 않았다.

## Copernicus GLO-30 — 미확보, 준비 코드의 입력

- 제공: Copernicus / DLR / Airbus, AWS 공개 버킷 `copernicus-dem-30m`.
- [AWS 데이터 설명·접근 방법](https://registry.opendata.aws/copernicus-dem/).
- [COP-DEM-GLO-30-F 이용 조건 원문](https://docs.sentinel-hub.com/api/latest/static/files/data/dem/resources/license/License-COPDEM-30.pdf).
- 대상 타일: `Copernicus_DSM_COG_10_N37_00_E126_00_DEM` 및 `Copernicus_DSM_COG_10_N37_00_E127_00_DEM`.
- 무상 이용·수정·배포가 가능한 별도 Copernicus 라이선스다. **CC0·CC BY로 표기하지 않는다.** 원자료와 파생물의 출처 문구가 다르므로 원문 제6조(a)/(b)에 맞는 문구를 최종 배포물에 넣는다. 이번에는 배포물을 만들지 않았다.
- 권리자: DLR e.V.(2010–2014), Airbus Defence and Space GmbH(2014–2018); 유럽연합·ESA의 COPERNICUS 제공. 파생 격자는 보간·절삭 내용을 명시한다.
- Copernicus 운영·제공 기관은 이 자료의 사용에 대한 책임을 지지 않는다. 공식 기관이 이 체험을 승인하거나 보증한 것으로 표시하지 않는다. 후속 이용자에게도 이용 의무를 전달한다.
- AWS 설명상 2021 release의 DSM이다. 나무·건물 표면을 포함하므로 국토지리정보원의 맨땅 고도와 동일하다고 가정하지 않는다.
- 다운로드 시도는 `curl` 종료 코드 6(DNS 실패). 접근일을 실제 데이터 확보일로 기록하지 않았다. 준비 코드 성공 시 URL·바이트·SHA-256을 `generated/sources.json`에 기록한다.

## Poly Haven — 모두 미확보 후보, CC0

## ambientCG — 대안 조사, 파일 미포함

[ambientCG 이용 조건](https://docs.ambientcg.com/license/)은 자산 파일에 CC0 1.0을 적용한다. [Rock030](https://ambientcg.com/view?id=Rock030)을 확인했으나 절벽용 절차적 바위이며 화강암 스캔 확인본이 아니다. 이번 준비 목록에 넣거나 다운로드하지 않았다.

## OpenStreetMap / Overpass — 미확보, ODbL

- 원자료: © OpenStreetMap contributors.
- [출처·이용 조건](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- 공개 Overpass의 건물 윤곽·height·building:levels·water를 서울 서/동·안양·과천 네 구역으로 나눠 요청하는 코드를 작성했다. 실제 응답은 받지 않았다.
- OSM 원자료 및 수정 데이터베이스는 별도 JSON으로 보존하고 ODbL 표기를 유지한다. 자산 전체를 CC0로 일괄 표시하지 않는다. 화면·캡처에 OSM 출처를 명확하게 표시하고 저작권 페이지로 연결한다.
- 파생 데이터베이스를 공개 사용·배포하는 경우 원본 제공·공유 의무를 준수한다. 압출·이미지 등 제작 결과물과 데이터베이스 의무는 구분해 최종 배포 시 확인한다.
- 층수×3m와 미상 9m는 자체 가정으로 heightSource에 기록한다. 빈 데이터를 임의 건물로 채우지 않는다.

## 코드 의존성

서울 원경 방위·거리·고도·대기 목표는 프로젝트의 `data/서울원경-기준표.md`(산리서치·산기획 보충), `design/실사-룩-기준.md`(산디자인), 산기획의 이번 확정 지시를 사용한다. 이 문서들의 참고 사진 이미지는 자산·검토 화면에 복사하지 않았다. 다리·도시·산의 주석 기준점은 원본 스캔 모델이 아니다. 새 캡처 이미지는 아직 없다.

- Three.js: 프로젝트 기존 의존성(MIT). 원본 LICENSE를 유지한다.
- geotiff 2.1.3(MIT), sharp 0.33.5(Apache-2.0): 별도 도구 package.json에 고정했으나 설치하지 않았다. 설치 시 전이 의존성과 libvips 등 바이너리 구성요소의 고지 파일을 보존한다.
- 이번에 외부 인체 모델·CC BY 모델을 추가하지 않았으므로 작가나 다운로드 URL을 가정해 적지 않았다. 추후 CC BY 사용 시 원본 제목·작가·버전·원문 링크·변경 내용을 자산별로 추가한다.
