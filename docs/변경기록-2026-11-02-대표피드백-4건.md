## 구현

- src/view.js: 이동과 독립인 시선, 명시적 F / 정면 보기만 0.4초 복귀. 사용자가 회전하면 복귀 중단.
- src/main.js: 이동·자동 걷기·일시정지·지도에서 시점을 강제 전환하지 않는다. 아바타 경로 heading과 카메라 yaw를 분리. 1·3인칭 모두 이동, 마지막 view 저장·복구.
- src/rendering.js: 3인칭 5개 충돌 레이, ACES/sRGB, Poly Haven CC0 1K 환경광, 추적 태양 그림자, 지수 안개, PC 높음 SSAO, 모바일 후처리 우회. 4초 FPS 창에서 품질 자동 하향. 느린 프레임도 FPS 측정에 포함한다.
- src/route.js: 계단·데크 계단 1.2걸음/초, 공칭 18cm/30cm 보폭, 0.4198285364m/s. 비계단만 0.8152328598로 보정. 전체 150분.
- src/terrain.js: 그림자 수신·투사. 계단 위로 지면 리본이 겹치지 않도록 하고 지형·길 면 방향을 상향으로 교정.
- index.html·src/input.js·src/style.css: 정면 보기 F 버튼과 안내, 태블릿 세로·좁은 화면 배치 조정.
- assets/ 파일은 수정하지 않았다. 실사 자산 제작·적용 및 현장 지리 승인과 구분한다.

## 검증

Node v22.17.1 PATH로 npm test(17개), npm run build, npm run simulate, BASE_URL=http://127.0.0.1:4173 npm run capture, npm run report.

브라우저 검증은 dist/index.html SHA-256을 기록하며 보고서가 현재 빌드와 비교한다. 10종 화면의 겹침·잘림·가로 스크롤, 실제 입력 시선·3인칭·F·모바일 조작·이어하기, 1·3인칭 계단 0.35~0.5m/s 및 1.2걸음/초를 검사한다. 결과 파일에 통과 여부·검사 시각·측정값·예외를 기록한다.

## 가정

GPX 평활 좌표·고도는 유지. 계단 18/30cm는 속도 모델이며 모든 합성 디딤폭을 30cm로 바꾼 것이 아니다. 비계단 경사 입력은 기존 ±50% 제한. HDRI는 환경광 전용이며 관악산 실경이 아니다.

## 대표 확인 필요

보급형 모바일 실기기 30fps와 지속 발열 구간, 실사 자산 적용 후 성능, 현장 DEM·고도 편차·계단/노면/폭·체크포인트와 경험자 확인. Mac 모바일 에뮬레이션 수치만으로 실기기 성능을 승인하지 않는다.

삭제·배포·push·업로드 없음. 대기 중인 위험 명령 없음. 요청된 로컬 실행·빌드·검증은 수행.
