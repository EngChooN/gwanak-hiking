- 색·글꼴: `src/hud-notebook.css` 1절 토큰(`--paper` `--stamp` `--ink` `--edge` `--rule` `--nb-font`)을 그대로 불러 씁니다. 새 색·글꼴·로고·캐릭터 없음. 동동이와 그래픽은 게임 화면 그대로(오버레이에 그리지 않음).
- 인스타 가림 영역: 위 220 · 아래 420 · 오른쪽 120 → 글자는 x 0~960, y 220~1500 안. 자막 띠는 y 1220~1480(아래 안전선 바로 위), 안내 띠는 y 240부터. 캡처에서 모든 상자가 이 안에 있음을 숫자로 확인했습니다.

## 4. 오버레이 사용법 (연개발용)
파일: `scripts/promo/reels-overlay.html` (1080×1920 고정, 장면 표가 안에 들어 있음)

### 4-1. 주소로 넘기기
```
file:///…/scripts/promo/reels-overlay.html?scene=3
file:///…/scripts/promo/reels-overlay.html?scene=6&hl=evening
file:///…/scripts/promo/reels-overlay.html?scene=0
file:///…/scripts/promo/reels-overlay.html?mode=ending&url=https://…
file:///…/scripts/promo/reels-overlay.html?mode=cover&bg=<프레임 이미지 주소>
```
| 값 | 뜻 |
|---|---|
| `scene` | 장면 번호 0~9. 자막·태그·시간대·안내 띠(0번)가 표대로 나옴. 9번이면 엔딩 |
| `mode` | `caption`(기본, 배경 투명) · `ending` · `cover`. 안 주면 caption(9번은 ending) |
| `cap` | 자막을 직접 정함. 줄바꿈은 `\|` (예: `cap=첫줄\|둘째줄`) |
| `tag` | 자막 왼쪽 위 작은 도장 글자(기본은 표 값, 빈 값이면 없앰) |
| `hl` | 장면 6에서 켜 둘 칩: `morning` `lunch` `evening` `afterparty` |
| `time` | `day` `dusk` `night`. 안 주면 장면 표 값(엔딩·표지는 day) |
| `notice` | `1`이면 안내 띠(가상 흡연장…)를 위에 붙임, `0`이면 뺌 |
| `url` | 엔딩 접속 주소 |
| `bg` | 표지 배경 이미지 |
| `guide` | `1`이면 안전 영역 점선을 그림(확인용, 영상에는 쓰지 말 것) |

### 4-2. 스크립트 안에서 바로 부르기
```js
await page.goto('file:///…/reels-overlay.html');
const {SCENES} = await page.evaluate(()=>window.reelsOverlay.SCENES); // 길이(sec)·시간대·자막 표
await page.evaluate(o=>window.reelsOverlay.show(o), {scene:6, hl:'lunch'});
await page.waitForSelector('body[data-ready="1"]');
await page.screenshot({path:'cap6-lunch.png', omitBackground:true}); // 투명 PNG
```
- `show()`는 글꼴이 준비되면 끝나고 `body[data-ready="1"]`을 켭니다.
- caption 모드는 `omitBackground:true`로 찍으면 **투명 PNG**가 되어, 편집 캔버스에서 게임 영상 위에 `drawImage`로 얹으면 됩니다. 장면마다 한 장(장면 6은 칩 4장)이면 됩니다.
- ending·cover는 불투명 1080×1920 한 장입니다. 엔딩은 `scene=9`의 4.5초 동안 그 한 장을 보여 주면 됩니다.
- 장면 길이 합계는 `SCENES.reduce((a,s)=>a+s.sec,0)` = 41.5초입니다.
- 서버 없이 `file://`로 열립니다. 상대 경로(`../../src/hud-notebook.css`)로 토큰을 읽으므로 파일 위치를 옮기면 안 됩니다.
