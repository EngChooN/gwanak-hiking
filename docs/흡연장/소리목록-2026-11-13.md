## 연개발이 연결할 때 참고 (추천값, 귀로 확인 전)
- 크기를 같은 피크(-3dB)로 맞췄을 뿐 **귀로 들은 크기는 다릅니다.** 평균 크기(RMS) 차이가 큽니다: lighter-open은 아주 짧은 딸깍이라 -31dB, vending-button·inhale은 큰 편입니다. 재생 gain은 대략 이렇게 시작해 귀로 조정하세요(추정): lighter-open 1.0, lighter-strike 0.8, cig-burn 0.15(반복, 들이마신 정도에 비례), inhale 0.35, exhale-* 0.5, vending-button 0.5, can-drop 0.8, can-open 0.8.
- 날숨 길이는 기존 `EXHALE_LEN`(light 0.8·sweet 1.7·deep 2.3)과 같습니다. cough 날숨은 이번 범위가 아닙니다.
- 불이 붙는 순간(`flame`)에 lighter-strike를, 캔이 나오는 순간에 can-drop을 맞춥니다. 순서 제안: vending-button → (0.3초) → can-drop → can-open.
- cig-burn은 `loop=true`로 틀고 안 들이마시면 멈춥니다. 0.74초짜리라 반복 주기가 들리면 gain을 낮추거나 `playbackRate`를 조금 흔들어 보세요.
- 파일을 못 불러오면 기존 합성음으로 대체하세요(기획서 완료 기준 1).

## 확인한 것 / 확인 못 한 것
- 확인함: 피크·길이·모노·44.1k(ffmpeg), 앞쪽 무음 없음, 크기 흐름(수치와 스펙트럼 그림), 각 원본의 CC0 표기.
- **확인 못 함:** 사람 귀로 듣는 느낌(이 환경에서 소리를 들을 수 없음). 특히 ① lighter-strike는 성냥 녹음이라 라이터와 약간 다를 수 있음 ② 날숨은 '한숨' 녹음이라 숨이 조금 깊게 들릴 수 있음 ③ vending-button은 휴대폰 키+계산대 삑이라 진짜 자판기와 다를 수 있음 ④ cig-burn 반복 이음매. 이 네 가지를 앱에서 먼저 들어 보고, 어색하면 구간(`trim-lounge-sfx.mjs`의 ss·t)만 바꿔 다시 돌립니다.
- 담배를 멋있게 들리게 하는 처리(울림·저음 키우기·반복 강조)는 넣지 않았습니다.
