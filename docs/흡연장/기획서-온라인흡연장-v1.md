# 온라인 흡연장 — 기획서 v1 (연기획, 2026-11-08)

온라인 시리즈 두 번째 작품. **담배를 끊었거나 피우지 않는 사람이** 메타버스 옥상 흡연장에 모여 **채팅으로 수다를 떨며 가상 담배를 피우는** 웹 3D 체험입니다. 몸에 해로운 것은 하나도 없고, "흡연장 수다"라는 분위기만 가져옵니다.

## 1. 브랜드 기준 (최우선 — 바꾸면 대표 확인)
- 캐릭터 = 온라인 등산 **동동이 그대로**: 키 1.0m·2.1등신·큰 머리·큰 눈·볼터치·벙거지, 동작(통통 걷기·뛰기)도 같은 코드. `src/toon/link-hiker.js`, `src/realistic-hiker.js` 등은 **복사본을 고치지 않습니다**.
- 바꾸는 것은 **옷만**(`src/lounge/outfit.js`): 대표 지시(11-08)로 등산복 대신 **회사원 옷** — 셔츠·넥타이(기본)·정장 재킷·카디건·롱패딩. 벙거지·배낭·쌍안경은 숨기고 맨손.
- 그래픽 = 온라인 등산 카툰 파이프라인 그대로(`src/toon/**`): 3단 툰 명암, 얇은 외곽선, 낮 「야생의 숨결」 / 노을·밤 「너의 이름은」 하늘·도심. 새 물건도 `toon.materialFactory`·`toonify`·`concept-kit`(단색 + 툰 재질, 텍스처 없음)로 만듭니다.
- HUD = 온라인 등산 「등산 수첩」 종이 톤(크라프트 종이 카드·빨간 도장·책갈피 탭, 낮/노을/밤 종이색 토큰)을 같은 계열로.
- 런타임 외부 접속 없음(정적 사이트). 소리는 코드 합성.

## 2. 체험 범위 (이번 출시본)
| 구분 | 내용 |
|---|---|
| 첫 화면(로비) | 「온라인 흡연장」 제목 카드, 닉네임, 나는 [금연 중(시작일·하루 갑 수) / 비흡연자], 옷 고르기 4종, 입장 |
| 장소 | 서울 도심 빌딩 **옥상 흡연장**: 지붕 덮인 흡연 부스, 스탠드 재떨이 3, 벤치 2, 자판기, 화분, 난간 너머 도심 원경, 밤에는 가로등·창 불빛 |
| 이동 | PC: WASD·방향키, Shift 뛰기, 드래그 시점, 휠 거리 / 휴대폰: 손가락 댄 자리에 생기는 조이스틱, 오른쪽 드래그 시점, 핀치 |
| 흡연 | 🚬 한 대 꺼내기 → 🔥 라이터 → 들이마시기(손을 입으로, 불씨 밝아짐)·내뿜기(입에서 연기 뭉게) 반복, 담배가 점점 짧아짐, 재 털기, 다 피우면 꽁초를 재떨이에(재떨이 근처면 「매너 도장」) |
| 채팅 | 아래 채팅창 + 머리 위 말풍선. 이모트(👋 인사·😮‍💨 한숨·🙆 기지개) |
| 함께 있는 사람 | 멀티 전까지 **NPC 동동이 4명**(옷 다름)이 돌아다니고·피우고·서로 떠들고·내 말에 반응 |
| 수첩 카드 | 금연 n일째·아낀 돈·오늘 핀 가상 담배 개비. 비흡연자는 "오늘의 수다" 기록 |
| 설정 | 시간(지금·낮·노을·밤), 소리 켜기/끄기, 옷 바꾸기, 내 정보 고치기 |
| 저장 | 브라우저 localStorage(서버 없음) |

### 이번에 하지 않는 것
- 실제 멀티(다른 사람과 실시간 접속) — 대표 지시로 미룸. 구조만 이벤트로 나눠 둡니다.
- 배포·커밋·push.

## 3. 완성 기준
1. 동동이 실루엣·비율·얼굴이 온라인 등산과 같다(나란히 캡처로 대조).
2. 낮·노을·밤 세 시간대가 온라인 등산과 같은 하늘·명암 계열이다.
3. 로비 → 입장 → 걷기 → 한 대 피우기(불 붙이기·들이마시기·내뿜기·꽁초 버리기) → 채팅 → NPC 반응이 막힘없이 된다.
4. 모든 기능이 HUD 버튼으로도 된다(휴대폰에 키보드 없음). 버튼은 44px 이상, 안전 영역 안.
5. 휴대폰 세로 390×844, 가로 844×390, PC 1920×1080에서 HUD가 겹치지 않는다.
6. 콘솔 오류 0, PC 60fps 근처.
7. 단위 테스트 통과(`npm test`), 빌드 성공(`npm run build`).
