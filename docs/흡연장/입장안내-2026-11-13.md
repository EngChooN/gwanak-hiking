# 흡연장 입장 안내 화면 + 일어나기 단추 (디자인·문구 확정)

작성: 연디자인 · 2026-11-13 · 연개발이 바로 쓰는 문서입니다. (법률 검토 아님, 일반적인 성인 확인 안내 수준)

## 맞춘 기준
- 온라인 등산 수첩 종이 톤: `src/lounge/hud.css`의 토큰(`--paper --paper2 --ink --ink2 --edge --rule --stamp --stamp-d --accent`)과 `.lg-card`·`.lg-btn`·`.lg-sheet`를 **그대로 재사용**. 새 색·새 그림 없음. 밤 모드 값도 토큰이 알아서 바뀜.
- 첫 화면 틀은 `server-pick.css`의 입장 전 화면(종이 전체 배경 `--paper2`, 왼쪽 빨간 책갈피 줄 `border-left:6px solid var(--stamp)`)과 같은 모양.
- 담배 그림·연기 그림·멋진 말투 없음. 이모지는 ⚠️ 대신 도장(빨간 테두리 글자)만 씀.

## 1. 입장 안내 화면 (한 장)

### 문구 (확정)
| 자리 | 문구 |
|---|---|
| 도장(오른쪽 위) | `19+` |
| 제목 h1 | `들어가기 전에` |
| 작은 글 .sub | `온라인 흡연장은 잠깐 보고 가는 가상 체험이에요.` |
| 공지 1 | `이곳은 흡연을 권하지 않는 가상 체험이에요. 실제 담배나 제품 광고가 아니에요.` |
| 공지 2 | `만 19세 미만은 이용할 수 없어요.` |
| 공지 3 | `흡연은 건강에 해로워요. 금연 상담: 1544-9030` (번호는 `tel:1544-9030` 링크) |
| 입력 라벨 | `태어난 해` |
| 입력 안내(placeholder) | `예: 1995` |
| 입력 보조글 | `숫자 4자리. 이 기기에만 저장되고 서버로 보내지 않아요.` |
| 체크 | `위 내용을 확인했어요` |
| 단추 | `들어가기` |
| 입력 오류(칸 아래, 빨강) | `태어난 해를 숫자 4자리로 적어 주세요.` (1900~올해 밖이면 같은 문구) |

### 들어가기 단추 상태
- 연도 4자리가 맞고 + 체크가 켜졌을 때만 활성. 아니면 `disabled`(기존 `.lg-btn[disabled]`: 흐림, 눌림 없음).
- 누르면: 계산 → 성인이면 저장 후 이름 정하기(기존 로비)로, 미성년이면 아래 막힘 화면.

### 나이 계산 (연 나이 기준)
`올해 - 출생연도 >= 19` 이면 입장. 올해는 `new Date().getFullYear()` (2026년이면 2007년생까지 입장).
생일·월은 묻지 않음(청소년보호법의 연 나이 기준과 같게 보수적으로 단순화).

### 미성년일 때 (입장 막힘 화면)
같은 카드의 안쪽 내용만 바뀜(입력칸·체크·단추 숨김).
| 자리 | 문구 |
|---|---|
| 제목 | `아직 들어갈 수 없어요` |
| 본문 | `온라인 흡연장은 만 19세 이상만 이용할 수 있어요.` |
| 보조 | `흡연이나 금연이 고민되면 금연 상담 1544-9030에 전화해 보세요.` |
| 단추(1개) | `처음으로` → 연도 입력 화면으로 되돌아감(저장 안 함). 흡연장 밖(허브)으로 나가는 링크가 있으면 `다른 체험 보러 가기`를 보조 단추로 추가(없으면 생략). |
- 미성년 판정 연도는 **저장하지 않음** → 다시 열면 다시 묻기. (연도를 바꿔 다시 적는 우회는 브라우저 안 확인이라 막을 수 없음. 경고 수준 확인이며 이 점은 기획서 가정과 같음.)

### 저장·다시 보기
- 성인 확인 시 `localStorage` 키 `lounge.age` = `{"y":출생연도,"ok":true,"at":"2026-11-13"}` 하나만. 서버 전송 금지.
- `ok:true`이고 `올해 - y >= 19`이면 다음부터 이 화면을 건너뜀(해가 바뀌어도 성인은 계속 성인).
- 설정 창(`hud.js` 설정)에 「안내」 줄 추가: 제목 `안내`, 단추 `📋 입장 안내 다시 보기`(`.lg-btn`). 누르면 같은 화면을 **읽기 모드**로 띄움: 공지 3줄 + `닫기` 단추만(입력·체크 없음).

## 3. '일어나기' 단추 → 아래 손 단추 줄

### 모양 (정함)
- 자리: `renderDock`의 `hand` 줄. 앉았을 때 `[↩ 일어나기]`, 난간일 때 `[↩ 떨어지기]`. (대상 위 `.sp-mark`는 이 둘일 때 **만들지 않음**: `markState`가 `mine`이면 `null` 반환 → 얼굴 가림 없음)
- 한 모금(☕)·캔 버리기(🗑)가 있으면 같은 줄 **맨 앞(왼쪽)**에 일어나기, 그 뒤 한 모금, 캔 버리기. 엄지가 오른쪽 아래라 자주 쓰는 한 모금이 오른쪽 끝에 남음.
- 색: 흡연 단추 같은 **빨간 도장 단추**가 아니라 종이색 보조 단추(`.sec` 계열: `--paper2` + `--edge` 테두리). 실수로 일어나는 것을 줄이고, 한 모금이 눈에 먼저 띄게 함. 아이콘 `↩`(기존 마크와 같음).
- 글: 데스크톱·태블릿은 `↩ 일어나기`(글 있음). 휴대폰은 한 줄 폭이 모자라 **그림 `↩`만 44×44**(기존 `.sec` 규칙과 같음, `aria-label`·`title`로 이름 유지). 단, 손 줄에 다른 단추가 없을 때(캔 안 들었을 때)는 휴대폰도 글까지 보여 줌(폭 여유).
- 키: `title="E"` 유지, E 키 그대로.

### 코드 (spots.js `renderDock`)
```js
const mineSit=S.pose==='sit', mineLean=S.pose==='lean';
const s=JSON.stringify([S.can.held,cur?.id,S.pose]);if(s===sig)return;sig=s;   // pose를 sig에 넣어야 다시 그려짐
const stand=mineSit?btn('stand','↩','일어나기','sec stand',' title="E"')
         :mineLean?btn('stand','↩','난간에서 떨어지기','sec stand',' title="E"'):'';
hand.innerHTML=stand+(S.can.held?btn('sip','☕','한 모금','',' title="C"')+btn('dropCan','🗑','캔 버리기','sec'):'');
```
※ 난간 떨어지기는 지금 `act` 이름이 `stand`와 같은지 `primary()`·`act`를 보고 맞출 것(마크가 쓰던 동작 그대로 연결).
※ 난간 글은 길어서 `떨어지기`로 줄여도 됨(줄이면 `aria-label`은 `난간에서 떨어지기` 유지).

## 4. 연개발 확인 목록
1. 안내 화면이 `#app` 안(`z-index` 20)에서 3D 장면·이름 정하기보다 먼저 뜨고, 통과 전에는 입장·이동 입력이 막히는지.
2. 360×640, 390×844, 844×390에서 스크롤 없이(가로는 카드만 스크롤) 단추 3개가 보이는지.
3. 앉은 채 화면 캡처: 머리 위 단추 없음, 아래 줄에 `↩` 단추 있음.
4. 미성년 연도(예: 2012) → 막힘 화면, 새로고침하면 다시 물음. 2000 → 입장, 새로고침하면 안 물음. 설정 → `입장 안내 다시 보기` 열림.
