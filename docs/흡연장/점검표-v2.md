# 점검표 v2 — 맛과 상호작용 (연검수, 2026-11-08)

기획서 `docs/기획서-맛과상호작용-v2.md`의 A1~A6, B1~B7, 완성 기준을 하나씩 확인하는 표입니다. 결과 칸은 **「통과(코드)」** = 코드·테스트로 확인됨, **「대표 캡처 대기」** = 화면·귀·손으로 봐야 함입니다. 직접 고치지 말고 연기획에게 알립니다.

> **최종 점검 1차 결과 (코드 확인 부분, 2026-11-08)**: 코드로 볼 수 있는 항목은 모두 통과. 화면·소리·터치 항목은 자율 모드에서 캡처가 막혀 전부 「대표 캡처 대기」. 열린 문제는 §6 참고(hud.js 단추 2건, 브랜드 사소한 점 3건).

## 0. 준비
```sh
cd ~/online-smoking && export PATH=$HOME/.nvm/versions/node/v22.23.4/bin:$PATH
npm run dev        # http://127.0.0.1:5180  (주소 끝에 ?time=day|dusk|night, ?scene=morning|lunch|evening|afterparty)
```
- 주소에 `?time=`이나 `?scene=`이 있으면 상황 카드가 안 뜹니다. 상황 카드까지 보려면 붙이지 마세요.
- 콘솔 `window.lounge`: `status()`, `setTime()`, `teleport(x,z,heading)`, `setCam({yaw,dist,pitch})`, `smoker`(start·light·puff·flick·dispose·status), `npcs`, `spots`.
- PC 키: **Space·F 꾹** 들이마시기 / **R** 링 / **N** 코로 / **T** 프렌치 / **1~4** 담배 고르기 / **B** 불 빌리기 / **G** 권하기·받기 / **E** 지금 뜬 할 일(난간·벤치·캔커피).
- 휴대폰은 390×844 세로, 844×390 가로 둘 다 봅니다(크롬 개발자도구 기기 모드). **화면 터치(길게 누르기 포함)** 로 합니다.
