# 「의견 보내기」 카드 디자인·문구 (연디자인 → 연개발)

기준: 등산 수첩 종이 톤 + 빨간 도장 테두리. `src/hud-notebook.css`, `src/lounge/hud.css`의 기존 토큰만 사용. 새 색·새 글꼴·동동이·그래픽 변경 없음. 초안 CSS: `src/feedback.css`.

## 1. 모양
- 바탕: `--paper` 종이, 모서리 `4px 14px 14px 4px`(등산 시트와 같은 수첩 모양), 겉선 `--edge`, 그림자 `--lift`+`--soft`.
- 빨간 도장 테두리: 카드 안쪽 5px에 `--stamp` 점선(opacity .55). 제목 옆에 작은 도장 `수첩` 대신 **「의견」** 도장(`--stamp`, -6° 기울임).
- 뒷배경 `--scrim`. 밤/해질녘은 토큰이 자동으로 바뀜.
- 글꼴 `--nb-font`. 글자 크기: 제목 20, 안내 12, 칩 13, 내용 칸 16(iOS 확대 방지), 단추 14.

## 2. 문구
| 자리 | 문구 |
|---|---|
| 제목 | 의견 보내기 |
| 도장 | 의견 |
| 안내 | **GitHub 계정이 있으면 바로 올라가요.** 없으면 「내용 복사」로 복사해서 보내 주세요. |
| 칩 1 | 🐞 고장·이상해요 (bug) |
| 칩 2 | 💡 이런 게 있으면 (idea) |
| 칩 3 | 💬 그냥 한마디 (라벨 `feedback`만) |
| 칩 부제(선택) | 안 돼요·멈춰요 / 바라는 점 / 느낌·응원 |
| 내용 칸 안내(placeholder) | 무슨 일이 있었나요? 어디서·언제 그랬는지 적어 주면 좋아요. |
| 글자 수 | `0 / 500` (넘으면 `--accent` 색) |
| 펼침 제목 | 📎 같이 올라가는 정보 (펼쳐 보기) |
| 펼침 아래 한 줄 | 닉네임·채팅·위치·IP는 들어가지 않아요. |
| 단추 | 🐙 GitHub에 올리기(큰 도장 단추) / 📋 내용 복사 / 닫기 |
| 복사 성공 | 복사했어요! |
| 복사 실패 | 복사가 안 돼서 글을 선택해 뒀어요. 길게 눌러 복사해 주세요. |
| 내용 비었을 때 | 한 줄만 적어 주세요 (단추는 비활성) |
| 올리기 후 | 새 탭에서 GitHub가 열렸어요. 거기서 「Submit」을 눌러야 올라가요. |

단추 이름은 문구가 길어도 줄바꿈 없이 한 줄(`white-space:nowrap`), 가장 좁은 폭(320px)에서도 2열로 들어가는 길이.

## 3. 붙는 정보 펼쳐 보기
`<details class="fb-info">` — 기본은 접힘(내용 칸이 먼저 보이게). 펼치면 종이 칸(`--paper2`) 안에 `이름 / 값` 줄, 줄 사이 점선(`--rule`).
행: 체험 · 주소(방 이름·`name=` 지움) · 화면 크기 · 기기(휴대폰/PC·세로/가로) · 브라우저 · 시간대/날씨(있을 때만) · 빌드 날짜 · 지금 시각.
값이 긴 주소는 `word-break:break-all`. 접힘 줄 높이 44px, 오른쪽 ▾ 화살표.

## 4. 배치
- **휴대폰 세로(390×844):** 가운데 카드 1열. 위→아래: 제목·도장 / 안내 / 칩 3개(3열) / 내용 칸 / 글자 수 / 정보 펼침 / [GitHub에 올리기(전체 폭)] / [내용 복사][닫기].
- **휴대폰 가로(844×390):** 높이가 낮으므로 카드를 넓혀(최대 760px) 2열. 왼쪽 = 칩·내용 칸, 오른쪽 = 정보·단추. (연개발: 마크업에 `.fb-side` 래퍼가 필요 — 정보 펼침+단추 줄을 감싸 주세요. 제목·안내는 두 열에 걸침.) 내용 칸 높이는 낮게(`30dvh`), 키보드가 올라오면 카드 자체가 스크롤.
- **PC(1920×1080):** 세로형과 같은 440px 카드를 가운데에.
- 안전 영역: 바깥 여백에 `--st/--sr/--sb/--sl` 포함. 키보드: 높이는 `dvh`·카드 `max-height:100%`+스크롤이라 칸이 가려지지 않음.
- 누르는 곳은 전부 44px 이상(칩 56, 단추 48, 펼침 줄 44).

## 5. 연개발에게 (마크업 약속)
```html
<div class="fb-modal"><div class="fb-card" role="dialog" aria-modal="true" aria-labelledby="fb-t">
  <div class="fb-head"><h2 class="fb-title" id="fb-t">의견 보내기</h2><span class="fb-seal">의견</span></div>
  <p class="fb-guide"><b>GitHub 계정이 있으면 바로 올라가요.</b> 없으면 「내용 복사」로 복사해서 보내 주세요.</p>
  <fieldset class="fb-kinds"><button class="fb-kind" aria-pressed="true"><i>🐞</i>고장·이상해요</button> … </fieldset>
  <textarea class="fb-text" maxlength="500"></textarea><span class="fb-count">0 / 500</span>
  <div class="fb-side">
    <details class="fb-info"><summary>📎 같이 올라가는 정보</summary><dl class="fb-rows"><div><dt>체험</dt><dd>smoking</dd></div>…</dl><p class="fb-safe">…</p></details>
    <div class="fb-actions"><button class="fb-btn primary">🐙 GitHub에 올리기</button><button class="fb-btn">📋 내용 복사</button><button class="fb-btn">닫기</button></div>
    <p class="fb-status" role="status"></p>
  </div>
</div></div>
```
- 칩은 `aria-pressed`로 선택 표시(등산 `.nb-seg`와 같은 방식). 기본 선택은 💬 그냥 한마디.
- 복사 실패 시 `.fb-fallback` 텍스트 영역을 `.fb-actions` 위에 넣고 `select()`.
- `z-index:40`은 등산 시트(7)·흡연장 모달 위. 카드가 열린 동안 키·조이스틱 차단은 기존 방식대로 개발 쪽에서.
- 등산 `#app`과 흡연장 `#app`이 같은 토큰 이름을 정의하므로 CSS 한 벌로 충분. 단 `.fb-modal`은 `#app` 바깥(body)에 붙이면 토큰이 `:root`에서 와서 안전.

## 6. 가정·확인
- 화면으로 직접 보지 못했습니다(캡처가 자율 모드에서 막힘). 캡처 명령: `npm run dev` 후 playwright로 390×844·844×390·1920×1080 각각 카드를 열어 찍기 — 연개발 구현 뒤 확인.
- `color:#fff`는 기존 `.nb-seg .on`·`.lg-btn.primary`와 같은 방식(기존 사용값)이라 그대로 썼습니다.
- 「GitHub에 올리기」 아이콘 🐙은 이모지입니다(그래픽 파일 추가 없음).
- 도장 글자·칩 부제는 대표 확인 전 변경 가능한 문구입니다.
