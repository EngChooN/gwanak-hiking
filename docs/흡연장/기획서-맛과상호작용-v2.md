# 온라인 흡연장 — 기획서 v2: 담배 맛 + 함께 있는 재미 (연기획, 2026-11-08)

대표 의견(11-08): "흡연자 입장에서 금연 욕구를 대신할 만큼 맛있었으면 좋겠다. 지금은 심심하다(연무량 낮음). 상호작용도 더 있으면 좋겠다." → 아이디어 A1~A6, B1~B7 **전부 진행**("다 해봐").

## 0. 지키는 것 (브랜드 기준, v1 §1 그대로)
- 동동이 몸·비율·얼굴·동작 속도, `src/lounge/` 밖 원본 파일은 **고치지 않는다**. 필요한 자세(기대기·앉기 등)는 `src/lounge/` 안에서 뼈 회전을 덧씌워 만든다. 안 되면 원본을 고치지 말고 대체안으로 하고 보고한다.
- 연기는 지금처럼 **온라인 등산 「헥헥 입김」 뭉게(trail-props `puff`) 모양**을 쓴다. 크기·개수·머무는 시간만 늘린다. 실사 연기·텍스처 연기 금지.
- 새 물건은 툰 재질 + 외곽선(`toonify`), 텍스처 없음. 소리는 코드 합성(외부 파일 없음). HUD는 「등산 수첩」 종이 톤.
- 모든 기능은 HUD 버튼으로도 된다(버튼 44px 이상). 휴대폰 성능 한도(LIMITS) 안에서.

## 1. 범위
### A. 한 모금을 맛있게
| 번호 | 내용 | 기준 숫자(시작값) |
|---|---|---|
| A1 꾹 누르는 모금 | 모금 버튼/키를 **누르는 동안** 빨아들임. 불씨 밝기·타는 소리가 누른 시간에 따라 커짐. 짧게 탭하면 지금처럼 기본 모금 | 0~0.6초 약한 모금, **0.6~2.2초 꿀모금**, 2.2~3.0초 진한 모금, 3초 넘으면 콜록(기침 + 연기 조금) |
| A2 큰 연기 | 내뿜는 연기를 크게, 오래, 바람 따라 | 뭉게 지름 지금의 3~5배(약 0.15~0.35m), 5~8초 머묾, 옥상 바람 방향으로 천천히 흐름. 꿀모금일수록 많음. 카메라 쪽으로 뿜으면 화면이 잠깐 뿌옇게 |
| A3 첫 모금 연출 | 불 붙인 뒤 첫 모금 내뿜을 때: 카메라 살짝 다가감, 주변 소리 작아짐, 화면 가장자리 따뜻한 색 1.5초, "하아…" 날숨 | 과하지 않게(색 오버레이 불투명도 0.25 이하) |
| A4 소리 | 지포 뚜껑 철컥·휠 드르륵, 종이 타는 치이익(들이마실수록 커짐), 길게 내쉬는 숨, 재 터는 톡톡, 기침, 캔 따는 소리 | 모두 audio.js 코드 합성 |
| A5 연기 묘기 | 도넛 링(내뿜는 중 짧게 끊어 탭 → 링 1개씩), 코로 내뿜기, 프렌치(입→코로 다시 들이마시기). HUD 「묘기」 버튼으로도 | 링 = 작은 뭉게 8~10개를 고리로 배치해 앞으로 날아가며 커짐 |
| A6 담배 고르기 | 순한 맛 / 독한 맛 / 멘솔 / 시가 | 연기 양 ×0.8 / ×1.3 / ×1.0 / ×2.0, 멘솔은 화면 살짝 시원한 파랑, 시가는 굵고 갈색 |

### B. 함께 있는 재미
| 번호 | 내용 |
|---|---|
| B1 불 있어요? | 불 안 붙인 담배를 들고 NPC 1.5m 안 → 「불 빌리기」 버튼 → NPC가 라이터를 켜 줌. NPC가 피우는 중이면 담배 끝끼리 맞대는 「맞불」 |
| B2 한 대 건네기·받기 | 「한 대 권하기」로 가까운 NPC에게 줌 → 받아서 피우며 고맙다는 말. NPC도 가끔 나에게 권함 → 「받기」 |
| B3 끼어드는 수다 | NPC끼리 화제(상사, 점심 메뉴, 퇴근, 금연 실패담, 주식 등) 대화. 나에게 고를 대답 2~3개 칩이 뜨고 고르면 대화가 이어짐 |
| B4 같이 내뿜기 | 나와 NPC가 2m 안에서 1초 안에 동시에 내뿜으면 연기가 합쳐져 큰 구름 + 반응 대사 |
| B5 옥상에서 할 일 | 난간에 기대기, 벤치에 앉기, 자판기에서 캔커피 뽑아 들고 마시기(담배와 함께 들 수 있게) |
| B6 상황 고르기 | 출근 전 한 대(아침), 점심 먹고 한 대(낮), 퇴근길 한 대(노을), 회식 후 한 대(밤). 시간대 + NPC 화제 + 분위기가 같이 바뀜 |
| B7 금연 기록 | 한 대 다 피우면 「진짜 담배 1개비 참음 · 약 225원 아낌」(4,500원÷20) 같은 도장. 오늘·누적 수첩에 쌓임 |

## 2. 모듈끼리 약속 (동시에 작업하므로 이대로 맞춘다)
- `lounge:smoke` detail에 추가: `kind`('mild'|'strong'|'menthol'|'cigar'), `quality`('light'|'sweet'|'deep'|'cough', 내뿜기 시작 때), `trick`('ring'|'nose'|'french'|null), `first`(불 붙인 뒤 첫 내뿜기면 true), `amount`(이번 연기 양 0~2).
- `smoker.status()`에 `draw`(지금 들이마신 정도 0~1, 들이마시는 동안 계속 변함), `kind` 추가.
- 새 이벤트: `lounge:spot` {spot:'rail'|'bench'|'vending', state:'enter'|'leave'|'use'}, `lounge:scene` {id:'morning'|'lunch'|'evening'|'afterparty'}, `lounge:give` {from,to,kind:'light'|'cig'}, `lounge:record` {today,total,savedWon}.
- 파일 주인(겹쳐 고치지 않기): 연개발 = smoke.js·input.js·hud.js(버튼)·npc.js·lines.js / 연디자인 = audio.js·새 moment.js·profile.js·hud.js의 수첩 카드 부분만 / 연공간 = rooftop.js·새 spots.js·scene.js·spots.css. main.js는 각자 연결(import·초기화) 몇 줄만, 고치기 직전에 최신 파일을 다시 읽고 좁게 고친다.
