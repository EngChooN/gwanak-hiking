# 풍경 화면 결함 보완 — 산풍경

작업 폴더: `/Users/pc-2311001/gwanak-hiking`

## 원인과 수정

- 철망 상자: `KHR_mesh_quantization`의 정규화 정수 position/normal에 세계 변환을 바로 적용해 정수 범위가 넘쳤다. `instance-geometry.js`에서 Float32 속성으로 복원한 뒤 행렬을 적용한다. 원본 GLB를 변경하거나 메시를 늘리지 않았다. 정수 좌표·스케일·이동 행렬의 조합을 재현한 회귀 테스트를 추가했다.
- 검은 나무: 소나무 twig JPG의 검은 여백은 원본 glTF에 alphaMode가 없어 불투명하게 렌더됐다. `foliage-material.js`는 twig 재질에만 검은 여백 컷아웃을 적용한다. 색의 하한을 두어 축소된 바늘잎이 검은 덩어리로 뭉치는 현상을 줄였다. 하한은 현장 측정값이 아닌 시각화 가정이다.
- 사진판: `bake-nature.html`에서 PBR 조명을 영구히 굽는 대신 diffuse 색을 굽는다. `refresh-impostors.mjs`로 기존 사진판 GLB 8개의 이미지만 갱신하며 기존 배치·사진판 형상을 보존했다. 런타임 LOD는 일반 나무 12m·관목/보완 식생 10m에서 사진판으로 전환하고 저밀도 사진판은 최대 60m에서 전환하도록 앞당겼다. 컷아웃 적용 후 첫 성능 검사에서 능선 25.54fps가 나와, 근경 고밀도 모델의 알파 오버드로를 줄인 조치다. 청크 중심 거리 기준이다. 일반 식생 가시 범위는 1,400m에서 950m로 줄여 원경 알파 오버드로와 청크 갱신 비용을 제한한다. 원본 스캔과 새 외부 자산은 받지 않았다.
- 사면: `terrain-material.js`의 고도·경사 기반 암반 혼합에 공간 패턴을 더하고, 버리던 흙 가중치·실제 풀/낙엽 PBR 색을 복구했다. 회색 일색에서 화강암 대체 노두·흙·풀의 질감 변화로 바꿨다. 추가 텍스처 샘플·삼각형·인스턴스는 없다.

## 작업 범위

`src`의 등산객·보행 파일은 변경하지 않았다. `movement.js`, `view.js`는 시작 시 체크섬과 동일하다. `realistic-hiker.js`는 산디자인의 동시 작업 중 체크섬 변화가 감지됐으며, 산풍경은 작성하지 않았다. 사람 표현의 변화는 풍경 수정 전후 비교 대상이 아니다. push·배포·삭제 없음. 최종 빌드의 정적 파일 복사는 로컬 dist 생성이며 외부 배포가 아니다.

기존 CC0 자산 재사용. 현장 암종·수종·개체 위치 일치와 모바일 실기기 성능은 이번 검증 범위 밖이다. 데스크톱 headless Chrome 1440×900 결과를 다른 장비 성능 보장으로 확대하지 않는다.
