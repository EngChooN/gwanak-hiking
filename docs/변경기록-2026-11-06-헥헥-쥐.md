# 변경 기록 — ⑥ 무리해서 뛰면(헥헥·다리에 쥐) (2026-11-06, 산풍경)

상위 업무: 자동걷기 즐길거리 6종 구현(산기획) 1/4단계의 남은 부분. 기준은 `docs/기획-2026-11-06-자동걷기-즐길거리.md` §⑥과 시안 `pant`·`cramp`입니다. ①~⑤는 `변경기록-2026-11-06-즐길거리-오브젝트-동물.md`에 있습니다.

## 무엇을 했나

### 1. 규칙 `src/exhaustion.js` (순수 함수, `tests/exhaustion.test.mjs` 4개)
- 뛰다가 스테미너가 0이 되는 순간(`runExhausted`가 켜질 때) 한 번 정합니다.
  - 그 걸음의 오르막 경사가 10% 이상이고, 지난 쥐에서 2분이 지났고, 25% 확률에 걸리면 **쥐 3초**입니다.
  - 아니면 **헥헥 1.5초**입니다.
- 쥐는 "🦶 발끝 당기기"(`hiking:command {id:'cramp-release'}`)를 누르면 누른 뒤 1초에 풀립니다.
- 헥헥·쥐 동안에는 이동 입력을 받지 않습니다. 끝나면 스테미너가 30이 될 때까지 **터벅터벅**(속도는 그대로)입니다.
- 쥐가 풀리면 바로 터벅터벅으로 이어 갑니다. 헥헥 1.5초를 한 번 더 넣지 않았습니다(조작이 너무 오래 막혀서).
- 자동걷기 중에는 생기지 않습니다.
- 1인칭에서는 카메라를 흔들지 않습니다. 쥐가 난 동안만 시야를 0.8초에 걸쳐 0.3m 낮추고, 풀리면 같은 속도로 돌아옵니다.

### 2. 동동이 동작 `src/toon/hiker-acts.js`
| 동작 | 내용 |
|---|---|
| 헥헥 | 무릎을 굽혀 두 손으로 무릎을 짚고, 몸은 앞으로 숙이고 고개는 듭니다. 실눈, 벌린 입과 혀. 입김이 옆으로 퐁퐁, 땀방울이 튑니다. "헥… 헥… 다리가… 내 말을… 안 들어…" |
| 쥐 | 뒤로 넘어져 등을 대고 눕고(배낭 때문에 0.24m 뜸) 오른다리를 들어 두 손으로 종아리를 잡고 좌우로 뒹굽니다. 넘어질 때 흙먼지, 0.28초마다 종아리 위 "찌릿" 번개, 모자는 머리 옆 땅에 떨어졌다가 일어나며 다시 씁니다. "으아아 쥐났다!! 종아리!!" → "찌릿" → "휴… 풀렸다" |
| 터벅터벅 | 등산객 걷기 위에 고개·등을 숙이고 입을 벌립니다. 가끔 입김·땀과 "헥헥" 소리 |

- 공유 형상 `src/toon/trail-props.js`에 번개(`zap`, 시안에서 옮김)와 하얀 입김(`breath`)을 더했습니다. 시안 페이지도 같은 `zap`을 씁니다.
- 효과음 "헥헥"(걸러 낸 숨소리)·"찌릿"(짧은 내림음)은 WebAudio로 만들었습니다. 외부 파일은 없습니다.

### 3. 연결
- `src/trail-world.js`가 상태를 돌립니다. `update(…,{runner:{exhausted,auto,uphill}})`로 받고, HUD에는 `hiking:trail {type:'exhaust',phase,left,label,release}`를 보냅니다.
  - `label`은 쥐일 때 "쥐 0:02"입니다.
  - `release:true`이면 발끝 당기기 버튼을 띄웁니다.
- `src/main.js`는 두 줄만 바꿨습니다.
  - `trail.update`에 `runner`를 넘깁니다(오르막 = 그 프레임 `travelSlope`).
  - 1인칭 눈높이에서 `trail.eyeDrop`을 뺍니다.
- 이동 막기는 기존 `trail.busy()`(동작 중 입력 0)를 그대로 씁니다.
- 검수용 함수 `hiking.trail.exhaust('pant'|'cramp')`와 `hiking.trail.exhaustion()`을 더했습니다.

## 확인한 것
`scripts/verify-exhaustion.mjs`로 확인했습니다(PC 1280×800, 휴대폰 세로 390×844 모두 오류 0건). 비교판은 `artifacts/trail-props/board-exhaustion.html`과 `compare-exhaustion.png`입니다.
- **오르막 실제 주행:** 경사 24.7% 오르막(2,582m)에서 Shift+W로 실제로 뛰어 스테미너를 0으로 만들었습니다.
  - 헥헥은 1.48초였고, W·Shift를 계속 누르고 있어도 0m 움직였습니다.
  - 한 번은 25% 확률에 걸려 진짜 쥐가 났습니다. 3.0초 동안 0m 움직였고, 저절로 풀렸습니다.
- **터벅터벅:** 스테미너 17일 때 켜져 있었고, 30에서 꺼졌습니다.
- **쥐:** 이동 0m, 모자가 땅에 떨어졌다가 끝나면 다시 머리 위에 있습니다. 발끝 당기기는 1.01초에 풀렸습니다.
- **1인칭 시야:** 0.3초에 −0.08m, 1.8초에 −0.30m였고, 풀리면 0으로 돌아왔습니다.
- **단위 테스트:** `npm test` 529개가 모두 통과했습니다.

## 작업 중 고친 것
- **번개 위치:** 번개가 머리 쪽에 떴습니다. 비켜 놓을 거리를 정규화한 방향 벡터로 더해서 1m 떨어졌기 때문이라 고쳤습니다.
- **에어건 흙먼지(⑤):** 같은 원인으로 흙먼지가 발에서 1m씩 흩어져 있었습니다. 이제 시안처럼 발 둘레에 모입니다(`airgun.png` 다시 찍음).
- **누운 몸 번개:** 번개가 누운 몸 방향을 따라 옆에서 보면 얇게 보였습니다. 선 자리 기준으로 세웠습니다.
