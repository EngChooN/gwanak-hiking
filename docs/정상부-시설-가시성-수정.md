# 정상부 시설 가시성 수정 — 산풍경

## 판단과 수정

기존 `artifacts/summit-facilities/summit.png`를 직접 확인했다. 시설이 없는 기존 화면이며 이번 수정 결과로 재등록하지 않는다.

300° 정상 카메라에서 레이더의 기존 상대 방위는 약 245°, 응진전 57°, 표지석 90°다. 모두 수평 시야 밖이다. 갈림길 90° 카메라에서도 기존 표지는 서쪽에 있다. 시설 통계가 있는 것만으로 화면 가시성을 판정할 수 없었다.

`summit-config.js`의 추정 배치를 다음과 같이 바꿨다. 실제 현장 배치의 확정값은 아니다.

| 시설 | 기준점 상대 X/Z (m) | 상대 방위 |
|---|---|---|
| 레이돔 | 정상 −35/−35 | 315° |
| 응진전 | 정상 −24/−7 | 약 286° |
| 표지석 | 정상 −7/−4 | 약 300° |
| 헬기장 | 갈림 +14/+4 | 약 106° |
| 갈림 표지 | 갈림 +5/−1 | 약 79° |

표지판 앞면도 관찰 방향을 향하도록 회전했다. 시설 높이는 중심점뿐 아니라 외곽 16방향과 기준 경로 고도 중 최대값에 8cm 여유를 더한다. 시설 받침 영역은 수평으로 만들고 바깥 3m에서 기존 지형으로 연결한다. 시설 자체 크기·LOD·삼각형 예산은 유지한다. 높이 보정은 시설 주변 지형을 바꾸므로 접합·보행 노면과의 연결은 실행 검수가 필요하다.

581m 갈림 기준은 DSM 정렬 고도가 아니라 `originalY` 원본 GPX 고도로 선택한다. 실행 중 정상 고도 632m와 GPX 원본 654.5m를 구별한다. 캡처의 임의 `route.length-493`도 같은 갈림 기준점에 가장 가까운 경로 선분 시작점으로 교체했다.

## 노란 지그재그

캡처에는 원거리 산면 전체에 규칙적인 명암 반복이 있다. 지형 셰이더가 월드 좌표의 반복 PBR 색·노멀과 주기적인 색 보정을 원거리까지 적용한다. 이것이 주된 원인이라는 코드 기반 추정이며 GPU 비교 검증은 하지 못했다.

`terrain-material.js`에서 35~120m 사이 노멀 세부를 평탄화하고 50~180m 사이 색 세부를 숲·화강암 기본색 쪽으로 92% 완화한다. 색 보정의 주기도 10배 넓히고 진폭을 줄였다. 근거리 PBR은 유지하며 새 텍스처·메시·드로우콜은 추가하지 않는다. 실제 무늬 감소량과 색 변화는 캡처 대조가 필요하다.

## 검증 상태

- `git diff --check` 통과.
- 회귀 검사 추가: 정상 300°·갈림 90° 카메라 절두체에 대상 시설 포함, 원본 고도 기반 갈림 선택, 외곽 지면보다 낮지 않은 받침 높이.
- 캡처 결과 JSON에 시설 배치 좌표·높이, 카메라 위치·플레이어 좌표·방위·경로 거리를 기록하도록 보강.
- 기존 캡처에서 집계한 삼각형은 5종 합계 LOD0 1,164 / LOD1 916 / LOD2 292 / LOD3 92다. 이번에는 형상·삼각형을 바꾸지 않았다. 이번 실행 실측값은 아니다.
- **npm test, 사본 빌드·preview, 수정 후 캡처 2장 미실행. 가시성·관통·색 변화의 화면 확인 미완료.**

## 가정

현장 좌표가 없어 기존 300°/90° 검토 화면에서 볼 수 있는 상대 배치를 기본값으로 정했다. 시야 내 배치를 실제 관악산의 확정 방위로 간주하지 않는다. 받침 높이는 국소 지형을 보수적으로 덮는 추정값이다.

## 대표 확인 필요

사용자의 로컬 실행 허용보다 우선하는 개발 지시에 “스크립트 실행 같은 위험 작업은 하지 말고”가 남아 있어 실행하지 않았다. 커밋·push 없음. 아래는 별도 사본에서 실행할 검증 명령이며 사본·산출물을 이번 턴에 만들었다는 뜻이 아니다.

```sh
# 작업 폴더의 고유한 새 사본 경로. 원본·기존 사본을 덮어쓰지 않는다.
test ! -e /private/tmp/gwanak-summit-visibility-review
mkdir /private/tmp/gwanak-summit-visibility-review
rsync -a --exclude=.git --exclude=node_modules --exclude=dist --exclude=artifacts /Users/joonyoung/gwanak-hiking/ /private/tmp/gwanak-summit-visibility-review/
ln -s /Users/joonyoung/gwanak-hiking/node_modules /private/tmp/gwanak-summit-visibility-review/node_modules
cd /private/tmp/gwanak-summit-visibility-review
export PATH=/Users/joonyoung/.nvm/versions/node/v24.22.2/bin:$PATH
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5177
# 별도 터미널, 같은 사본 폴더와 PATH에서
BASE_URL=http://127.0.0.1:5177 node scripts/capture-summit-facilities.mjs
```

사본의 `artifacts/summit-facilities/summit.png`와 `junction.png`에서 정상 3종·갈림 2종의 실제 픽셀 노출 및 노란 반복 무늬 감소를 확인해야 완료다. 절두체 검사는 지형·나무에 의한 가림을 보장하지 않는다.
