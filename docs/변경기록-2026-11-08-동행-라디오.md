### 채널
| 주파수 | 내용 | 재생 |
|---|---|---|
| 91.9 잔잔한 음악 | Kevin MacLeod 8곡(CC BY 4.0, 약 30분) | 시각 % 총 길이로 '흘러가고 있던' 곡·위치에서 시작, 곡 사이 1.5초 겹침 |
| 95.5 산 날씨·등산 안내 | 대본 15줄(radio-design §5) | 녹음 파일이 없어 **자막 + 합성한 낮은 톤**(110·165·220Hz, 느린 흔들림) + 합성 징글. 멘트 40~60초 간격, 처음 맞추면 0.8초 뒤. 고르기 규칙(정상 근처 > 비·안개·눈 > 바람 > 노을·밤 > 계절 > 날씨 > 오래 걸음 > fm-id, 마지막 3개 반복 안 함)은 `radio-tracks.js` `pickGuideLine`. **녹음이 생기면 `manifest.json`의 `lines[].file`에 파일 이름만 적으면 소리가 붙습니다** |
| 99.1 숲과 바람 | Freesound CC0 6개 | 바람·새 4개 층 + 물 2개 층을 따로 돌려 겹침(층 길이가 달라 똑같이 반복되지 않음), 파일 사이 3초 겹침 |

- 섞기(radio-design §3-2): 또렷함 `clarity`(±0.1 = 1, 0.9 MHz 밖 = 0, 직선), 방송 = clarity^1.5 × 볼륨, 잡음 = (1 − clarity)^0.8 × 볼륨 × 0.55, 방송에 저역 통과 800 + 5200 × clarity Hz, 음량은 `setTargetAtTime`(약 0.08초). 맞추는 순간 딸깍.
- 잡음은 파일 없이 Web Audio로 만듭니다(분홍 잡음 2초 반복 + 고역·저역 필터 + 가끔 찌직).
- 파일을 못 받으면 표시창 "방송이 끊겼어요"·잡음만(오류 창 없음). 불러오는 중에는 "…".
- 소리 경로: 발소리와 **같은 AudioContext·마스터**(사용자 음량·'소리 꺼짐'을 따름) → 라디오 버스 최대 0.7. 소리 꺼짐이면 무음 + 표시창 "소리 꺼짐". 라디오가 켜져 있으면 환경음 ×0.7.
- 곡은 `<audio>`로 **흘려 받고**(긴 곡을 통째로 풀지 않음) MediaElementSource로 섞습니다. 전원이 켜져 있고 그 채널이 들릴 때만 불러오고, 끄면 0.2초 페이드 뒤 노드를 떼고 `<audio>` 주소를 비웁니다.
- 저장 `gwanak-radio` = `{freq,vol}`(처음 91.9·0.6). 전원은 늘 꺼진 채 시작합니다(자동 재생 정책).
- 외부 접속 없음: manifest·소리는 같은 출처 `assets/radio/`, 방송사 주소는 `radio-stations.js`의 링크뿐(시험이 src 전체를 훑어 막음). `CANDIDATES`는 지웠습니다.

### 파일 용량 (원본은 바꾸지 않음)
- 91.9 8곡 71MB(160~320kbps 스테레오), 99.1 6개 17MB(약 180kbps), 합계 약 88MB. 파일 하나 최대 15MB라 GitHub Pages 100MB 한도에는 걸리지 않습니다.
- `<audio>`가 듣는 부분만 받으므로 휴대폰 데이터는 대략 비트레이트만큼 씁니다(320kbps 곡 = 1분에 약 2.4MB).
- **압축안(제안만, 실행 안 함):** 91.9는 AAC-LC 96kbps 스테레오(.m4a, 아이폰 사파리·크롬 모두 재생) → 약 22MB, 99.1은 AAC 64kbps → 약 7.6MB. 합계 약 30MB(⅓). 예: `ffmpeg -i in.mp3 -c:a aac -b:a 96k out.m4a`. 바꾸면 manifest의 `file`·`duration`만 고치면 됩니다. CC BY 곡은 "변경함"(인코딩만이면 보통 변경으로 보지 않지만 표기해도 무방)을 크레딧에 적을지 산리서치 확인.
