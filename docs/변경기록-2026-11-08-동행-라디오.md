## A. 같이 등산하기(동행)

### 무엇을 만들었나
- 함께 걷기 중에 다른 사람을 골라 **🤝 같이 등산하기**를 제안하고, 상대가 수락하면 둘이 **나란히** 걷습니다. 동행 중인 두 몸은 서로 겹치지 않습니다.
- 고르는 방법은 두 가지입니다(휴대폰도 됨, 단축키 전용 없음).
  - 머리 위 **이름표를 누르면** 고르기 카드가 뜹니다. 보이는 모양은 그대로 두고 누름 칸만 넓혔습니다.
  - HUD **👥 버튼**(💬 채팅 버튼 오른쪽)을 누르면 '👥 함께 있는 사람' 목록(이름·거리·🤝 단추)이 뜹니다.
- 받은 사람: 화면 아래 **제안 카드** "○○님이 같이 등산하자고 해요" + [수락]·[거절 n초] + 30초 띠.
- 보낸 사람: 위쪽 칩 "○○님에게 제안했어요 · 기다리는 중…" + [취소].
- 수락 뒤 둘 다: 위쪽 칩 **"🤝 ○○님과 동행 중"** + 지금 상태(나란히 걷는 중 / 앞뒤로 걷는 중 / 조금 떨어져 있어요 / ○○님 기다리는 중 / ○○님 연결을 기다리는 중…) + [동행 끝내기]. 상대 이름표에 🤝 표시.
- 짧은 알림: "○○님이 지금은 어렵대요", "지금은 다른 분과 함께예요", "조금 뒤에 다시 제안할 수 있어요", "제안은 10초에 한 번만 보낼 수 있어요", "○○님이 답이 없어요", "○○님이 동행을 마쳤어요", "○○님 연결이 끊겨 동행을 마쳤어요" 등. 문구는 `multi-protocol.js` `PAIR_TEXT` 한곳.
- 모양은 등산 수첩 톤(종이·철끈 점선·도장 빨강)으로 먼저 만들었습니다. **산디자인이 `src/pair-ui.css`를 다듬을 차례**입니다.

### 서버 규칙 (`server/rooms.mjs`, 메모리만·디스크 저장 없음)
| 규칙 | 값 |
|---|---|
| 한 사람 | 제안 하나(보냄·받음) 또는 쌍 하나 |
| 제안 만료 | 30초 → 저절로 거절(보낸 사람 `pair:declined timeout`, 받은 사람 `pair:canceled timeout`) |
| 재제안 금지 | 거절·만료 뒤 같은 사람에게 60초 |
| 제안 간격 | 10초에 1번 |
| 숨김(신고 3명) | 제안 불가. 숨겨지는 순간 동행도 끝 |
| 끊김(소켓) | 60초 유예, 상대에게 `pair:wait`. resume으로 같은 ID가 돌아오면 둘 다 `pair:on`(다시 이어짐). 60초가 지나면 `pair:off gone` |
| 나가기(b)·다른 방 | 바로 끝 |
| 체험 | 등산만(`EXPERIENCE_MESSAGES.hiking`), 흡연장은 버림 |

- 메시지: 보냄 `pair:offer{to}`·`pair:accept{to}`·`pair:decline{to}`·`pair:cancel{to}`·`pair:end`, 받음 `pair:offer`·`pair:sent`·`pair:no{reason,wait?}`·`pair:declined`·`pair:canceled`·`pair:on`·`pair:wait`·`pair:off`(모두 `id` = 상대).
- 클라이언트 상태기계 `createPairClient`(`multi-protocol.js`)는 서버 메시지를 따라가고, 10초·60초·숨김·바쁨은 서버보다 먼저 막습니다. 내 컴퓨터 모드(BroadcastChannel)에서는 서버 몫(바쁨 거절·30초·사라짐 60초)도 합니다.
- 위치 flags에 `FLAG.auto = 8`(자동 걷기 중)을 더했습니다. 상대 자동 걷기 여부를 알아 속도를 맞춥니다.

### 나란히 걷기 · 겹치지 않기 (`src/pair-walk.js`, 순수 계산)
- 동행 중 **8m 안**이면 나란히 모드입니다.
  - 길 폭 1.6m 이상·계단 아님 → **좌우**: 길 중심선 ±0.5m(간격 1.0m), ID가 작은 사람이 왼쪽. 좁으면 가장자리 0.3m 안으로 줄임.
  - 폭 1.6m 미만·계단 → **앞뒤 한 줄**: 앞선 사람이 앞, 뒷사람은 1.5m보다 가까우면 늦춤.
- **겹치지 않기:** 두 몸 중심이 0.85m보다 가까우면 서로 반씩 비켜납니다(최대 0.8m/s = 0.1초에 8cm). 옆으로 자리가 없으면 앞뒤로 비킵니다. 딱 겹치면 ID 순서로 갈라집니다.
- **길 밖·허공으로 안 밀림:** 옮길 때마다 `route-surfaces` 노면 폭(반폭 − 0.3m)을 넘지 않고(이미 길 밖이면 더 나가지 않음), `animal-lanes.inForbid`(바위·시설 금지 원)에 새로 들어가지 않습니다. 광장·정상은 그 구역 경계 검사(`setPlayerPosition`)를 거칩니다.
- **서버 순간이동 거부(`FLAG.jump`)에 안 걸림:** 한 프레임 이동이 8cm 이하라 서버 한도(2m + 12m/s)와 클라이언트 순간이동 표시(0.1초 2m)보다 한참 작습니다. 두 브라우저 시험에서 거부 0건.
- **자동 걷기:** 둘 다 자동 걷기면 앞선 쪽이 상대 속도에 맞춰 조금 더 늦춰 따라잡히게 합니다. 8m 넘게 앞서면 0.4배, 15m 넘으면 0.2배로 아주 느리게 걷고 칩에 "○○님 기다리는 중"(멈추지는 않음). 앞뒤 줄의 앞사람은 1.5m 간격까지만 기다립니다.
- 직접 걸을 때는 자기 조작이 그대로이고, 옆 키를 누르지 않는 동안만 자리로 천천히(0.5m/s) 옮겨 갑니다. 카메라는 흔들지 않습니다.
- `movement.js`의 `advance`에 입력 두 개를 더했습니다: `laneTarget`(자동 걷기가 중심선 대신 이 옆 자리로 감, 없으면 0 = 예전과 같음), `pace`(0.1~1 속도 배율, 없으면 1).

- 잡음은 파일 없이 Web Audio로 만듭니다(분홍 잡음 2초 반복 + 고역·저역 필터 + 가끔 찌직).

- 91.9 8곡 71MB(160~320kbps 스테레오), 99.1 6개 17MB(약 180kbps), 합계 약 88MB. 파일 하나 최대 15MB라 GitHub Pages 100MB 한도에는 걸리지 않습니다.
