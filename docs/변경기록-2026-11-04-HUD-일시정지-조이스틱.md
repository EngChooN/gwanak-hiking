# 변경 기록 — HUD 전 기능 노출·일시정지 제거·떠다니는 조이스틱 (2026-11-04)

## 일시정지 개념 제거
- 일시정지 버튼·화면·`state.paused`·`pause` 명령·`resumeOnInput`을 모두 없앴다. 저장에서 이어와도 바로 걷는다.
- Space는 휴대폰을 들었을 때 셔터뿐이다. ESC는 열린 창·기구(쌍안경·휴대폰)·상호작용 패널 닫기에만 쓴다(`escape` 명령).
- 지도·조작 안내 창이 열려 있는 동안은 걷기 입력을 막는다(일시정지가 아니라 입력 차단). 탭을 벗어나면 저장만 한다(`suspend`).
- 정상 도착 때 멈추던 동작도 없앴다.

## 모든 기능 버튼 노출
- 새로 넣은 버튼: 쌍안경(B), 휴대폰(P). 아이콘+이름+단축키 구조로 통일.
- 데스크톱 1440×900: 아래 한 줄에 자동 걷기·앉기·(차)·쌍안경·휴대폰·시점·헤드랜턴·정면 보기·수첩·스트레칭·지도, 위쪽에 소리·HUD·조작 안내. 잘림·겹침 없음.
- 휴대폰: 아이콘 버튼(42px)을 오른쪽 위에 2열(세로)·3열(가로)로 묶고, 달리기는 오른쪽 아래 큰 둥근 버튼. 정보 패널은 왼쪽 위에 작게. 숨은 버튼 0개(더보기 없음).
- 구간 이동 버튼은 유지, 왼쪽 정보 아래로 옮겨 겹치지 않는다.

## 떠다니는 조이스틱 (`src/joystick.js`, `src/input.js`)
- 왼쪽 절반 아무 곳이나 손가락으로 누르면 그 자리에 생기고, 떼면 사라진다. 쌍안경·휴대폰을 든 동안과 마우스는 둘러보기.
- 데드존 20%(움직이는 중에는 14%), 직진 보정: 앞·뒤·옆 ±28° 안은 한 방향만, 사선은 17° 폭 8방향 스냅, 경계 8° 유지.
- 손가락이 반지름을 넘으면 기준점이 따라온다. 오른쪽 절반은 시점 드래그.
- 첫 사용 전에만 흐린 안내 고리가 보인다.
