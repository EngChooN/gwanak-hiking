# 좌표 확정·지형 연결 점검

산개발 · 2026-11-03 · 부분 구현, 자료 확보 대기

## 결과

- `data/체크포인트표.csv`는 5곳 모두 좌표 확인불가다. 안내 표지판 좌표는 장소 자체의 좌표가 아니므로 확정 좌표로 사용하지 않았다. 임시 표시는 유지했다.
- `docs/실경자료-조사.md`, `docs/고해상도-지형-교체-준비.md`는 고해상도 DEM·정사영상 미확보를 명시한다. 현재 near.f32는 30m DSM을 8m로 보간한 자료다. 신규 지형 연결과 둑·웅덩이 점검은 미완료다.
- 정상 기준 632m를 대체할 확정 고도·수직 기준이 없어 유지했다.
- 진행 저장에 경로 기하·폭·체크포인트 배치·정상 고도의 서명을 추가했다. ROUTE_ID가 같아도 서명이 바뀌면 진행을 초기화한다. ID 변경 시 기존 차단도 유지한다.
- 서명 없는 이전 저장도 안전하게 초기화한다. 첫 업데이트 후 기존 진행이 복원되지 않는 의도적 호환성 변경이다. 음소거·화질 설정 키는 건드리지 않는다.
- 서명은 비보안 32비트 변경 감지값이며 파일 무결성 보증이나 암호학적 해시가 아니다. 지형 자체가 바뀌고 경로 기하가 동일한 경우에는 ROUTE_ID를 별도로 갱신해야 한다.
- 회귀 테스트 2개 추가: 기하·배치 변경 감지, 동일/이전/서명 누락/다른 ID 저장 복구. 기존 테스트는 수정하지 않았다.

## 검증

코드 정적 검토만 수행했다. npm test·빌드·화면·접지·충돌·청크 경계·성능 검증은 이번 지시의 스크립트 실행 금지로 수행하지 않았다. 테스트 통과나 실제 좌표 확정을 주장하지 않는다. 화면 변경이 없어 새 캡처는 없다.

## 가정

프로젝트 내 최신 조사·인계 문서를 전달 상태의 기준으로 삼았다. 다른 위치의 미전달 자료는 사용하지 않았다. 기존 미커밋 변경이 다수 있어 이번 작업 파일만 커밋 대상으로 삼는다.

## 대표 확인 필요

1. 5곳의 장소 자체 WGS84 좌표, 근거, 정확도와 정상 표고의 수직 기준 확보.
2. 사용 허용 고해상도 DEM·메타데이터와 지형 교체 결과 전달. 이후 로더·충돌·접지·스트리밍 및 실제 메시와 GPX 오차 검증 필요.
3. 스크립트 실행 금지 해제 후 다음 명령으로 검증한다.

```sh
cd /Users/joonyoung/gwanak-hiking
npm test
npm run build
npm run dev -- --port 5176
```

푸시·배포·외부 전송은 하지 않는다.
