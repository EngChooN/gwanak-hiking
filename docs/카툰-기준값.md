## 0. 먼저 알아 둘 것
1. **색은 sRGB hex입니다.** three.js의 `Color.set('#…')`에 그대로 넣으면 선형으로 바뀝니다.
   - 아래 값은 화면에 최종으로 보이는 색(톤매핑·색보정 후)입니다.
   - 재질 색은 조명과 색보정을 거친 뒤 이 값에 가깝게 보이도록 맞추세요.
   - 맞춤 확인은 비교 스크립트(§4)의 기준색 띠로 합니다.
2. **값 하나는 여러 사진의 중앙값입니다.** 영역마다 채널별 중앙값을 찍고, 그 값들의 중앙값을 다시 냈습니다.
   - 개별 값은 「근거」 열에 적었습니다. 대상 안에서 밝기 차가 크면 범위도 함께 적었습니다.
3. **출처의 한계**
   - 사진은 팬 위키 스크린샷이고, 공식 원본이 아닙니다.
     - 06 물 폴더의 상당수는 색 단계가 줄어든(포스터화) 사진이라 경계에 띠가 보입니다.
     - 중앙값은 이 영향을 거의 받지 않습니다.
   - 「왕국의 눈물」 사진은 하늘 섬 2장(07_10·07_11)뿐이라, 낮 기준은 사실상 「야생의 숨결」입니다.
   - 같은 장면이 두 번 들어간 사진(10_08=10_09, 11_08=11_09)은 한 장으로 셌습니다.

## 4. 비교 이미지 스크립트 (산풍경·산개발용)
오브젝트 하나를 고칠 때마다 우리 화면을 같은 자리에서 찍습니다.
- 결과 이미지: 참고 사진 2~3장과 2×2로 붙이고, 맨 아래에 이 문서의 기준색 띠를 깝니다.
- 결과에 참고 사진이 들어가므로 `artifacts/cartoon-compare/`는 `.gitignore`에 넣었습니다.

```bash
# 1) 개발 서버(스크립트가 /src/movement.js를 불러오므로 vite dev가 필요)
npx vite --host 127.0.0.1 --port 5310
# 2) 프리셋 촬영 — scripts/cartoon-compare-presets.json
node scripts/cartoon-compare.mjs tree --tag after        # 하나
node scripts/cartoon-compare.mjs tree,grass,rock         # 여러 개
node scripts/cartoon-compare.mjs final --tag after       # 최종 판정 10장
# 3) 자리를 직접 지정
node scripts/cartoon-compare.mjs --name rock-yeonju --s 3600 --yaw -30 --pitch -8 --time 11:00 --refs 04_19,04_14,04_16
node scripts/cartoon-compare.mjs --name city --start summit --bearing 345.6 --time 20:30 --refs 09_03,10_04
# 4) 이미 찍은 화면으로 비교 이미지만
node scripts/cartoon-compare.mjs rock --image path/to/shot.png --tag v2
```

- **프리셋:** 최종 판정 10장은 `final:true`로 표시돼 있습니다.
  - 클로즈업: tree·grass·rock·water
  - 장면: forest·valley·ridge·summit-view·dusk·night-city
  - 따로 소나무용 pine도 있습니다.
- **옵션:**
  - `--style realistic`: 실사 모드로 찍어 비교합니다.
  - `--third`: 3인칭으로 찍습니다.
  - `--base`: 다른 서버 주소를 씁니다.
- **결과물:**
  - 비교 이미지: `artifacts/cartoon-compare/<이름>-<tag>.png`
  - 우리 화면 원본: `shots/<이름>-<스타일>-<tag>.png`
  - 콘솔·셰이더 오류와 위치: `results.json`
- **기타 도구:**
  - `node scripts/cartoon-ref-sheet.mjs [폴더번호]`: 폴더별로 파일명이 붙은 전체 목록 이미지(`sheets/NN.png`)를 만듭니다. 사진 고를 때 씁니다.
  - `node scripts/cartoon-palette.mjs`: 팔레트를 다시 뽑습니다. 영역을 고치려면 `scripts/cartoon-palette-samples.json`을 수정하세요.
- **현재 화면 기준 이미지:** `--tag baseline`으로 찍은 11장(재작업 전)이 `artifacts/cartoon-compare/*-baseline.png`에 있습니다.
