# after16 — 큰 바위 묻힘 보존

산개발 / 2026-11-03. 코드 수정 완료, 실행·시각 검수 대기.

## 수정과 근거

13차 검수와 round13의 summit-a14-third.png / summit-a15-third.png를 확인했다. after15는 밑면이 지형보다 낮은 일반 바위까지 `ground-before.y`만큼 들어 올렸다. 이 때문에 원래 묻혀 있던 rock_face_02·boulder_01 13개가 +0.67~+5.39m 상승했다.

- `nearDetail=false` 일반 바위는 `min(0, 보정지형−원래지형, 보정지형−기존바닥)`만큼만 이동한다. 회랑 하강은 따라가고 기존 묻힘 깊이는 유지하며, 원래 떠 있던 바닥은 지표로 내린다. 상승은 허용하지 않는다.
- 원래지형은 회랑을 깎기 전의 동일 64m/2m Float32 삼각형을 조회한다. 연속 높이 함수를 차감해 보간 오차까지 회랑 하강으로 오인하지 않는다. 조회 캐시 총 8개 제한을 유지한다.
- 모든 LOD의 인스턴스에 같은 Y 이동을 적용하고 경계 상자·구를 다시 계산하는 기존 경로를 유지한다. 계단 옆 nearDetail=true rock_09의 지표 맞춤 계산·음영 차폐율·노면은 변경하지 않았다.
- `allStairSections`와 `visibleRendered`에서 일반 바위 오차는 `max(0, 바닥−지형)`으로 계산한다. 상세 바위는 기존 절대오차다. `signedGroundError`는 묻힘 깊이를 숨기지 않고 남기며 `groundingMode`, `terrainDrop`, `heightCorrection`을 기록한다. 지형 누락은 null로 계속 실패 처리한다.
- `capture-route-surfaces.mjs`에 s=5030 / first·third를 추가했다. 기존 계단 결과 키 first/third는 유지하고 summit-first/summit-third에 정상 직전 결과를 남긴다. 켬/끔 화면·띠 지표·셰이더 오류·접지 검사도 함께 기록한다.
- 일반 바위 무상승·회랑 하강 시 묻힘 보존·떠 있는 바위 하강·모든 LOD 동일 이동·상세 바위 절대오차·지형 누락에 대한 회귀 테스트를 추가했다. 테스트는 실행하지 않았다.

## 하늘 파편 조사

비교 화면에서 after15에만 오른쪽 판석과 검은 삼각형들이 나타난다. 바위 InstancedMesh는 castShadow=false이고 after15는 모든 LOD에 동일한 Y 이동을 적용한다. 따라서 바위가 직접 투사한 그림자라는 설명은 코드와 맞지 않는다. 큰 바위 상승으로 원래 묻힌 메시 일부가 드러났다는 것이 현재 가장 유력한 설명이다. 이번 변경은 이 상승 경로를 제거한다.

다만 개별 파편의 메시·LOD 식별이나 수정 후 소멸은 실행 없이 확정할 수 없다. LOD 자체의 형상 결함 또는 다른 메시 원인은 미배제다. 새 s=5030 캡처를 after14와 대조하기 전에는 파편 해결·완료 기준 통과를 주장하지 않는다. 남으면 해당 장면에서 바위 종류별 표시 및 LOD 고정 비교로 원인을 분리해야 한다.

## 가정

일반 바위의 기존 사면 매립은 의도된 배치다. 상대 묻힘 깊이 기준은 접촉 밑부분 상자의 중심 XZ이며 전체 바닥 면적의 관통 검사는 아니다. 검은 파편은 들린 바위의 노출 형상으로 추정하며 아직 런타임 확인 전이다.
