- 시작 전에는 입력·걸은 시간·자동 걷기·저장을 막음. `window.hiking.ready()`(Promise), `hiking.start()`, `hiking:start` 이벤트.
- 규약: `docs/이동-휴식-통합규약.md` §로딩 단계 신호, §광장 출발과 위치.

## 복장 2차 보정 (산기획 지시)
- 상의 밑단: 벨트 없는 3·4번도 셰이더 밑단 절단선(`uHemY`)을 벨트 아래 4.5cm로 둬 가랑이·치마 모양과 3번 뒷모습 얼룩을 없앴다. 벨트 있는 1·2번은 기존대로 벨트 위.
- 1번: 접힌 카라 두 날개(`poloCollar`), 앞섶 단(셰이더), 단추 3개 추가. 가슴 로고는 작은 타원으로 축소.
- 2번 가슴 패치: 베이지 테두리·겨자 바탕·갈색 산 무늬 그림 패치. 3번: 작은 흰 방패(안쪽 빨강).
- 4번 모자: 기존 납작한 파나마 메시를 숨기고 챙 양옆이 말린 흰 챙모자 + 검정 띠(`wideHat`)를 머리뼈에 부착.
- 선택 화면: 배경을 불투명하게 하고 선택 화면이 있는 동안 `#resume-note`를 숨김.
- 확인: npm test 198/198, npm run build 통과, 광장 3인칭 걷기(4번, 균형) 60.0fps, 콘솔 오류 0건.
