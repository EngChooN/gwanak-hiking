## ① 멧토끼

### 1-1. 모델 사양 (`hare()` — `src/toon/trail-props.js`, 종류 이름 `'hare'`)
원점 = 발바닥, 앞 +Z. 다람쥐·고양이와 같은 도우미(`ell`·`capsule`·`decal`·`eye`)와 외곽선을 씁니다. 텍스처는 없고 단색 + 툰 재질입니다.

| 항목 | 값 |
|---|---|
| 크기 | 몸길이 약 0.38m, 앉은 키(귀 빼고) 약 0.30m, 귀 끝 약 0.46m. 다람쥐(0.25m)보다 크고 고양이(0.4m)와 비슷 |
| 색 | 털 `#a9875a`, 등 줄 `#8d6c44`, 배·볼 `#f6ead4`, 귀 안쪽 `#f2b3a6`, 귀 끝 `#3b2c20`, 꼬리 솜 `#fff7ea` |
| 얼굴 | 점눈(검정, 눈높이 +.1), 분홍 코, 작은 웃는 입. 고양이와 같은 큰 눈 비율 |
| 외곽선 | 다른 동물과 같은 두께. 귀 안쪽·꼬리는 `line:0`/작게 |

**움직이는 부위 이름** (게임이 `traverse`로 찾는 이름. 다람쥐 `head`·`tail`, 고양이 `head`·`tail`·`paw`와 같은 방식)

| 이름 | 종류 | 쓰임 |
|---|---|---|
| `body` | Group | 웅크림·일어서기(`rotation.x`, `position.y`) |
| `head` | Group | 풀 뜯기(`rotation.x` 0.75까지), 두리번(`rotation.y`) |
| `ears` | Group | 둘을 함께: `rotation.x` 0.5 = 뒤로 눕힘, 0 = 보통, `-.05`(각 귀) = 쫑긋 |
| `ear-L`·`ear-R` | Group(`ears` 안) | 한쪽만 까딱(경계 중 한쪽씩 돌리기) |
| `legs` → `leg-F`·`leg-H` | Group | 앞다리 둘·뒷다리 둘. 깡충은 `leg-H.rotation.x` 0.9(뻗음), `leg-F` -0.9 |
| `tail` | Group | 솜뭉치. 알림 때 살짝 들기(`position.y` +.03) |

삼각형 수는 다람쥐와 비슷한 수준입니다(귀 3겹·다리 4덩이). 원형은 한 번만 만들고 `clone(true)`로 나눠 씁니다.

### 1-2. 상태별 동작

| 상태 | 모습 | 시간 | 들어가는 조건 → 나가는 조건 |
|---|---|---|---|
| `idle` 풀뜯기 | 고개 숙여 `head.rotation.x` 0→.75를 0.5초 주기로 ±.12 끄덕, 귀는 뒤로(`ears.x` .5), 꼬리 살랑 | 풀 4~9초 → 고개 들고 2~3초 두리번 → 다시 풀 | 기본. 플레이어 8m 안이면 `alert` |
| `alert` 귀 쫑긋 | 몸 −.28 세우고 `position.y` .21, 귀 곧게(`-.05`), 고개 정면, **얼어붙음**(걸음 멈춤, 꼬리만 작게) | 1.2초 | 8m 안(또는 3m 안에서 플레이어가 움직임) → 3m 안이면 `flee`, 8m 안에서 가만히 있으면 `idle`로 |
| `hop` 깡충 | 몸이 늘어나며 공중으로 .12m, 뒷다리 뻗음·앞다리 모음, 귀는 뒤로 뜸. 착지에서 몸 납작(`scale.y` .9) | 한 번 0.35초 | 풀 있는 쪽으로 옮길 때(4~7번 한 묶음) → 묶음 뒤 `idle` |
| `flee` 달아나기 | 플레이어 반대쪽으로 `yaw`를 돌리고 낮게 엎드려 달림, 귀 눕힘(`ears.x` 1.0), 큰 보폭 | 3.5초, 속도 5.0m/s | `alert`에서 3m 안 / 방해(걷는 속도 이상으로 다가옴) → 3.5초 뒤 `goneFor(40)`로 사라짐 |
| `return` 다시 다가옴 | 고개 낮고 귀 반쯤(`ears.x` .2), 한 걸음 가고 멈추기 반복 | 3~6초 | 사라진 40초 뒤 같은 구역 다른 자리에 다시 나타남(멀티 대비 §3), 플레이어가 **20초 이상 가만히** 있으면 5m까지 다가와 `idle` |

모자·배낭 위로 오르기 같은 상호작용은 만들지 않습니다(다람쥐·까치 전용 유지).

### 1-3. 말풍선 문구 (`src/trail-lines.js` 톤: 짧게 + 몸 개그, 첫 문구가 대표 안)
`kind`: ''=동동이 말 · `sfx`=소리 글자(형광펜) · `tag`=이름표·속마음. 붙이는 법은 기존과 같습니다.

```js
// ⑦ 멧토끼(2026-11-07 시안)
'hare.alert':{kind:'sfx',at:'animal',seconds:1,lines:['쫑긋!','…!','(귀가 먼저 알았다)']},
'hare.thump':{kind:'sfx',at:'animal',seconds:.9,lines:['탁!','탁탁!']},          // 뒷발 구르기(경계 신호) — 선택
'hare.flee':{kind:'sfx',at:'animal',seconds:1.1,lines:['휙!','깡충깡충!','후다닥!']},
'hare.munch':{kind:'tag',at:'animal',seconds:2.2,lines:['냠냠…','(풀이 맛있다)','아삭아삭…']},
'hare.return':{kind:'tag',at:'animal',seconds:2.2,lines:['…(슬금슬금)','…다시 와 봄','(안 무서운 사람?)']},
'hare.look':{kind:'',at:'head',seconds:1.8,lines:['귀가… 나보다 길다','저 귀… 안테나인가?']},  // 동동이가 토끼를 볼 때 — 선택
```
대표 안 5개: **쫑긋! / 휙! / 냠냠… / …(슬금슬금) / 귀가… 나보다 길다**. `'hare.look'`은 귀가 쫑긋해진 순간 동동이 머리 위(`at:'head'`)에 띄우는 한 줄 개그이고, 자동걷기 중에는 한 구역에서 한 번만 띄웁니다(말풍선 겹침 규칙은 기존 `quiet` 그대로).

## ② 동물별 배회 스타일 수치표

기준: 동동이 걷기 1.3m/s, 기존 다람쥐 달아나기 3.4m/s, 놀람 거리 `squirrelLook` 3m·`magpieFlee` 4m. 모두 **제안 시작값**이고 확률은 "한 묶음(걸음→멈춤)을 마칠 때마다 뽑는 값"입니다. 난수는 구역 ID + 시간 칸으로 정한 결정적 난수(멀티 대비 §3).

| 항목 | 다람쥐 | 토끼 | 까치 | 고양이 |
|---|---|---|---|---|
| 이동 방식 | 짧게 뛰기(전력 질주) | 깡충 4~7번 한 묶음 | 땅 종종걸음 + 짧은 비행 | 느린 어슬렁 |
| 이동 속도 | 2.8~3.6m/s | 2.2m/s(평소) · 5.0m/s(달아남) | 0.9m/s(걸음) · 5.0m/s(날기) | 0.5m/s |
| 한 번 이동 거리 | 1.5~4m | 묶음 2~5m | 걸음 2~5m · 날기 6~15m | 3~8m |
| 멈춤 시간 | 1.5~4초(고개 두리번) | 풀 뜯기 4~9초 + 두리번 2~3초 | 2~5초(고개 갸웃) | 앉아 있기 8~25초 |
| 놀람 거리 | 3m(`squirrelLook`) | 8m 경계 · 3m 달아남 | 4m 날아오름 | 4m 쳐다봄(달아나지 않음) |
| 달아난 뒤 | 40초 뒤 재등장 | 40초 뒤 재등장, 20초 가만히 있으면 5m까지 다가옴 | 날아간 쪽 나무에 앉음 | 달아나지 않음(쓰다듬기 가능) |
| 등산로 가로지르기 | 묶음당 6% (뛰어서 2~3초) | 묶음당 10% (깡충 3번) | 걸어서 5% · 날아서 20% | 묶음당 4% (천천히, 길 한가운데서 멈춤 0~3초) |
| 나무 타기 | 멈춤 뒤 15%: 가까운 나무(6m 안) 줄기에 붙어 2.5초 오름 → 사라짐 | 없음 | 걸어 있다 25%: 다른 나무로 짧게 날아 앉음(높이 2~4m) | 없음 |
| 짧은 비행 | 없음 | 없음 | 6~15m, 3초, 포물선 높이 2~4m | 없음 |
| 한 곳에 머무는 시간 | 12~25초 | 20~40초(풀 자리) | 15~30초 | 40~120초 |
| 활동 시간·계절 가중 | 낮 ×1.0 · 가을 ×1.4 · 겨울 ×0.1 | 새벽·해질녘 ×2.0 · 낮 ×0.4 · 밤 ×0.8 | 낮 ×1.0 | 새벽·저녁 ×1.5 · 한낮 ×0.5 |
| 구역 안 길에서 떨어진 폭 | 4~14m(나무 가까이) | 2~10m(풀·관목 가장자리) | 0~8m(길가 땅) | 2~6m(쉼터 옆) |

고정 자리를 없애려면 위 숫자를 **구역 안 무작위 자리 + 위 행동**으로 돌리면 됩니다. 기존 반응(쳐다보기·모자 오르기·날아오르기·쓰다듬기·벤치 옆자리)은 그대로 유지합니다. `LIMITS.trailAnimals`(3) 안에서, 가까운 구역 동물부터 채웁니다.
