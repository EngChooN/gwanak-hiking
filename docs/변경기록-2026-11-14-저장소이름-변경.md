## 남은 순서
1. 대표가 GitHub 웹에서 저장소 Settings → Repository name을 `ai-office-world`로 바꿈.
2. `git remote set-url origin https://github.com/EngChooN/ai-office-world` 뒤 커밋·`npm run deploy`(이름만 바꾸면 사이트가 옛 경로로 만든 파일을 찾아 깨지므로 배포를 바로 이어서 함).
3. 함께 걷기 서버를 켤 때 `npm run multi:up`이 새 저장소의 gh-pages에 서버 주소 파일을 올림.
