# 릴스 콘티 — 「관악산, 집에서 올라요」 (산디자인, 2026-11-11)

상위 업무: 인스타 릴스용 온라인 등산 소개 영상 · 1/4단계(콘티·자막·엔딩 카드). 다음 단계(촬영 스크립트·편집)는 이 문서를 기준으로 합니다.

- 규격: 세로 1080×1920, **총 40초**(본편 37초 + 엔딩 3초), mp4 H.264/AAC, 목소리 없음.
- 소리: 게임 안 소리(발소리·바람·새·계곡물)만. 배경음악 없음. 라디오 장면은 **99.1(숲과 바람, CC0)** 만 들리게 하거나 소리를 줄인다(91.9는 Kevin MacLeod CC BY라 크레딧을 캡션에 적어야 함 — §6).
- 사이트 확인(2026-11-11): 허브(`/`)에 등산·흡연장 카드 2개, `/hiking/` 산 고르기 → 서버 카드 → 입장 흐름이 배포돼 있다. 아래 기능은 11-02~11-11 변경 기록에 있는 것만 썼다.

## 2. 첫 2초 (훅)

- **화면**: 정상 근처 노을 능선. 서울 도심이 아랫녘에 깔리고 하늘이 주황~보라인 장면(「너의 이름은」 풍). 카메라는 정지하지 말고 느리게 한쪽으로 훑는다(움직임이 첫 프레임 이탈을 줄인다).
- **문구**: **「집에서 관악산 등산하기」** — 기획서 예시 그대로. 1.0초에 큰 글이 위에서 툭 떨어져 자리 잡고 2초까지 유지. 14자 이내 두 줄(`집에서` / `관악산 등산하기`).
- 이유: 장소(관악산)와 새로움(집에서)을 한 번에 말한다. 가장 예쁜 장면을 맨 앞에 두고 곧바로 "처음부터" 올라가는 구조라 끝까지 볼 이유가 생긴다.

## 4. 엔딩 카드 — `artifacts/reels/ending.html`, `ending.png`

- 구성: 하늘~능선 그림 위에 큰 문구 **「관악산, 집에서 올라요」**(작은 글 「온라인 등산 · 무료 웹 게임」), 아래 종이 카드에 **`engchoon.github.io/gwanak-hiking/hiking`**(두 줄, 대표 결정 11-13)(빨강 강조), 구분선, **「AI Office로 만든 게임」**(AI Office 초록 강조) + 「기획·디자인·개발, 모두 AI 직원들이」.
- 색·서체는 허브 화면 종이 톤을 그대로 썼다(종이 #fbf3df, 잉크 #4a3618, 강조 #b8452e·#2f6b4a). 모든 요소가 안전 영역(x 64~912, y 250~1500) 안.
- 주소에는 `https://`를 뺐다(글자를 크게 하려고). 클릭이 안 되는 릴스라 직접 치기 쉬운 짧은 형태가 낫다. 기획서의 전체 주소는 캡션에 넣는다.
- 다시 만들기: `artifacts/reels/ending.html?guide=1`을 열면 안전 영역이 점선으로 보인다. PNG 재생성은 같은 폴더 HTML을 1080×1920 창으로 열어 스크린샷.
- 주의: 이 주소는 **허브**라 들어가면 흡연장 카드도 보인다(§7). 등산만 열고 싶으면 `/hiking/`로 바꿔야 하는데 기획서가 허브 주소를 지정해 그대로 두었다 → 대표 결정 사항으로 올림.

## 7. 흡연장 — 홍보 영상에서 **뺀다**

이유:
1. **정책·노출 위험**: 담배를 피우는 장면은 인스타·메타 광고·추천 정책에서 제한·연령 제한 대상이 될 수 있다(정확한 현행 조항은 업로드 전 확인 필요). 가상이라도 담배 연기·불씨가 화면의 중심이 된다.
2. **메시지가 섞인다**: 이 릴스는 "관악산 등산"과 "AI Office로 만든 게임"이 핵심이다. 흡연장은 금연 중인 사람 대상 별도 컨셉이라 같은 40초에 넣으면 두 가지가 모두 흐려진다.
3. **건강한 산 이미지와 충돌**: 등산 브랜드(맑은 산 공기)와 옥상 흡연장은 같은 영상에서 어색하다.
4. **분량**: 등산 기능만으로 40초가 이미 가득하다.

대신 지킬 것:
- 허브(`/`) 첫 화면에는 흡연장 카드가 있으므로 **영상은 `/hiking/` 직접 주소로 촬영**해 허브를 화면에 넣지 않는다(엔딩 주소는 허브라서 §4 주의).
- 캡션에 흡연장을 언급하지 않는다. 흡연장 홍보 영상이 필요하면 별도 릴스로 기획한다(연령 제한 설정·정책 확인 포함).

## 8. 다음 단계에 넘기는 것·대표 결정이 필요한 것

- 촬영·편집(2·3단계): 위 표의 URL·키를 `scripts/` 스크립트로 옮긴다. 구간 이동 버튼 대신 `hiking.teleport` 류 진단 함수가 있는지는 개발 쪽 확인 필요(이 단계에서 코드는 열어보지 않았다).
- **함께 걷기 장면은 서버가 켜져 있어야 한다**: `npm run multi:up`(맥 + 터널)이 필요하고, 안 켜지면 같은 브라우저 창끼리 모드(`?server=off`)로 두 창을 찍을 수 있다.
- 라디오 장면: 91.9를 쓰면 캡션에 CC BY 크레딧, 99.1(CC0)이면 불필요. 99.1 권장.
- 화면 아래 출처 줄은 녹화에서 숨긴다(11-13 대표 결정, 날씨 Open-Meteo는 영상에 쓰지 않음). 그래서 캡션에 「지형 © Copernicus · 건물·물 © OpenStreetMap contributors」 크레딧 문장을 꼭 넣는다.
- **결정 필요**: ① 엔딩 주소를 허브 그대로 둘지 `/hiking/`로 바꿀지(허브에 흡연장 카드가 보임). ② 40초 본편이 길면 25–28초(지도·수첩) 장면을 뺀 35초판.
- 아이폰 실기기 가독성 확인은 아직 못 했다.
