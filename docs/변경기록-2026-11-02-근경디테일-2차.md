상태: 코드 수정·정적 검토 완료, 실행·시각 검증 대기. 이번 지시의 스크립트 실행 금지에 따라 캡처·테스트·빌드를 실행하지 않았다. 완료 기준 충족을 주장하지 않는다. 기존 30개 통과·fps 기록은 이전 버전 결과다.

- `load-landscape.js`: 기존 리본 폭·고도·충돌 형상을 유지하고, 렌더링 전용 `trailEdge` 속성을 -1~1로 정규화한다. 기존 `uv.x`는 미터/타일 폭이어서 이전 가장자리 가중치가 폭에 의존했다. 알파 해시와 공간 패턴으로 바깥쪽을 불규칙하게 지면에 혼합한다. 투명도 정렬 대신 알파 해시를 사용하므로 미세 입자감은 육안 확인이 필요하다.
- `near-detail.js`: 고정 난수로 양쪽 길가에 2m 간격 자갈·낮은 풀을 배치한다. 인접 경로도 검사해 길 중앙을 비운다. 자갈은 기존 CC0 Rock 09의 3.3cm 높이에 맞춰 약 4~19cm 크기로 사용한다. 풀은 5장 삼각형의 절차형 군집이다. 430m 이상 상부 길가에는 12m 간격 소나무·관목 후보를 배치하며 600m 위에는 낮은 묘목을 사용한다. 실제 좌표로 64m 청크를 만든다.
- `realistic-models.js`: 기존 관목 최소 배율 .28(약 1.4m), 근경 실제 입체 GLB → 48m 사진판 → 110m 저밀도 사진판으로 전환한다. 새 자갈·수목은 180m, 풀은 130m 거리에서만 표시한다. LOD 거리는 청크 중심 기준이므로 전환 시점 차이는 시각 검증 대상이다.
- 식생 입체 LOD0의 모든 파트 최하단을 구해 지면에 맞추며 약간 묻는다. 사진판은 투명 여백을 바닥으로 오인하지 않도록 원래 이미지 기준점을 유지한다.
