# 변경 기록 2026-11-08 — 서버 고르기 창 (등산·흡연장)

담당: 산개발 · 기획: 산기획 「서버 고르기 창 기획」(1/2단계) · 커밋·배포 안 함(산기획 검수 뒤)

## 무엇이 바뀌었나
등산(/hiking/)·흡연장(/smoking/)에 들어갈 때 게임처럼 **서버 목록 창**에서 서버를 고릅니다. 서버마다 `n / 20명`, 위쪽에 `지금 접속 n명`(이 체험)·`전체 n명`(등산+흡연장)이 보입니다. 방 이름을 직접 치는 칸은 없앴습니다.

## 서버 쪽
- **서버 목록 표** `src/multi-protocol.js` `SERVERS`(+ `SERVER_MAX=20`·`serverRoomName`·`findServer`).
  - 등산 `{id:'1',name:'관악산 1서버',room:'관악산-1'}`, 흡연장 `{id:'1',name:'옥상 1서버',room:'옥상-1'}`.
  - 서버 쪽 방 이름은 기존 방 키 규칙대로 끝 `-1`을 뗍니다(`hiking:관악산`, `smoking:옥상`). 2서버부터는 그대로(`관악산-2`)라 줄 하나만 더하면 됩니다.
- **정원** `server/rooms.mjs`:
  - 서버 목록의 방은 꽉 차면 `-2`로 넘기지 않고 `full`로 거절합니다. 옛 주소의 끝 번호만 다른 이름(`관악산-3`)도 같은 서버로 봅니다. 목록 밖 방 이름은 예전 규칙(`-2`, `-3` …) 그대로입니다.
  - welcome에 `server:'1'`을 붙입니다.
  - 서버 방에서 신고로 숨겨진 사람은 옮길 방이 없어 같은 방에서 이름만 익명입니다.
  - `serverCounts()`로 서버별 `{id,name,count,max}`를 냅니다(`max`는 `MAX_PER_ROOM`).
- **/health** `server/multi-server.mjs`: `servers:{hiking:[{id,name,count,max}],smoking:[…]}`와 `total`(전체 접속)을 더했습니다. 기존 칸은 그대로입니다(CORS `*`).

## 창 (공용)
- `src/server-pick.js` + `src/server-pick.css`. 등산 수첩 종이 톤(낮·노을·밤 토큰, 토큰이 아직 없을 때는 낮 값), 줄 56px·단추 48px·닫기 44px·입력 16px, 안전 영역 안. 휴대폰 가로는 목록 왼쪽·닉네임과 혼자 단추 오른쪽 두 칸.
- 서버 줄을 누르면 바로 들어갑니다. 꽉 찬 줄은 `꽉 참`으로 비활성.
- 닉네임 12자, 저장값 `gwanak-multi-name`을 다시 씁니다(등산 옛 카드와 같은 값, 흡연장은 없으면 로비 닉네임).
- 창이 열려 있는 동안 5초마다 `/health`를 다시 받습니다(ws 주소 → http(s)`/health`, 4초 넘으면 실패로 봄).
- 연결이 안 되면 `서버에 연결할 수 없어요` + `혼자 걷기/피우기`만. 서버 주소가 없으면(`?server=off` 등) 내 컴퓨터 모드 표시, 줄은 고를 수 있음.
- 들어간 뒤 다시 열면 지금 서버 줄에 `지금 여기`, 아래 단추는 `나가서 혼자 걷기/피우기`, ✕로 닫기. 처음 창은 고를 때까지 닫히지 않습니다.
- 서버가 `full`로 거절하면(동시에 들어와 21번째) 나가기 뒤 창이 `방금 꽉 찼어요`로 다시 뜹니다. 30초 뒤 다시 시도는 하지 않습니다.

## 등산
- 산 고르기 → **서버 고르기** → 출발(`src/hiking-server-pick.js`가 창 하나를 산 고르기·HUD에 같이 씀). 고를 때까지 출발 신호를 보내지 않습니다(로딩은 뒤에서 계속).
- 산 고르기를 건너뛰는 경우(`?pick=off`, 점검 스크립트 + `?serverpick=on`)에는 서버 고르기 창이 출발 문입니다.
- main.js가 듣기 전에 고른 참가는 `window.__hikingMultiJoin`에 남겨 두었다가 main.js가 처리합니다.
- `src/multi-entry-ui.js`: 방 이름·닉네임 카드를 없애고 설정 시트의 `👋 함께 걷기` 버튼과 상태 칩이 서버 고르기 창을 엽니다. 칩·버튼에 방 이름 대신 `관악산 1서버`.

## 흡연장
- `src/lounge/multi-ui.js`: `👥 같이 피우기` 단추가 같은 창을 엽니다(참가 카드 없앰, `lounge/multi.css`에서 카드 스타일 삭제). 상태 칩은 단추 그대로.
- `src/lounge/main.js`: 로딩(처음 온 사람은 로비 카드) 뒤 창을 띄웁니다.
- 상태 문구: `방금 꽉 찼어요 · 다른 서버를 골라 주세요`, 방 이름 대신 `옥상 1서버`.

## 건너뛰기 규칙
- 옛 주소 `?multi=관악산-1`, `?multi=옥상-1`은 창 없이 바로 1서버(`legacy`). `?server=off`도 그대로.
- 점검 스크립트(navigator.webdriver)는 창을 건너뜁니다. `?serverpick=on`으로 켜고 `?serverpick=off`로 끕니다.

## 가정
- 서버 줄을 누르면 바로 들어갑니다(따로 `들어가기` 단추 없음). 닉네임은 고르기 전에 칩니다.
- 처음 창은 ✕가 없습니다. 혼자 걷기/피우기 또는 서버를 골라야 넘어갑니다.
- 인원을 아직 받지 못한 동안(첫 0.x초)은 줄이 `… / 20명`으로 비활성입니다.
- 흡연장 닉네임도 등산과 같은 저장값을 씁니다(같은 사람이면 같은 이름).
- `?pick=off`로 들어오면 예전에는 바로 출발했지만 이제 서버 고르기 창이 먼저 뜹니다(점검 스크립트는 그대로 건너뜀).

## 디자인 메모 (산디자인, 서버 고르기 창 검수·다듬기)
- **톤:** `server-pick.css`는 수첩 토큰(`--paper`·`--ink`·`--go`·`--low`·`--stamp` 등)만 씁니다. 낮·노을·밤과 흡연장 `lounge/hud.css` 토큰 모두 같은 이름이라 따로 고칠 것 없이 맞습니다. 빨간 왼쪽 띠 = 수첩 도장 색.
- **상태 표시:** 열림 = 초록 테두리·초록 막대, 꽉 참 = 빨간 테두리·빨간 막대·`꽉 참` 꼬리표(흐리게, 못 누름), 지금 여기 = 도장색 굵은 테두리, 연결 실패 = 빨간 점선 안내 + 줄은 `— / 20명`으로 흐리게 + 혼자 걷기/피우기 단추가 도장색으로 바뀌어 눈에 띔. 색만으로 구분하지 않도록 글자(`꽉 참`·`지금 여기`)를 같이 둠.
- **이번에 고친 것(CSS만):**
  1. 가로 휴대폰에 키보드가 올라온 높이(약 200px): 전에는 창 안에서 스크롤해야 혼자 단추가 보였음 → 합계를 제목 줄로 올리고 닉네임 설명 글을 접어 **스크롤 없이** 닉네임·혼자 단추가 한 화면(창 170px).
  2. PC(1920×1080): 창이 420px로 작아 보여 460px로 키우고 제목·줄 높이를 조금 키움.
- **그대로 둔 것:** 세로·가로·PC 기본 배치, 입력 글자 16px(iOS 확대 방지), 줄 56px·혼자 단추 48px·✕ 44px, 안전 영역 패딩. JS 구조는 바꾸지 않음.
- **알아둘 점:** 등산 서버 창 종이 톤은 `?time=`이 아니라 **실제 시각**(`free-settings-ui.js applyHudTime`)을 따릅니다. 밤 12시 시험은 톤을 직접 지정해야 해서 캡처 스크립트가 `data-hud-time`을 고정합니다.
- **확인:** `node scripts/capture-server-pick.mjs`(서버 2개·vite를 직접 띄움) → `artifacts/server-pick/` 41장 중 서버 창 36장. 등산·흡연장 × 세로 390×844·가로 844×390·PC 1920×1080 × 일반·꽉 참·연결 실패(낮), 키보드(세로 390×430·가로 844×200), 노을·밤, 모든 줄 검사 통과(단추 44px 이상, 창이 화면 안, 가로 넘침 없음, 일반 상태는 스크롤 없이 한 화면, 노을·밤 톤 적용, 콘솔 오류 0). 키보드는 화면 높이를 줄여 흉내 낸 것이라 **실제 휴대폰 키보드는 미확인**.

## 추가: 산 고르기 첫 화면 닉네임 칸 (대표 추가 지시, 산개발)
흡연장 첫 화면('입장하기')처럼 등산도 첫 화면에서 이름을 넣습니다.

- **어디에:** 산 고르기(`src/mountain-pick.js`) 머리글 아래 수첩 종이 칸 `✎ 닉네임`. 12자까지(`NET.nameMax`), 비우면 안내 글자 `등산객XXXX`(서버가 익명 이름을 붙임).
  - PC: 제목 아래 가운데 360px 칸. 휴대폰 세로: 머리글 폭 그대로. 휴대폰 가로: 왼쪽 머리글 열 안(두 번째 안내 줄 `지금은 1곳…`은 숨겨 자리 확보).
- **저장값:** 서버 고르기 창과 같은 `NAME_KEY` `gwanak-multi-name`. 치는 대로 저장하고 `▶ 오르기`를 누를 때 한 번 더 정리해 저장합니다. 공용 함수 `loadPickName`·`savePickName`(`src/server-pick.js`, 12자·공백 정리, 저장소가 막혀도 멈추지 않음).
- **서버 고르기 창:** 열 때마다 저장값을 다시 읽어 닉네임 칸을 미리 채웁니다. 창에서 고치면 치는 대로 같은 저장값에 반영합니다(전에는 고를 때만 저장). 흡연장은 저장값이 비어 있으면 예전처럼 로비 닉네임을 씁니다.
- **혼자 걷기:** 골라도 이름은 저장돼 있어, 나중에 HUD 👋 함께 걷기로 열면 그 이름이 채워집니다. 다시 들어오면 마지막 이름이 칸에 있습니다.
- **단축키:** 칸에서 `keydown`·`keyup`·`keypress`를 멈춰 R·C·F·WASD·Space 같은 걷기 단축키가 먹히지 않습니다(Esc만 통과, Enter는 입력 끝 = 휴대폰 키보드 닫기).
- **휴대폰 키보드:** 칸에 들어가면 `pk-typing` 상태가 되어 산 고르기 화면이 스크롤되고, `visualViewport`로 잰 키보드 높이(`--kb`)만큼 아래를 비운 뒤 칸을 보이는 곳 가운데로 끌어옵니다. 가로 휴대폰은 머리글 열이 내용 높이만큼 늘어나 스크롤로 닿습니다.
