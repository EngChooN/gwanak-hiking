# 변경 기록 — 즐길거리 규칙·HUD 버튼·자동걷기 들르기 연결 (2026-11-06, 산개발)

상위 업무: 자동걷기 즐길거리 5종 구현(산기획) 2/4단계. 기준은 `docs/기획-2026-11-06-자동걷기-즐길거리.md`이고, 모형·동작은 앞 단계(`변경기록-2026-11-06-즐길거리-오브젝트-동물.md`, 산풍경)에서 만든 것을 이벤트로 연결했습니다. 커밋·배포는 하지 않았습니다.

## 무엇을 했나

### 1. 규칙 `src/trail-rules.js` (순수 함수)
- **초콜릿:** 처음 5개(`state.chocolates`, 이어하기 저장에 남음). 먹으면 `state.chocoLeft`=30초 동안 이동속도 ×1.2. 효과 중·다른 동작 중·0개면 못 먹음(겹침 없음). 효과 시간은 저장하지 않음.
  - 걷기·뛰기·자동걷기 모두 적용(`movement.js` 코스·광장·정상 속도에 곱함). **계단 노면은 그대로**(한 칸 한 걸음 리듬 유지).
- **벤치:** 벤치에 앉아 있는 동안 스테미너가 초당 22.5(땅에 앉기 15의 1.5배). `advance()` 입력 `benchRest`로 받음.
- **즐길거리 줄 고르기(`trailBarView`):** 우선순위 = 쥐 발끝 당기기 → 역기 연타 → 벤치 일어나기 → 들르기(자동걷기 중) → 오브젝트 옆 버튼(직접 걸을 때 6m 안).

### 2. HUD `src/trail-hud.js/.css`
- **진행 카드 간식 줄**(스테미너 밑): `🍫 n/5` 칩, `🍫 먹기` 버튼, 먹은 뒤 `⚡ 빨라짐 0:28` 칩. 빨라진 동안은 ⚡ 칩이 먹기 버튼 자리에 섭니다(버튼은 막힘). 0개면 "🍫 다 먹음".
  - 휴대폰 가로에서는 카드 높이를 맞추려고 노면·방위 줄(`.nb-foot`)을 숨겼습니다(세로는 원래 숨김).
- **즐길거리 줄**(화면 아래, PC = 가운데, 가로 = 도장 칩 왼쪽, 세로 = 도장 칩 위 좌우 가득):
  - 자동걷기 들르기 버튼(빨간 도장색, 4초 줄어드는 막대). 누르면 걸어가 동작 → 길로 돌아와 자동걷기 다시 켜짐.
  - 직접 걸을 때 6m 안: 산스장 `🏋 역기`·`🙃 거꾸리`·`🌀 허리돌리기`·`🤸 철봉`, `🪑 벤치에 앉기`, `💨 신발 털기`, `🐱 쓰다듬기`.
  - 역기: `💪 들어 올리기 n/10` 연타 버튼과 10칸 게이지(pointerdown에서 바로 셈).
  - 벤치: `🧍 일어나기`.
  - ⑥ 쥐: `🦶 발끝 당기기`(노랑), 스테미너 칸에 `쥐 0:02`.
- 휴대폰에서 모든 버튼은 44px 이상, 안전 영역 안. 기구(쌍안경·휴대폰)를 들면 숨깁니다.

### 3. 도장 `interaction-logic.js`·`interaction-controller.js`·`interaction-ui.js`
- 수첩에 **즐길거리 칸** 2개: "산스장 득근"(역기 10회), "깨끗한 신발"(에어건). 코스 스탬프 6개와 따로이고 완등 카드 조건에는 넣지 않았습니다. `gwanak-interaction:v1`의 `fun`에 저장.
- 처음 얻으면 알림 한 번("💪 산스장 득근 도장 쾅!").

### 4. `trail-world.js`·`main.js` 연결
- 들르기 제안은 **자동걷기 중에만** 보냅니다(한 번 지날 때 한 번, 12m 넘게 멀어지면 다시). 자동걷기를 끄면 바로 사라집니다.
- **들르기 거리는 소품 가장자리부터 잽니다**(`OFFER_REACH` 산스장 3.4m·벤치 0.75m·에어건 0.6m). 산스장 가운데가 길에서 6.2m라, 가운데로 재면 자동걷기로는 한 번도 뜨지 않았습니다(입구~정상 확인에서 찾음).
- 직접 누른 동작도 끝나면 서 있던 길로 걸어 돌아갑니다(예전에는 6m를 순간 이동).
- `hiking:trail-view` 이벤트(바뀔 때만): `{near, act, stage, offer, auto, busy}`.
- 초콜릿 명령(`chocolate`)은 main.js가 개수를 세고 `acts.eatChocolate(30)`으로 몸짓만 부릅니다(trail-world의 개수 없는 처리는 뺌). 구간 이동·자유 설정 다시 출발 때 초콜릿 개수를 그대로 둡니다.
- 말풍선은 화면 밖으로 잘리지 않게 안쪽으로 당깁니다. 층은 그대로 z 20(HUD 6~7 위, 알림 32~33 아래).

### 5. 휴대폰 상한 `src/device-profile.js`
- `trailAnimals:3`(그대로), `trailEffects` 휴대폰 24·PC 60(흙먼지·하트·땀·반짝이 동시 수, 넘으면 오래된 것부터 뗌, `hiker-acts.js`), `trailBubbles:1`.

## 검사하며 고친 것
- 휴대폰 가로에서 `⚡ 빨라짐` 칩이 카드 밖으로 삐져나옴 → 빨라진 동안은 먹기 버튼 자리에 칩을 둠.
- 산스장 들르기가 자동걷기로 한 번도 뜨지 않음 → 가장자리 거리로 잼.
- 🦶 발끝 당기기 버튼 전체가 들썩여서(scale 애니메이션) 누르기 어려움 → 발 그림만 들썩임.

## 알아 둘 것
- 개발 서버(HMR)는 다른 사람이 파일을 저장할 때마다 페이지를 다시 읽어 검사가 중간에 끊깁니다. 검사는 HMR을 끈 서버나 `npm run preview`로 돌리세요.
- 헤드리스 브라우저는 프레임이 느려(한 프레임 0.1초 상한) 벽시계로 잰 스테미너·이동 속도가 실제보다 낮게 나옵니다. 그래서 벤치는 "서 있을 때 대비 배율"로 검사합니다.
- 자리 자료의 `m`(GPX 수평거리)과 게임 코스 거리 `s`는 정상 쪽에서 약 90m 벌어집니다. 자리로 순간 이동할 때는 게임 길에서 가장 가까운 `s`를 찾아 쓰세요(`verify-trail-dropin-route.mjs` 참고).
