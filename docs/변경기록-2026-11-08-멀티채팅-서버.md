# 변경 기록 — 멀티 서버 채팅·흡연장 열기, 등산 채팅 연결 (2026-11-08, 산개발)

상위 업무: 「멀티 서버 붙이기: 등산·흡연장 둘 다 함께하기 + 등산 채팅」 1/4단계(산기획 기획서 '공통 규격'). 커밋·push·배포·서버 공개는 하지 않았습니다.

## 무엇이 문제였나
- 함께 걷기 서버는 체험별로 방을 나누기만 하고, 흡연장 메시지(위치·채팅·담배 상태)는 '예약'으로 막혀 있었습니다.
- 등산에는 채팅이 없었습니다. 흡연장 예약안은 `lounge:chat`이라 등산과 서버 코드를 두 벌로 둬야 했습니다.

## 바꾼 것
- **프로토콜 `src/multi-protocol.js`**
  - 공통 채팅 `c`: `CHAT`(80자·2초 1번·10초 4번·최근 3줄), `sanitizeChat`(제어·방향 문자 제거, 금칙어 `***`), `createChatLimiter`.
  - `EXPERIENCE_MESSAGES`: 공통 = `j`·`report`·`b`·`c`. 등산 = 공통 + `s`·`g`·`a`·셀카 4종. 흡연장 = 공통 + `s`·`lounge:smoke`. `RESERVED_MESSAGES`를 없앰(`lounge:chat` 예약은 `c`로 대체).
  - 담배 상태 허용 목록 `SMOKE_STATES`(= `src/lounge/smoke.js`가 내는 상태 12개)·`sanitizeSmoke`.
  - 체험별 익명 이름 `ANON_PREFIX`(등산 `등산객`, 흡연장 `손님`), `anonymousName(id, 체험)`.
- **서버 `server/rooms.mjs`·`server/multi-server.mjs`**
  - `c`: 속도 제한 → 넘으면 `{t:'c-limit'}`, 정리·금칙어 → 보낸 사람 포함 같은 방에 `{t:'c',id,text}`.
  - 채팅은 저장하지 않음. 사람마다 최근 3줄을 메모리 링버퍼로 두고, 신고 기록 한 줄에 `chat`(대상의 최근 3줄)만 남김.
  - `lounge:smoke {state,lit}` 검사·중계(보낸 사람 제외), 새로 온 사람에게 마지막 상태. 흡연장 `s`는 등산과 같은 검사.
  - 채팅 금칙어 = `server/chat-banned-words.txt`(산리서치가 만들 기본 목록, 없으면 빈 목록, `CHAT_BANNED_FILE`로 경로 변경) + `BANNED_CHAT_WORDS`. 순수 함수 `parseWordList`, `loadChatBanned`.
  - 통계에 `chats`·`chatLimited`·`smokes`(개수만).
  - `server/Dockerfile`에 `server/chat-banned-words.tx[t]`(없어도 빌드되게), 두 `.dockerignore`에 같은 파일.
- **전송 `src/multi-transport.js`**: BroadcastChannel 채널 이름 `gwanak-multi:체험:방`(`broadcastChannelName`, 등산은 옛 이름 `gwanak-multi:방` 유지, 방 이름의 `:` 제거). 내 컴퓨터 모드 채팅도 서버와 같은 규칙(속도 제한·정리·나에게 되돌려 줌·받은 글 다시 정리). WebSocket 전송은 그대로이고 `c`·`c-limit`·`lounge:smoke`·`s`를 손대지 않고 주고받는 것을 시험으로 확인.
- **등산 클라이언트 `src/multi-client.js`**: `hiking:chat-send {text}` → 전송, 받은 `c` → `hiking:chat {id,name,text,me,remote:true}`(차단한 사람 글은 버림), `c-limit` → `hiking:chat-limit {reason:'rate'}`, 서버 모드 연결 전 → `{reason:'offline'}`. 채팅 HUD는 산디자인.
- **결함 고침:** HUD 상태 칩이 있을 때 처음 띄운 "연결 중…" 알림이 연결된 뒤에도 화면에 남던 문제(두 브라우저 캡처에서 발견). 상태 알림이면 지우도록 고침.
- **문서**: `docs/멀티-서버-운영안내.md` §2(환경 변수 2개)·§3-1(메시지 표·채팅·흡연장·익명·내 컴퓨터 모드)·새 §3-2(등산 이벤트, 흡연장이 쓸 전송 계층 인터페이스)·§6(Docker 파일·배포 명령 모음, 실행 안 함)·§8(채팅 보관). `AGENTS.md` §6·§7·§8.

## 가정
- 금칙어는 부분 일치로 가립니다(띄어 쓰거나 글자 사이에 기호를 넣은 변형은 못 잡음). 이름 금칙어(`BANNED_WORDS`)와 채팅 금칙어는 따로입니다.
- 채팅 링크(URL)는 막지 않았습니다(기획서 규칙에 없음).
- 속도 제한에 걸린 글은 세지 않습니다(성공한 글만 2초·10초 창에 들어감).
- 흡연장 `lounge:smoke`는 `state`·`lit`만 중계합니다(`puffs`·`left` 등은 버림).
- 신고된 사람의 채팅도 중계하고 이름만 익명으로 보입니다.
- 등산 BroadcastChannel은 옛 채널 이름을 그대로 써서 호환합니다(새 이름과 둘 다 듣지 않음).
