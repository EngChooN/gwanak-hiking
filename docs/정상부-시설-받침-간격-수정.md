# 정상부 시설 받침·간격 수정 — 산풍경

## 결과

코드 수정 완료, 실행·화면 검증 대기. 완료 기준인 전체 테스트 통과와 새 summit.png·junction.png 확인은 달성하지 못했다.

- 시설 기초를 외곽·경로 최대 고도 대신 **시설 중심 지면 + 8cm**로 배치한다.
- 받침 반경 안은 중심 높이로 절토·성토하고 바깥 3m에서 기존 지면에 부드럽게 연결한다. 높은 경사면도 낮출 수 있도록 기존의 높이 최댓값 제한을 제거했다. 레이돔 아래 지형 기둥도 이 처리 대상이다. 석축 메시를 추가하는 대신 지형을 다듬는 방식을 선택했다.
- 표지석 원통 받침은 지름 8m·높이 0.8m에서 지름 2.4m·높이 0.24m로 줄였다. 표지석 바닥과 글자 높이도 함께 내렸다.
- 정상 기준 상대 X/Z: 표지석 (-9,-6)m, 응진전 (-44,-8)m, 레이돔 (-48,-56)m. 표지석은 약 11m 앞, 큰 시설은 약 45m·74m 뒤로 보내고 좌우 방위를 벌렸다. 정상 300° 기준 응진전 약 280°, 표지석 약 304°, 레이돔 약 319°다.
- 갈림 표지판 기둥의 Z를 -0.2m로 옮겼다. 기둥 앞면(-0.13m)은 판 앞면(+0.04m)·글자(+0.045m)보다 뒤에 있다.
- 시설 모델은 기존 도형 종류·분할 수·LOD·재질·메시 수를 유지했다. 삼각형 수는 코드 구조상 동일하며, 기존 예산 검사도 유지했다. 실행 수치 확인은 대기다.
- 중심 고도·급경사 양쪽 절토/성토·외곽 연결·시설 앞뒤 간격 회귀 검사를 보강했다. 카메라 검사는 중심 기초 변경에 맞춰 시험 지형과 경로의 고도를 일치시켰다.

## 확인

- `git diff --check`: 통과.
- 기존 검수 summit.png를 확인했다. 기존 화면은 이번 결과 화면으로 첨부하지 않았다.
- npm test·build·preview·캡처: 미실행. 새 화면에서 단상·시설 중첩·레이돔 하부·표지판 글자 가림의 해소는 확정할 수 없다.
- 새 사본: `/private/tmp/gwanak-facilities-revision.XO5ej6` (`mktemp -d` 사용). .git·node_modules·dist·artifacts를 제외하고 복사했고 의존성은 원본 node_modules에 링크했다. 삭제·커밋·push는 하지 않았다.

## 가정

- 시설 위치·치수는 현장 실측 전 추정이며, 이번 상대 배치는 고정 검수 방위의 전망 여백을 확보하기 위한 시안이다.
- 지형을 다듬는 방법으로 기초 경사를 처리한다. 별도 바위 인스턴스가 새 화면에서도 시설과 겹치면 추가 조정이 필요하다.

## 대표 확인 필요

사용자와 랩 리드의 로컬 확인 허용은 확인했다. 다만 상위 개발 지시의 “스크립트 실행 같은 위험 작업은 하지 말고 … 그 명령을 남기세요”가 계속 적용되어 아래 명령은 실행하지 않았다. 이 제한 해제 후 사본에서 순서대로 실행해야 한다.

```sh
cd /private/tmp/gwanak-facilities-revision.XO5ej6
npm test
npm run build
npm run preview -- --port 5178 --strictPort
```

preview 실행 상태에서 별도 터미널:

```sh
cd /private/tmp/gwanak-facilities-revision.XO5ej6
BASE_URL=http://127.0.0.1:5178 node scripts/capture-summit-facilities.mjs
```

사본의 `artifacts/summit-facilities/summit.png`, `junction.png`, `results.json`을 확인해야 한다. 테스트의 시설 예산은 LOD별 30,000 / 6,000 / 1,200 미만, 최원거리 300 이하로 유지한다. 포트가 사용 중이면 다른 빈 포트를 선택하고 BASE_URL도 일치시킨다.
