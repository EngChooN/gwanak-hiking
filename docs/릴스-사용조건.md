# 인스타 릴스 — 소리·자료 사용 조건 (산리서치, 2026-11-11)

릴스는 게임을 홍보하고 AI Office도 알리는 영상이므로 **상업·홍보 용도로 보는 쪽을 기준**으로 판정했습니다.
근거는 이 저장소의 기존 출처 기록(`data/자료-출처-이용조건-기록표.md`, `public/sounds/CREDITS.md`, `public/environment/출처-이용조건.md`, `assets/radio/manifest.json`, 게임 안 「소리 출처」 화면)과 이번에 연 공식 페이지입니다.
**한계:** OpenGameArt·Freesound 곡이 정말 CC0인지는 이전 단계에서 작품 페이지로 확인한 기록을 믿었고 이번에 다시 열지 않았습니다. 법령·약관 해석은 법무 확인이 아닙니다(⚖️).

판정: ✅ 써도 됨(표기 불필요) / 🟡 표기 필요(써도 되지만 출처를 넣어야 함) / ⛔ 빼야 함 / ❓ 확인 필요

## 3. 배경음악 후보

먼저, 인스타 정책은 공식 도움말 페이지를 열지 못했고 음악 회사 블로그 요약만 확인했습니다(공식 아님). 요약: 비개인(비즈니스) 계정은 인스타 음원 중 상업 이용이 허용된 작은 라이브러리만 쓸 수 있다는 설명이 많습니다. **대표 계정이 개인/크리에이터/비즈니스 중 무엇인지에 따라 달라지므로 앱에서 직접 확인**이 필요합니다.

| 순위 | 후보 | 장점 | 조건·위험 |
|---|---|---|---|
| 1 | **게임 소리만** (발소리·바람·새·물소리, 뽕짝 없음) | 저작권 걱정 없음(§1의 CC0·자작). 기획서 기본안 | 심심할 수 있음. 능선 장면은 CC BY 크레딧 한 줄 |
| 2 | **인스타 자체 음원**(앱의 음악 넣기) | 영상 올릴 때 대표가 앱에서 고름. 우리가 음원 파일을 안 넣음 | 계정 종류에 따라 쓸 수 있는 곡이 다르고 홍보용(비즈니스) 계정은 목록이 제한됨. 곡이 나중에 빠질 수 있음. 곡은 업로드 시점에 대표가 고르므로 mp4에는 게임 소리만 넣어 둔다 |
| 3 | **Kevin MacLeod "Morning" 또는 "Fresh Air"** (이미 `assets/radio/919-calm/`에 있음) | 잔잔해서 풍경 장면과 잘 어울림. 상업 이용 가능 | CC BY 4.0 크레딧 필수(캡션에 §4 문구). 곡 페이지의 라이선스 줄은 아직 눈으로 확인하지 못함(§14 대표 확인 사항). 인스타에서 저작권 알림이 뜰 수 있음(Kevin MacLeod 안내: 크레딧을 설명에 넣으면 해결) |

추천: 1번을 기본으로 하고, 마지막에 대표가 인스타 앱에서 2번을 얹을지 판단. 3번은 곡을 쓴다면 40초 영상의 30% 이내로 낮은 볼륨.

## 5. 대표가 확인·결정할 것

1. **Open-Meteo:** 홍보 영상에 날씨 HUD 수치를 보이게 둘지(위험 수용) / 가릴지 / 문의할지.
2. **Copernicus:** ESA 이용허가서 PDF를 사람이 열어 상업 이용 조항 확인(제가 읽을 수 있는 형태가 아니었음).
3. **인스타 계정 종류와 음악:** 앱에서 개인/비즈니스 중 무엇인지, 쓸 수 있는 음원 목록은 업로드 때 확인.
4. **Kevin MacLeod 곡 페이지 라이선스 줄** 눈으로 한 번 확인(3번 후보를 쓸 때만).
5. 능선 바위 발소리 크레딧을 넣을지, 해당 장면을 짧게 쓸지.
