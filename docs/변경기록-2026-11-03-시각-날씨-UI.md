## 구성 (main.js는 수정하지 않음)
`setupRendering()`(rendering.js)이 시각·날씨·입자·HUD를 스스로 연결해서, 산개발이 main.js에 넣을 줄은 **없다**. main.js는 이미 `hiking:state` 이벤트를 내보내고 `#sit`·`#tea` 클릭을 command로 연결하고 있어 그대로 맞물린다.

| 파일 | 역할 |
|---|---|
| `src/daytime.js` | 서울 시각→태양·달 고도/방위(NOAA 저정밀식), 고도별 하늘·빛 키프레임, 시각×날씨 합성(`composeEnvironment`) |
| `src/weather.js` | Open-Meteo 호출(10분·8초 시간초과·1시간 넘은 값 폐기), WMO 코드→6단계, 표현값, 풍속→바람 소리 세기, 수동 지정, 실패·오프라인→맑음 |
| `src/environment.js` | 시각+날씨 목표값을 프레임마다 2.5초 시정수로 따라가는 보관소(`hiking:environment` 이벤트) |
| `src/precipitation.js` | 비(선분 7000)·눈(점 4500) GPU 입자, 드로콜 2개 |
| `src/weather-sound.js` | 빗소리(분홍잡음 절차 생성, 파일·저작권 없음). 환경음 버스에 붙음 |
| `src/hud.js` | 앉기/일어나기·차 마시기·달리기 버튼, 스테미너 막대, 시각·날씨 칩, 하단 출처 줄 |
| `src/sky-dome.js` | 구름량·구름색, 별, 달 원반, 서울 야경 불빛 알갱이·불빛 번짐, 태양 글로 세기 uniform |
| `src/rendering.js` | 방향광(태양↔달)·환경광·노출·연무색·fog 밀도 적용, MeshBasic 재질(나무·원경 도시 3만여 개) 밝기 보정 |
| `src/look-profile.js` | 연무 셰이더에 날씨 감쇠 항(`fog.near` 칸에 계수를 실음). 값 0이면 기존과 동일 |
| `src/ambient-config.js`·`ambient-audio.js` | 바람 소리 세기(숲·능선 층 dB 이동), 비에 새소리 감소, 빗소리 층 연결 |
| `assets/realistic/skyline-reference.js` | 원경 도시 대기 감쇠에 같은 날씨 감쇠 항 추가 |

## 사용법
- 기본: 서울 현재 시각 + 10분마다 실제 날씨. 실패·오프라인이면 맑음.
- `?time=HH:MM` 시각 고정(서울 오늘 날짜), `?weather=rain|snow|fog|cloudy|overcast|clear`, `&level=light|medium|heavy`, `&wind=m/s`.
- `?sun=am|pm`은 예전 고정 태양 그대로(`?time`이 있으면 `?time` 우선).
- 낮 맑음(고도 25° 이상)은 이전 기준값과 같다. 환경광 굽기·노출 보정은 낮 기준으로 한 번만 한다.

## 표현값 요약
산리서치 `docs/실시간날씨-기준.md` §6의 표를 그대로 코드로 옮겼다(맑음 연무 15km, 비 약/보통/강 4000/2500/1200m, 눈 4000/2500/1000m, 안개 400/200m, 직사광 1.0/0.75/0.3/0.15/0.25/0.1). 비 입자는 0.3/0.6/1.0 비율.

## 한계·후속
- 실제 날씨 API는 이 환경에서 수동 지정으로만 장면을 확인했다. 단위 테스트는 가짜 fetch로 검증. 실호출 응답 형식은 산리서치가 확인한 값 기준.
- 환경광 PMREM은 낮 기준으로 한 번만 굽는다(밤·노을은 강도·색만 조절). 하늘색에 맞춘 재굽기는 하지 않았다.
- 서울 야경은 하늘 셰이더의 불빛 알갱이·번짐이다. 원경 건물 창문 발광은 없다.
- 달 위상은 원반 밝기만 반영하고 초승·그믐 모양은 그리지 않는다(저정밀 월력, 오차 수 도).
- 나무 등 MeshBasic 재질은 구워진 낮 조명이라 색 배율로만 어둡게 한다. 노을 방향별 음영은 없다.
- 구름은 하늘 셰이더의 2D 노이즈다. 비 입자는 지붕·나무 아래 가림, 바닥 튀김을 표현하지 않는다.
- 시간 경과로 태양이 움직이는 것은 실시간(초 단위)이며 가속 기능은 없다.
- Open-Meteo 무료 API는 비상업 전용(산리서치 문서). 출처 문구는 하단 줄·조작 안내에 표기했다.
- 개발 서버 콘솔에 404 한 건이 있는 경우가 있으나(이 변경과 무관한 정적 리소스) 화면 동작에 영향은 없다.
