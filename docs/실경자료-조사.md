## 2. 지형 (DEM·등고선)
- 현재 게임은 Copernicus 30m(기획서 기재)입니다. 더 촘촘한 자료 후보는 국토지리정보원 공개 DEM입니다.
- 확인된 사실
  - 공공데이터포털 파일데이터 15059920: 제공 URL이 국토정보맵(map.ngii.go.kr), 다운로드는 **로그인 필요**, 공간정보 소프트웨어(지리OneView 등)나 CAD가 필요합니다 ⚠️(검색 요약).
  - **5m 해상도 제품인지, 좌표계, 출처표시 문구는 여전히 확인하지 못했습니다.** 기존 기록표(2025-06-17 수정)의 "이용허락 제한 없음"은 공공누리 유형이 아닙니다.
- 대표 확인 필요(로그인·가입): 국토정보플랫폼 계정이 있으면 관악산 도엽을 직접 받아 해상도를 확인하는 것이 가장 빠릅니다. 계정이 없으면 가입이 필요합니다(내가 하지 않음).
- 제안: 1:5000 등고선(수치지도)도 같은 플랫폼에서 받으므로 한 번의 로그인으로 DEM과 함께 확인하세요.
- 사용 금지: 같은 포털의 "국토연구원_국토 지도 정보"는 4유형(상업·변경 금지)이라 쓰지 않습니다(기록표).

## 3. 정사영상 (VWorld 등)
- 이용 약관 원문을 열람하지 못했습니다(이전 조사에서 404/스크립트 렌더링, 이번 검색에서도 약관이 잡히지 않음).
- 확인된 사실: 국토교통부 WMTS/TMS API는 data.go.kr에 무료로 올라 있고 **인증키 발급 후 사용**, 이용 신청은 PC 버전만 가능 ⚠️.
- **"타일을 받아 3D 지형 텍스처로 구워 웹 게임에 넣어도 되는가"는 약관과 공공누리 표시에 달려 있습니다.** 확인 전까지 내려받거나 게임에 넣지 마세요.
- 대표 확인 필요: VWorld 이용약관의 저장·가공·재배포·출처표시 조항을 브라우저로 읽어 판정(사람이 읽어야 함), 또는 VWorld 문의.

## 4. 식생 (산림청 임상도)
- 임상도는 **1:25,000**이고 속성에 임종(천연·인공), 임상(활엽·침엽·혼효), 주요 수종, 수관밀도, 영급, 경급이 있습니다 ✅(공공데이터포털 메타데이터 요약). 코스 폭(수십 m) 규모의 구간별 수종 분포를 구분하기엔 거칩니다.
- 1:5000 임상도는 찾지 못했습니다. 산림청에 문의가 필요합니다.
- 관악산 학술 요약(국회도서관, 1972~2010): 신갈나무 단계 유지, 소나무→신갈나무 이행 예측, 상수리→졸참, 때죽·팥배나무 증가 ✅(검색 요약, 원문 미열람).
- 하층 식생(조릿대·억새·고사리)·암릉 구간 차이·계절 모습은 **자료를 찾지 못했습니다**(후기에 수종 서술이 거의 없음, `관악산-체감자료-구간별.md` §0). 현장 촬영이나 식물 도감·산림청 식물 자료 별도 조사가 필요합니다.
- 진달래·철쭉은 인접 산(북한산·팔공산) 연구에서 능선 관목으로 보고됨 ⚠️. 관악산 자체 분포는 확인 못 함.

## 2-3. 임상도 15159371 이용허락 — 데이터셋 번호가 임상도가 아님
- `data.go.kr/data/15159371/fileData.do`를 읽으니 **"경상남도 함양군_산림보호구역 연속주제도"**(SHP, 이용허락범위 제한 없음, 수정 2026-05-12)였습니다. **산림청 임상도가 아닙니다.** 앞 절 §4·§9에 적은 15159371은 번호 오기로 보이며, 이 번호의 이용허락은 관악산 식생과 무관합니다.
- 산림청 임상도의 이용허락은 **여전히 미확인**입니다. 산림공간정보서비스(map.forest.go.kr)·forest.go.kr은 본문이 비어 읽지 못했습니다(공공누리 표시 미확인).
- 해야 할 것: data.go.kr에서 "산림청 임상도"로 직접 검색해 올바른 데이터셋 번호와 이용허락범위를 확인하고, 산림공간정보서비스의 임상도 이용 안내를 브라우저로 확인(사람). 그때까지 임상도 원자료는 **게임 에셋에 직접 쓰지 않고 수종 비율 참고에만** 사용(현재 6:4 조정은 추정치).
