# 변경 기록 — 등산 수첩 HUD (2026-11-06, 산개발)

- 기준: `docs/UI-등산수첩-사양.md`, `artifacts/ui-concepts/등산수첩-상세.html`
- 범위: HUD의 HTML·CSS·JS와 대화창. 게임 로직·3D는 바꾸지 않았다(아래 '게임 쪽 작은 변경' 제외).
- 커밋·배포 없음.

## 바뀐 것

### 새 파일
- `src/hud-notebook.js` — 책갈피 탭·종이 시트·빨간 도장·상황 꼬리표·시간대 색. main.js와는 window 이벤트로만 만난다.
  - 읽기: `hiking:state`, `hiking:environment`(해 높이 → 낮·노을·밤), `hiking:interact-view`, `hiking:action-view`
  - 쓰기: `hiking:command`(interact·choice-2·choice-3·sit·auto·stretch·labels-toggle·card-open), `hiking:quality`
  - 순수 함수(`timeOfDay`, `stampFor`, `stampView`, `contextView`, `checkpointTicks`, `formatRemainKm`, `qualityModeFromText`)는 단위 테스트로 묶었다.
- `src/hud-notebook.css` — 색 토큰(낮·노을·밤), 휴대폰 가로(높이 540 이하)·세로·PC 세 배치.
- `scripts/capture-notebook-hud.mjs` — 세 화면 × 낮·밤 × 펼침 화면 촬영과 자동 검사(겹침·화면 밖·44px 미만·글자 잘림·콘솔 오류, 펼친 시트·대화창 버튼이 다른 요소에 덮이는지).
- `scripts/measure-notebook-hud.mjs` — 같은 장면에서 HUD 보이기/숨기기를 번갈아 fps·레이아웃·스타일 재계산을 잰다.
- `tests/hud-notebook.test.mjs` — 도장 우선순위·도장 모양·상황 꼬리표·진행 눈금·화질 글자, 지킬 조건(일시정지 없음·기능 버튼 id·구간 이동 개발용 칸).

### 고친 파일
- `index.html` — 진행 카드·책갈피 탭·도장·칩·꼬리표·시트(배낭·쉬기·설정) 구조. 기존 버튼 id는 모두 유지. 로딩 화면은 밤 크라프트 종이 톤.
- `src/style.css` — 바탕 규칙만 남기고 HUD 배치·색은 `hud-notebook.css`로 옮김(`--u` 비례 변수는 상호작용·기구 화면용으로 유지).
- `src/interaction-ui.js` — 세상 속 상호작용 줄은 도장(첫 줄)·상황 꼬리표(나머지 줄)로 넘기고, 휴대폰 화면 안 줄만 직접 그린다. `.ix-quick`(▣·✦)은 탭으로 대신해 없앰.
- `src/section-jump.js` — 구간 이동을 설정 탭 '개발용' 점선 칸 + 목록 시트로. 그 칸이 없으면 예전 자리.
- `src/hud-toggle.js` — 숨김 뒤 남는 버튼을 `👁 화면 보이기 H` 꼬리표로.
- `src/city-grid.js` — OSM 출처를 화면 아래 출처 한 줄(`#source-line`)에 붙임.
- `src/environment.js` — 시간대 색을 위해 해 높이(`sunElevation`)를 함께 보냄.
- `src/hud-v2.css`, `src/interaction-ui.css`, `src/multi-ui.css`, `src/rest-ui.css`, `src/section-jump.css` — 종이 톤으로 맞춤.

### 게임 쪽 작은 변경
- `src/main.js` — 멈춰 서 있을 때 상태 글자를 `쉬는 중` → `서 있음`(사양 4절. 앉아 있을 때는 그대로 `앉아서 쉬는 중`).

### 복장 고르기 삭제 (같은 작업 트리, 의도한 삭제)
대표 지시(2026-11-06 "복장고르기도 지우자 이제 안쓰는데"). 카툰 캐릭터 동동이 한 벌만 쓰고 선택 화면은 이미 꺼져 있었다.
- 지운 파일: `src/outfit-picker.js`, `src/outfit-picker.css`, `src/outfit-config.js`, `src/hiker-outfits.js`, `tests/outfits.test.mjs`, `scripts/capture-outfits.mjs`, `scripts/capture-outfit-compare.mjs`, `scripts/capture-gadget-fix.mjs`
- 정리: `main.js`(선택 화면·지도 복장 메뉴·`hiking.outfit/setOutfit/outfitPreviews`), `multi-client.js`(복장 번호 주고받기), `loading-screen.js`, `toon/link-hiker.js`(`dressable`), 사양서의 복장 항목.
- 다른 캡처 스크립트 주소의 `outfit=N`은 이제 무시되는 값이라 그대로 둠.
