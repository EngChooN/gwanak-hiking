# 경치 보강 후속 — 산풍경

산기획 요청: 서울 전망 가림, 11월 풀·숲 바닥, 평평한 포장길을 수정한다. 기준 화면은 `artifacts/scenery-final-after-*.png`이며 원본을 보존했다.

## 구현

- `assets/realistic/load-landscape.js`: 정상 표지석으로부터 정상 기준점을 복원하고 북측 85m·남쪽 경계 8m 안의 장식 바위 배율을 기존의 18%로 낮춘다. 모든 LOD가 같은 변환을 쓴다. 기존 지면 접지와 시설 반경 보호를 거친다. DSM 지형은 바꾸지 않는다.
- `assets/realistic/summit-config.js`: 레이돔은 정상 기준 (-18,+52)m의 남측으로 옮긴다. 흰 구체는 연주대 응진전이 아닌 기상레이더 관측소 레이돔이다. 정체 확인 출처: [기상청 기상레이더센터 안내](https://radar.kma.go.kr/book.pdf). 위치는 현장 실측값이 아닌 전망 보호용 시안으로 명시했다. 응진전 후보 선택·표지석·갈림 시설은 유지한다.
- `assets/realistic/generated/nature/forest-layers.js`: 풀 HSL 색은 sRGB 기준 색상 .105~.20, 채도 .22~.35로 황록·갈색을 섞는다. 높이·밀도·바람·LOD는 유지한다. 기존 낙엽 텍스처의 갈색 혼합과 이끼 패치를 강화해 근경의 맨 모래색 면적을 줄인다.
- `assets/realistic/terrain-material.js`: 포장길에 기존 돌 PBR 색/노멀을 골재로 활용한다. 저채도 회색, 미세 입자·색 변화와 길 양측의 낙엽 퇴적, 불규칙한 알파 경계를 적용한다. 새 외부 텍스처·메시는 추가하지 않는다. GPU 첫 검수에서 발견한 GLSL 예약어 `patch`는 `edgePatch`로 교정했다.

## 검증

- `npm test`: 123개 전체 통과, 실패 0. 기존 하늘·간접광 실패는 이번 작업 시작 시 이미 재현되지 않았다. 해당 소스·검사는 수정하지 않았다.
- 시설 검사는 레이돔이 북·북동 절두체 밖에 있는지, 응진전 후보와 시설 기초·간격을 유지하는지 확인하도록 변경했다. 풀 검사는 봄 녹색 대신 황록·갈색 범위와 낮은 채도를 확인한다.
- `npm run build`: 통과. 기존 500kB 청크 크기 경고가 남는다.
- `git diff --check`: 통과.
- `scripts/capture-scenery-final.mjs`: 높음 1440×900·DPR1, 준비 후 9초 대기·10초 프레임 집계. 7개 경치 시점과 3인칭 보행을 순차 측정한다. 3인칭은 걷기 시작 2초 뒤부터 측정한다. 시점별 진행 로그를 보강했다.
- 최종 캡처는 `artifacts/scenery-final-review-*.png/.json`, 원본 비교 화면은 `artifacts/scenery-final-after-*.png/.json`이다. `scripts/report-scenery-followup.mjs`는 전후 경로 거리·방위·시점 일치, 페이지·셰이더 오류 0, 높음 4시점 45fps 이상·3인칭 40fps 이상을 검사하고 HTML 보고서를 만든다.
- 최종 fps는 `artifacts/scenery-followup-validation.json`과 `artifacts/경치-후속수정-7시점-비교.html`을 참조한다.

## 최종 실측

입구 51.94, 계곡 53.82, 능선 54.23, 정상 54.02fps로 높음 4시점 기준을 통과했다. 북 54.02·북동 54.12·서 52.54fps이며 화면을 직접 열어 장식 바위·레이돔이 시가지 전망을 가리지 않는 것을 확인했다. 기존 숲의 나무는 서쪽 전망 주변에 남아 있다. 3인칭 보행 59.50fps로 기준을 통과했다. 8개 캡처 모두 페이지·셰이더 오류 0이며 전후 시점 일치 검사·보고서 생성도 통과했다.

## 범위와 한계

등산객·걷기 관련 소스는 수정하지 않았다. push·배포·삭제는 하지 않았다. 기존 공유 작업 변경을 되돌리지 않았다. 현장 시설 좌표·치수, 관악산 11월 식생 분포·색은 실측 전이며 이번 배치는 시각 검수용이다. 성능은 이 Mac의 해당 시점 실측이며 모든 기기에 대한 보장은 아니다.
