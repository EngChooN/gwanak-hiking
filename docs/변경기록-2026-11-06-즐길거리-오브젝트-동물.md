# 변경 기록 — 즐길거리 오브젝트·동물을 게임에 넣기 (2026-11-06, 산풍경)

상위 업무: 자동걷기 즐길거리 5종 구현(산기획) 1/4단계. 기준은 `docs/기획-2026-11-06-자동걷기-즐길거리.md`와 시안 `src/toon/props-concepts.js`입니다.

## 무엇을 했나

### 1. 형상 모듈 `src/toon/trail-props.js`
- 시안의 산스장·벤치·먼지털이기·다람쥐·산고양이·까치와 손 소품(초콜릿·역기·에어건)·효과(하트·땀·흙먼지·반짝이·영혼)를 옮겼습니다.
- 시안 페이지(`props-concepts.js`)도 이 파일을 import해서, 형상은 한 벌만 있습니다.
- 텍스처 없이 단색 + 툰 재질입니다. 글자판 3장(간판·"20"·에어건 안내판)만 작은 캔버스 글자를 씁니다.
- 종류마다 원형을 한 번 만들고 `clone(true)`로 형상·재질을 나눠 씁니다.

자리는 `TRAIL_PROPS`·`CAT_SPOTS`·`TRAIL_RULES`에 모았고, 모두 게임 속 배치(`est`)입니다.

|---|---|---|
| 산스장 | 팔각정(2,392m) 근처 2,320~2,480m에서 가장 평평한 곳 → 2,416m, 길 오른쪽 6m 남짓 | 0.32m |
| 벤치 | 1,552m · 1,692m · 2,148m | 0.13 · 0.07 · 0.03m |
| 벤치(깔딱고개 앞) | 3,639m(나무계단 시작 전) | 0.22m |
| 벤치(깔딱고개 뒤) | 4,513m(계단을 다 오른 뒤 연주암 갈림길 근처). 계단 끝 4,425m 둘레는 0.54m 차이라 피했습니다 | 0.03m |
| 먼지털이기 | 일주문 안쪽 광장 왼편(일주문 기준 x −5, z 9.8) | 0 |

- 모든 소품은 노면 밖에 두고, 정면이 길을 보게 했습니다. 벤치는 높은 다리에 맞추고, 낮은 쪽 다리 밑은 받침돌로 채웁니다.
- 먼지털이기는 처음에 일주문 바로 옆에 두려 했습니다. 그런데 화분(일주문 기준 −4.1, 3.2)과 기둥에 가려지고, 문 바깥은 덤불이었습니다. 그래서 광장 안 트인 곳으로 옮겼습니다.
- 나무·풀·숲 바닥 덤불은 소품 둘레를 비웁니다. 고친 파일은 `load-landscape.js`, `grass-field.js`, `forest-layers.js`입니다.
- 모형은 가까이 갈 때(260m 안, 200m 청크 바로 옆까지)만 만들고, 340m 밖으로 멀어지면 뗍니다.

### 3. 동동이 동작 `src/toon/hiker-acts.js` (link-hiker 뼈대)
시안의 팔·다리 각도를 목표점으로 바꿔 두 관절 IK로 풉니다. 등산객 코드의 자세 위에 섞어(blend) 덮습니다.

| 동작 | 내용 |
|---|---|
| 벤치 앉기 | 다리를 달랑달랑 흔들고, 배낭은 옆에 내려놓습니다. 1초 뒤 영혼이 나와 "후우… (영혼 휴식 중)" 하고, 일어나면 쏙 들어갑니다. 30%는 고양이가 옆자리에 옵니다 |
| 시멘트 역기 | 역기를 머리로 들고, 모자가 눌리고, 실눈을 뜹니다. 들어 올릴 때마다 땀이 나고, 10회면 "득근!!"입니다 |
| 거꾸리 | 판이 돌아 거꾸로 매달립니다. 모자가 땅에 툭 떨어지고 볼이 빨개집니다. 내려오면 모자를 다시 씁니다 |
| 허리돌리기 | 돌림판과 함께 세 바퀴 돈 뒤 2초 동안 비틀거립니다(조작은 그대로 받습니다) |
| 철봉 | 뛰어올라 매달리고 다리를 버둥거립니다. "발이… 안 닿아…!" |
| 에어건 | 에어건을 신발에 대면 흙먼지가 펑 터집니다("치이이익—!!!"). 모자가 날아갔다가("내 모자!!") 2초 뒤 머리 위로 툭 떨어지고, 신발이 반짝입니다 |
| 초콜릿 | 1.2초 동안 손을 입으로 가져갑니다. 효과가 있는 30초 동안 입가에 초콜릿이 묻고, 걸을 때 뒤에 흰 바람 줄이 생기고 발밑에 흙먼지가 입니다 |
| 고양이 쓰다듬기 | 웅크려 쓰다듬으면 고양이가 배를 보이고 하트가 뜹니다("골골골…"). 3초 뒤 냥펀치("앗!")를 날리고 도망갑니다 |

- **모자·배낭 분리:** 모자·배낭은 `link-hiker.js`에서 따로 된 메시(`ToonHiker_Hat`·`ToonHiker_Pack`)로 나눴습니다. 동작 중에는 같은 형상의 단단한 사본을 움직입니다.
- **바인드 자세·얼굴 자리:** `scene.userData.restPose`·`face`에 남깁니다.

### 4. 동물과 들르기 `src/trail-world.js`
**동물 행동**
- **다람쥐:** 3m 안에 들어오면 도토리를 들고 쳐다봅니다. 5초 동안 가만히 있으면 모자 위로 올라와 "여기 내 자리"라고 하고, 동동이는 "…무거워" 하며 고개를 숙입니다. 걸으면 뛰어내려 도망갑니다.
- **고양이:** 4m 안에 들어오면 고개를 돌려 쳐다봅니다. 쓰다듬기와 벤치 옆자리는 위 동작대로입니다.
- **까치:** 땅에서 콕콕 쪼다가, 4m 안에 들어오면 날아올라 원을 그립니다. 가끔(35%) 배낭 위에 앉아 20초 동안 같이 갑니다.

**동시에 나오는 수**
- 동시에 최대 3마리입니다(`device-profile.js`의 `trailAnimals`).
- 가까운 순으로 45m 안에서 나오고, 60m 밖으로 멀어지면 사라집니다.

**효과음:** 찍찍·야옹·깍깍·치익 소리를 WebAudio로 만들었습니다. 외부 파일을 쓰지 않아 출처를 적을 자료가 없습니다.

**말풍선**
- 한 번에 하나만, 1.2~2.8초 동안 뜹니다.
- z-index는 20입니다. HUD(5~7)보다 위, 알림(32·33)보다 아래입니다.

**들르기 흐름**
1. 소품·고양이의 6m 안에 들어오면 `hiking:trail-offer` 이벤트를 보냅니다. 한 번 지나갈 때 한 번만 보내고, 12m 넘게 멀어지면 다시 보낼 수 있습니다.
2. `hiking:command {id:'trail-play', value:{act,id}}`를 받으면 그 자리로 걸어가서(1.3m/s) 동작합니다.
3. 동작이 끝나면 원래 자리로 걸어 돌아와, 자동걷기였으면 다시 켭니다.
4. 걷기 입력이 들어오면 그만두고 돌아옵니다.

**앉기 버튼:** 벤치 2m 안에서 누르면 벤치에 앉고, 다시 누르면 일어납니다. 바꾼 곳은 `main.js` 한 줄입니다.

**main.js 연결(작게)**
- 들른 동안에는 `trail.override()`가 몸 자리·방향·걷는 위상을 줍니다. `ground()` 뒤에 `trail.update()`와 `afterGround()`를 부릅니다.
- 검수용 고정 카메라 `hiking.cameraOverride`를 더했습니다.

## 작업 중 고친 것
- **스틱:** 동작 중 숨겨야 할 등산 스틱이 보였습니다. `visible`에 `undefined`가 들어갔기 때문이고, `false`로 고쳤습니다.
- **손 소품 위치:** 초콜릿·에어건·호스가 손에서 1m 떨어져 있었습니다. 방향 벡터를 정규화해서 생긴 문제라 고쳤습니다.
- **거꾸리 말풍선:** 거꾸로 매달릴 때 말풍선이 땅에 박혔습니다. 동작 자세가 정해진 뒤에 자리를 잡게 했습니다.
- **산스장 덤불:** 산스장이 숲 바닥 덤불에 묻혔습니다. `forest-layers` 비우기 목록에 자리를 넣었습니다.
- **철봉:** 매달린 몸이 훌라후프와 겹쳐서, 매달리는 자리를 옆으로 옮겼습니다.
- **까치:** 배낭에 앉은 까치가 날개를 편 채였습니다. 앉은 모습으로 바꿨습니다.
- **역기:** 빠르게 연타하면 득근 횟수가 10을 넘었습니다. 10에서 멈추게 했습니다.

## 남은 일(다른 단계·담당)
- **HUD(산개발):** 아래 화면과 규칙은 이번 범위가 아닙니다. 이벤트·명령은 위 "들르기 흐름"대로 연결하면 됩니다.
  - 들르기 버튼(4초), 역기 연타 버튼(`trail-press`)
  - 🍫 칩과 먹기 버튼(`chocolate` 명령), ⚡ 남은 시간 칩
  - 실제 이동 속도 +20%, 벤치 스테미너 1.5배
  - "산스장 득근" 도장, "깨끗한 신발" 칸
- **까치 횃대:** 까치는 나뭇가지가 아니라 땅에 앉습니다. 숲 나무의 가지 좌표가 없어서입니다. 가지에 앉히려면 나무 배치에서 가지 높이를 받아야 합니다.
- **⑥ 헥헥·쥐:** 이 카드 범위 밖이라 만들지 않았습니다.
- **먼지털이기 실물 확인:** 관악산공원 입구에 실제로 먼지털이기가 있는지는 확인하지 못했습니다(산리서치).
