# 입구·구간 풍경 통합 (4/4단계)

2026-11-03 · 산개발 · /Users/pc-2311001/gwanak-hiking

실시간 날씨·스틱·앉기·달리기 통합 뒤, 산풍경의 일주문·입구 광장·구간 보정을 이동 규칙과 합쳤다. 입구 위치는 가설 B(대표 로드뷰 확인값)를 쓴다. 현장 실측은 아직 하지 않았다.

## 변경

- **출발 방향**: 입구 출발점(37.468378, 126.946067)의 시작 방향은 132°이고, 일주문 방위는 131.7°다(약 30m 앞). 1인칭·3인칭 모두 화면 가운데에 일주문이 보인다. 테스트로 오차 2° 이내를 확인한다.
- **출발 위치 선택**: 지도(M) 창에 `입구 일주문에서 시작`과 `545m 구간에서 시작` 버튼을 넣었다. 둘 다 진행 기록을 새로 시작하고 주소의 `?start=`를 지운 뒤 다시 읽는다. 처음 열 때 시작점은 545m 구간 그대로다(기존 측정·저장과의 호환을 위해). `?start=entrance`도 계속 쓸 수 있다. README 안내도 고쳤다.
- **일주문 충돌**: `src/entrance-config.js`의 `gateObstacles`
  - 기둥 2개: x ±3.05m, 반경 0.56m(돌 받침 기준)
  - 바리케이드 4개: 0.8×0.7m
  - `assets/realistic/entrance-scenery.js`도 같은 상수로 모델을 배치하므로, 모양과 충돌 위치가 따로 어긋나지 않는다.
- **이동 규칙**: `route.js`의 `blockedByGate`가 월드 좌표를 일주문 좌표로 바꾸고, 몸 반경 0.25m로 검사한다. `movement.js`는 이동 선분을 4등분해 검사한다.
  - 길 안이든 길 밖이든 막는다.
  - 막히면 앞뒤나 좌우 중 한 방향만 남겨 미끄러진다. 두 방향 모두 막히면 멈추고 걷지 않을 때처럼 스테미너를 회복한다.
  - 가운데 통로(약 1m)는 열려 있다. 자동 걷기는 이 통로로 GPX 0m를 넘는다.
