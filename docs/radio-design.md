# 라디오 설계 — 자체 방송국 "관악산 FM" (2026-11-08, 산디자인)

대표 결정: 방송사에 허락 문의를 하지 않는다. 근거·출처·이용 조건은 `docs/radio-options.md`(산리서치). 이 문서는 **화면·동작·멘트·크레딧 위치**를 정하고, 산개발이 바로 구현할 수 있게 규칙을 적는다. 코드는 바꾸지 않았다.
이미 정한 기기 설계(전원 스위치, 끌어서 돌리는 다이얼, 볼륨 노브, 라디오를 내려도 소리 계속·HUD에 `📻 91.9` 칩만 남음)는 그대로 둔다.

## 0. 구현 규칙 (radio-options.md §4 그대로 — 어기면 안 됨)

1. **앱 코드는 외부 주소에 접속하지 않는다.** `fetch`·`<audio src>`·`<iframe>`·WebSocket 어느 것으로도 방송사 주소를 부르지 않는다. `STATIONS`(실제 방송 재생용)는 **계속 빈 배열**이다. AGENTS.md §5 "런타임 외부 접속 없음"은 그대로다.
2. **외부 링크는 사용자가 누르는 하이퍼링크뿐**이다: `<a href target="_blank" rel="noopener noreferrer">`. 앱이 소리를 틀거나 화면에 끼워 넣지 않는다(iframe 금지). 방송사 로고·이미지는 쓰지 않고 **글자 이름만** 쓴다.
3. **링크 주소는 `src/radio-stations.js` 한곳에만 둔다**(`EXTERNAL_LINKS`). 다른 파일에 `https://…` 방송사 주소를 적지 않는다. 테스트가 `src/`를 훑어 이 파일 밖의 방송사 주소를 막는다(§8).
4. **음악·소리 파일은 우리 서버(같은 출처, `public/radio/…`)에서만 받는다.** CC0·CC-BY 곡만, 곡마다 `data/자료-출처-이용조건-기록표.md`에 한 줄(라이선스 페이지 주소·확인일) 적은 뒤에 올린다. NC·SA·ND·FMA-Limited·Pixabay 원본 직접 제공은 쓰지 않는다.
5. **음성(95.5 멘트)은 직접 녹음 파일만** 쓴다. 브라우저 합성음성(`speechSynthesis`)·외부 TTS 서비스는 쓰지 않는다(약관·외부 접속 문제). 녹음 전에는 자막(글)만 나온다(§5).
6. 방송 코드 `CANDIDATES`(허락 문의 후보)는 문의하지 않으므로 **삭제**한다.
7. 모든 기능은 HUD 버튼으로도 된다(키보드 없음). 버튼은 44px 이상, 안전 영역 안. 일시정지 개념 없음 — 라디오는 켜짐/꺼짐만 있다.

## 1. 채널 (가상 주파수)

다이얼 눈금 87.5~108.0 MHz(`FREQ_MIN`·`FREQ_MAX` 유지), 눈금 간격 0.1.

| 주파수 | 채널 이름(표시창) | 내용 | 출처 |
|---|---|---|---|
| **91.9** | 관악산 FM · 잔잔한 음악 | CC0·CC-BY 환경음악·어쿠스틱 6~10곡 순환 | Kevin MacLeod, OpenGameArt 등(곡별 확인) |
| **95.5** | 관악산 FM · 산 날씨·등산 안내 | 게임 안 날씨·시각·계절·위치에 맞춘 자작 멘트(§5) + 징글 | 자작(직접 녹음, 징글은 `scripts/`로 합성 CC0) |
| **99.1** | 관악산 FM · 숲과 바람 | 바람·새·계곡물 루프를 길게 이어 방송처럼 흘림 | Freesound CC0 (BY가 섞이면 크레딧 표기) |

이 3개가 아닌 주파수는 방송이 없다(잡음만). 같은 숫자가 실제 방송과 겹치는 것(91.9·95.5·99.1 등)은 게임 속 가상 주파수일 뿐이고, 화면 어디에도 실제 방송사 이름과 연결해 쓰지 않는다.

## 2. 화면 구성

라디오 기기는 수첩 종이 톤(`--paper`·`--ink`·`--edge`, 낮/노을/밤 `data-hud-time`)을 따른다. 아래는 앞면·뒷면·HUD 칩이다.

### 2-1. 앞면 (기본)

```
┌──────────────────────────────┐
│ ● ON            관악산 FM  ⟲ │  ← 전원 스위치(좌) · 이름 · 뒷면 보기(⟲, 44px)
│ ┌──────────────────────────┐ │
│ │   95.5 MHz               │ │  ← 표시창: 주파수(크게) / 채널 이름 / 상태 글자
│ │   산 날씨·등산 안내       │ │
│ │   ▮▮▮▮▯ 수신 좋음         │ │  ← 수신 막대 5칸 + 글자(색에만 의존 안 함)
│ └──────────────────────────┘ │
│ 87.5 ·|·|·|·|▲|·|·|·|·|· 108 │  ← 눈금 다이얼(끌어서 돌림). 방송 3곳에 작은 ◆ 표시
│ [◀ 0.1] [91.9][95.5][99.1] [0.1 ▶] │ ← 미세 조정·채널 바로가기(버튼으로도 모두 가능)
│ 볼륨 (노브)         [♪ 곡 정보] │ ← 볼륨 노브 / 현재 곡·크레딧 칸(§6)
│                       [내리기 ✕]│
└──────────────────────────────┘
```

- 다이얼: 손가락으로 좌우로 끌면 주파수가 연속으로 바뀌고 0.1 칸마다 짧은 틱(소리 아주 작게). 방송 주파수 ±0.1 안에서는 눈금이 **자석처럼 붙는다**(스냅).
- 버튼: `◀`·`▶`는 0.1씩, 길게 누르면 반복. `91.9·95.5·99.1`은 바로 가기. 전원이 꺼져 있으면 전부 흐리게(눌러도 반응 없음, 전원부터 켜라는 힌트 `전원을 켜 보세요` 한 줄).
- 표시창 글자: 방송 중 = 주파수 + 채널 이름 / 잡음 = 주파수 + `수신 불량…` / 꺼짐 = 빈 창(불빛 꺼짐).
- 95.5 수신 중에는 표시창 아래에 **자막 줄**(방금 멘트 글, 최대 2줄)이 뜬다. 소리를 끈 사람도 읽을 수 있다.
- 크기: 휴대폰 세로 390px 폭에서 폭 min(92vw, 340px). 가로 844×390에서는 높이가 모자라므로 곡 정보 칸을 한 줄로 줄이고 다이얼·버튼을 한 줄에 둔다. PC는 폭 360px, 화면 좌하단 쪽.
- 밤 톤(`night`): 종이 바탕이 어두워지고 표시창은 노란 불빛(호박색 글자), 낮은 어두운 갈색 글자.

### 2-2. 뒷면 (⟲ 누르면 뒤집힘)

```
┌──────────────────────────────┐
│ ← 앞면으로                    │
│ 실제 방송 듣기                │
│ ┌──────────────────────────┐ │
│ │ CBS 음악FM          ↗    │ │  ← 글자 이름만, 로고 없음. 44px 이상 줄
│ │ CBS 표준FM          ↗    │ │
│ │ MBC mini            ↗    │ │
│ └──────────────────────────┘ │
│ ⓘ 누르면 새 탭에서 방송사 공식   │
│   페이지가 열려요. 게임 소리와는 │
│   섞이지 않으니, 게임 소리는    │
│   라디오를 끄거나 줄여 주세요.   │
│ ─────────────────────────── │
│ 소리 출처 보기 →              │  ← §6 크레딧 화면 열기
└──────────────────────────────┘
```

- 안내 문구(고정): **「누르면 새 탭에서 방송사 공식 페이지가 열려요. 실제 방송은 이 게임 소리와 섞이지 않아요. 게임 소리는 라디오를 끄거나 볼륨을 줄여 주세요.」** 그 아래 작은 글씨: 「방송사 이름은 안내용 글자일 뿐, 방송사와 관계가 없어요.」
- 줄 오른쪽 `↗`(새 탭 표시). 접근성 이름 `CBS 음악FM, 새 탭에서 열림`.
- 아이폰에서 새 탭으로 가면 게임 탭이 백그라운드가 되어 게임 소리가 멎을 수 있다. 안내에 `돌아오면 이어서 걸어요` 한 줄을 더한다(자동 걷기는 백그라운드에서도 계속 간다 — AGENTS.md §8 11-08).
- 같은 링크를 **설정 시트의 "소리 출처" 화면 하단**에도 한 번 더 둔다(라디오를 못 찾는 사람용). 같은 `EXTERNAL_LINKS`를 읽는다.
- 지금 넣을 링크는 3개뿐: CBS 음악FM `https://www.cbs.co.kr/onair/musicFm`, CBS 표준FM `https://www.cbs.co.kr/onair/fm`, MBC mini `https://mini.imbc.com`. (KBS·SBS·EBS·TBS·국악방송·아리랑은 링크 확인이 안 됐으므로 넣지 않는다. 국악방송 igbs.kr은 도박 사이트 응답이 있었으니 절대 넣지 않는다.) **배포 전 대표가 세 링크를 브라우저로 한 번씩 열어 본다**(radio-options §3 조건).

### 2-3. HUD 칩 (라디오를 내렸을 때)

- 칩: `📻 91.9`(현재 주파수). 방송 수신 중이면 평소 색, 잡음 구간이면 `📻 ~87.5`처럼 앞에 `~`(희미한 글자), 꺼져 있으면 칩 자체를 보이지 않는다.
- 칩을 누르면 라디오가 다시 올라온다. 라디오를 내려도 소리는 계속 나온다(기존 설계).
- 칩 위치·크기는 기존 HUD 칩 규격(44px 높이, 종이색, 시점 칩 옆)을 따르고, 알림·쌍안경 내리기 버튼을 가리지 않는다.

## 3. 상태별 동작

### 3-1. 전원

| 상태 | 화면 | 소리 | 저장 |
|---|---|---|---|
| 꺼짐 (처음 기본) | 표시창 불 꺼짐, 다이얼·버튼 흐림, 스위치 `OFF` | 완전 무음(오디오 노드 연결 해제, 잡음도 없음) | `gwanak-radio` = `{on:false,freq,vol}` |
| 켜는 순간 | 스위치 딸깍 → 표시창 켜짐, 0.3초 페이드인 | 딸깍 한 번 + 잡음이 0.3초 올라옴 | 처음 켤 때 주파수 = **91.9**, 볼륨 0.6 |
| 켜짐 | 아래 3-2·3-3 | 주파수에 따라 | — |
| 끄는 순간 | 스위치 `OFF`, 표시창 꺼짐 | 0.2초 페이드아웃 후 완전 정지·메모리 반환 | on=false |

- 전원은 **사용자 터치 안에서만** 켠다(iOS 오디오 시작 조건). 앱 시작 때 자동으로 켜지 않는다.
- 라디오를 내려도 전원은 그대로다. 칩은 켜진 동안만 보인다.
- 게임의 "소리 끄기"가 켜져 있으면 라디오도 무음(기존 규칙: 발소리 마스터를 따름, `src/trail-sound.js`와 같은 AudioContext·마스터를 거친다). 표시창에 `소리 꺼짐` 글자를 띄운다.

### 3-2. 주파수와 수신 (잡음 ↔ 방송 섞기)

가장 가까운 채널 주파수 `ch`와 거리 `d = |freq − ch|`(MHz)로 **또렷함 `clarity`(0~1)** 를 정한다.

```
clarity = d <= 0.1 ? 1 : d >= 0.9 ? 0 : (0.9 − d) / 0.8       // 선형, 0.9 MHz 밖이면 방송이 안 들림
방송 음량 = clarity ^ 1.5 × 볼륨         // 가까울 때만 확 올라옴
잡음 음량 = (1 − clarity) ^ 0.8 × 볼륨 × 0.55   // 방송이 약할수록 잡음 커짐, 정확히 맞으면 잡음 0
```

- 방송이 없는 구간(clarity = 0): 잡음만 들린다. 표시창 `수신 불량…`, 수신 막대 0칸.
- 접근 중(0 < clarity < 1): 잡음 아래로 방송이 흐릿하게 섞인다. 방송 소리에 저역 통과 필터(차단 주파수 `800 + 5200 × clarity` Hz)를 걸어 **멀수록 먹먹하게**. 수신 막대는 `ceil(clarity × 5)`칸, 글자: `0.8 미만 …약함`, `…보통`, `수신 좋음`(clarity ≥ 0.9).
- 맞췄을 때(d ≤ 0.1, 스냅): 잡음이 0이 되고 방송이 또렷이 나오며 `딸깍` 소리 한 번, 표시창 채널 이름 밝아짐, `◆` 표시가 깜박 켜짐.
- 다이얼을 빠르게 돌리는 동안에는 지나친 채널의 방송이 조각조각 들린다(크로스페이드 0.08초). 끊김·팝 소리가 나지 않게 음량은 `setTargetAtTime`으로 바꾼다.
- 잡음은 **파일 없이 Web Audio로 만든다**(분홍 잡음 버퍼 2초 반복 + 저역·고역 필터 + 가끔 찌직(짧은 클릭)). 잡음 파일 용량·출처 걱정이 없다.
- 채널 3곳이 서로 3.6 MHz 이상 떨어져 있어 두 방송이 한 번에 섞이는 구간은 없다.

### 3-3. 채널별 재생

- 91.9: 곡 목록을 한 곡씩 이어 틀고(곡 사이 1.5초 크로스페이드), 다이얼이 이 채널을 떠났다 돌아오면 **이어 듣는 느낌**을 위해 그 시각 기준으로 같은 곡의 같은 위치에서 들리게 한다(채널 목록 총 길이로 `시각 % 총길이`. 실제 방송처럼 "틀어 놓은 채 지나가고 있었다").
- 95.5: §5 규칙으로 멘트를 고른다. 멘트와 멘트 사이(약 40~60초)는 짧은 징글 후 아주 작은 배경 바람(99.1의 파일 재사용, 음량 −18 dB). 멘트는 한 번에 하나, 말하는 중에는 자막이 보인다.
- 99.1: 바람·새·계곡물 루프를 길게 이어 틀고, 동일한 파일이 정확히 반복되는 느낌이 나지 않게 루프 둘을 서로 다른 길이로 겹친다.
- 방송은 전원이 켜져 있고 clarity > 0일 때만 오디오를 **불러온다**(메모리 절약, 휴대폰 상한 `src/device-profile.js`). 불러오는 중에는 표시창에 `…` 점 세 개(잡음은 계속 들림).
- 파일을 못 불러오면 표시창 `방송이 끊겼어요`, 잡음으로 대체. 팝업은 띄우지 않는다.

### 3-4. 볼륨 노브·게임 소리와의 관계

- 노브 회전 −135°~+135°, 0~1(기본 0.6). 끌어서 돌리고, 버튼 대체로 `−`·`+` 0.1(높이가 모자랄 때 노브 옆에 둠).
- 볼륨 0이어도 전원은 켜진 상태(표시창 `음소거`).
- 라디오 소리는 발소리·환경음 마스터 아래의 별도 버스. 발소리 위로 올라오지 않게 **라디오 최대 음량은 발소리의 약 70%**. 산스장의 빨간 라디오(뽕짝, 18m)와 겹치면 산스장 쪽 소리를 −10 dB 낮춘다(둘이 동시에 크게 들리지 않게).

### 3-5. 링크 (뒷면)

| 동작 | 결과 |
|---|---|
| ⟲ 누르기 | 카드가 뒤집힘(0.25초). 전원·주파수·소리는 그대로 이어짐 |
| 링크 줄 누르기 | `window.open` 대신 **그냥 `<a>`**: 새 탭에서 방송사 공식 페이지. 게임은 계속 진행(소리도 그대로, 섞이지 않는다는 안내는 항상 보임) |
| 링크가 없는 상태(목록 비었을 때) | 줄과 안내를 숨기고 `준비 중이에요` 한 줄 |
| 뒷면에서 `← 앞면으로` | 다시 뒤집힘 |

## 5. 95.5 멘트 대본 (자작, 게임 속 소리)

원칙
- 모두 **우리가 쓴 게임 속 방송**이다. 실제 기상예보·실제 시설·실제 방송사 표현을 쓰지 않는다(AGENTS.md §3: 실제 자료는 산 모양·코스·도심 풍경뿐). 날씨 멘트는 **게임 안 날씨·시각·계절 값**(`weather.kind`·`daytime`·`season`)만 읽는다.
- 한 번에 읽는 시간 8~15초(한국어 60~110자). 다정하고 느긋한 DJ 말투, 사과 같은 불필요한 말 없음. 이름은 "관악산 FM"만 쓴다.
- 인사말·끝맺음은 징글이 대신하므로 대사 앞뒤에 따로 쓰지 않는다. `{ }`는 구현이 채우는 자리(없어도 읽히게 쓴 문장이 기본).
- 아래 표의 id는 녹음 파일 이름(`public/radio/fm955/<id>.ogg`)과 같다. **한 줄 = 한 파일**(예: 20~40KB 안팎, 모노 ogg).

| id | 조건 | 대사 |
|---|---|---|
| `clear-day` | 낮 · 맑음(`clear`) | 관악산 FM입니다. 지금 산은 하늘이 맑아요. 그늘진 길에서는 숨을 한 번 크게 쉬어 보세요. 서두를 일 없는 하루, 발걸음은 가볍게 가요. |
| `cloud-day` | 낮 · 구름(`cloud`·`overcast`) | 구름이 천천히 능선을 지나가고 있어요. 햇볕이 약해서 걷기 좋은 날씨죠. 물 한 모금 챙기고, 오늘도 한 걸음씩 올라가 봐요. |
| `rain-light` | 비(`rain`, 약함·보통) | 지금 산에는 비가 내리고 있어요. 젖은 길은 미끄러우니 발밑을 먼저 보고 걸어 주세요. 빗소리와 함께하는 길, 오늘만의 풍경이에요. |
| `rain-heavy` | 비(`rain`, 센 비) | 빗줄기가 꽤 굵어졌어요. 바위 길은 특히 조심하고, 쉬어 갈 곳에서는 잠깐 숨을 돌려 가요. 서두르지 않아도 산은 그 자리에 있어요. |
| `fog` | 안개(`fog`) | 산에 안개가 내려앉았어요. 시야가 짧아졌으니 멀리 보지 말고 눈앞의 길만 천천히 따라가세요. 안개 속의 고요함을 즐겨 보세요. |
| `snow-winter` | 눈(`snow`) 또는 겨울(`winter`) | 눈 내리는 소리, 들리시나요? 사각사각 눈 밟는 소리가 오늘의 박자예요. 손은 따뜻하게, 걸음은 천천히 가요. |
| `dusk` | 노을 시간대 | 하늘이 붉게 물들기 시작했어요. 서울이 불빛으로 천천히 바뀌는 시간이죠. 걸음을 멈추고 잠깐 하늘을 올려다봐도 좋아요. |
| `night` | 밤 | 지금은 밤이에요. 산은 낮보다 더 조용하고, 별빛이 길을 비춰 줘요. 발밑을 살피며 천천히, 오늘 밤도 안전하게 걸어요. |
| `summit-near` | 정상 근처(남은 거리 ≤ 400m) | 정상이 가까워졌어요. 조금만 더 가면 연주대예요. 숨이 차도 괜찮아요, 여기까지 온 걸음이 이미 대단한걸요. |
| `spring` | 봄(`spring`) | 봄이 산에 닿았어요. 길가에 꽃잎이 날리고 새소리가 가까워졌네요. 오늘은 사진 한 장 담아 가도 좋겠어요. |
| `summer` | 여름(`summer`) | 숲이 짙은 초록으로 가득해요. 그늘에서는 바람이 시원하니 잠깐 쉬어 가기 좋아요. 물은 넉넉히, 걸음은 천천히요. |
| `autumn` | 가을(`autumn`) | 단풍이 한창인 산이에요. 발밑에서 바스락 낙엽 소리가 나면 그게 오늘의 리듬이에요. 천천히, 알록달록한 길을 걸어요. |
| `wind` | 바람 센 날(날씨 `windSpeed` ≥ 6 m/s, 있을 때만) | 능선에는 바람이 꽤 불고 있어요. 모자는 꼭 눌러 쓰고, 바위 가까이에서는 중심을 낮춰 걸어 주세요. |
| `long-walk` | 걷기 시작 후 30분마다(날씨 무관) | 한참을 걸어오셨네요. 어깨 힘을 조금 빼고, 숨을 길게 내쉬어 볼까요? 쉬는 것도 등산의 일부예요. |
| `fm-id` | 아무 때나(재방송 간격 채우기) | 이곳은 관악산 FM 95.5. 산의 날씨와 길 이야기를 전해 드려요. 지금 이 소리는 게임 속에서만 들리는 방송이에요. |

선택 규칙
1. 현재 상태에서 조건이 맞는 줄을 모은 뒤 **우선순위**: 정상 근처 > 비·안개·눈 > 바람 > 노을·밤 > 계절 > 날씨(맑음·구름) > 오래 걸음 > fm-id.
2. 같은 id는 **마지막 3개 안에서 반복하지 않는다**. 후보가 모자라면 `fm-id`.
3. 멘트 사이 간격 40~60초(95.5를 처음 맞췄을 때는 0.8초 뒤 바로 한 줄). 맞추는 순간 다른 채널로 가면 재생 취소, 돌아오면 새로 뽑는다.
4. 비·밤처럼 상태가 멘트 도중 바뀌어도 읽던 줄은 끝까지 읽는다(끊지 않음).
5. 녹음 파일이 아직 없는 줄은 **자막만** 6~10초 보여주고 징글을 울린다(소리 없이도 화면에는 방송이 흐르는 것처럼). 파일이 생기면 코드 수정 없이 파일 이름만 맞추면 소리가 붙는다.
