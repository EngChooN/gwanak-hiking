# 1차 개선 검수 — 자동 걷기 경치 감상 · 실제 관악산 비교

작성: 산디자인 · 2026-11-03 · 짝 문서: `artifacts/실경-비교.html`

## 0. 검수 범위와 한계 (먼저 읽기)
- **새로 걸어 보지 못했습니다.** 브라우저 이동과 캡처 스크립트 실행이 승인되지 않아, 입구부터 연주대까지 자동 걷기를 직접 돌리지 못했습니다. 아래는 11/2~11/3에 남은 캡처 6장(입구 1m, 4,419m, 4,510m 3인칭, 4,599m, 정상 북·동 5,067m)과 코드·문서를 근거로 한 판단입니다.
- 프레임 끊김, 화질 토글 동작, 오르막 다리 꺾임의 현재 상태는 **실측하지 못했습니다**(산개발 앞 단계도 측정 미완료).
- **실제 사진이 0장**입니다(산리서치 `실경자료-조사.md` §6). 실경 비교는 후기 서술과 화면의 대조에 그칩니다.
- **실제 관악산 경험자 확인은 남아 있습니다.** 모든 판정은 잠정입니다.

## 1. 체험 검수
| 항목 | 관찰 | 판정 |
|---|---|---|
| 남성 체형 | 3인칭 캡처(4,510m)에서 어깨·몸통이 남성형으로 보임. 다만 앞 단계 보고에 GLB 갱신 미완료로 적혀 있어 어느 버전인지 확인 못함 | 확인 필요 |
| 모자 중앙 | 캡처에서 모자가 머리 위에 있음. 정면·옆모습 근접 캡처는 없음 | 확인 필요 |
| 스틱 동작 | 캡처에 스틱이 없음. 신규 GLB 전달이 확인되지 않음 | 미반영 |
| 오르막 다리 | 4,510m 걷기 장면에서 꺾임은 보이지 않음. 한 장면뿐이라 계단·바위 구간 전체 확인은 못함 | 미확정 |
| 카메라 | 1인칭 눈높이 1.6m, 3인칭 기본 거리 안에서 캐릭터가 화면 중앙·하단에 잘 보임. 시야각 65°(가로)·78°(세로 화면)는 능선·시내 원경에는 적당하나 계단 오르막에서 바닥이 화면 대부분을 차지함 | 계단 구간 시야 조정 권고 |
| 화질 토글 | 오른쪽 아래 '화질 자동' 표시가 캡처에 보임. 순환 동작은 코드상 자동→높음→균형→낮음 | 코드상 정상, 실조작 미확인 |
| 프레임 끊김 | 실측 없음 | 미검증 |

## 2. 경치가 지루한 구간 (자동 걷기 기준)
| 구간 | 거리(m) | 이유 | 담당 |
|---|---|---|---|
| 깔딱고개 계단 오르막 | 약 3,400~4,500 | 노면이 매끈한 단색 경사면이고 계단·난간·데크가 없어 화면 대부분이 바닥(4,419m 캡처). 가장 긴 오르막이라 지루함이 오래 지속 | 산풍경(계단·데크 배치), 산개발(카메라) |
| 능선 직전 | 4,500~4,800 | 둥근 바위 하나와 낮은 밀도의 나무뿐(4,599m 캡처). 시선을 끄는 지형·시설 없음 | 산풍경 |
| 계곡길 | 1,070~2,600 | 계곡 물·바위 표현이 없음(환경음은 설계됨, 코드 연결 전) | 산풍경, 산개발(소리 연결) |
| 입구~호수공원 | 0~1,070 | 포장도로·호수공원 시설이 없고 숲이 균일 | 산풍경 |

## 3. 실경 비교 문제 목록 (거리·담당)
| # | 문제 | 구간 거리(m) | 담당 |
|---|---|---|---|
| 1 | 정상 시설(연주대·응진전·레이돔·송신탑)이 화면에 없음. 모델 코드는 준비됐으나 기본 코스에 미배치 | 5,000~5,067 | 산풍경 배치, 산개발 연결 |
| 2 | 계단·데크·난간이 보이지 않음. HUD는 '계단' 표시, 화면은 매끈한 경사 | 약 3,400~4,600 | 산풍경 |
| 3 | 능선 윤곽이 둥근 구릉. 각진 암릉 톱니 없음(30m DEM 한계) | 4,500~5,067 | 산풍경(고해상도 DEM 필요, 산리서치 자료 확보 대기) |
| 4 | 암릉 위치가 실제와 대응하는 근거 없음, 바위색이 어두운 검정에 가까워 화강암 회백색과 다름 | 4,599~5,067 | 산풍경 |
| 5 | 숲이 연녹색 일색, 수종·밀도 변화 없음. 입구 양쪽 검은 돌이 일정 간격 줄지어 인공물처럼 보임 | 0~1,070 | 산풍경 |
| 6 | 정상 북향 앞 지형에 노란 지그재그 격자 무늬(텍스처 타일 반복)가 보임 | 5,067 | 산풍경 |
| 7 | HUD 고도와 구간표 고도 불일치: 입구 HUD 50m, 구간표 99m. 정상 HUD 632m, 구간표 654m. 어느 쪽이 맞는지 확인 필요 | 0, 5,067 | 산개발 |
| 8 | 체크포인트 5곳 좌표가 전부 '확인불가'. 임시 위치라 실제 지점과 대응 안 됨 | 구간 전체 | 산개발(좌표), 산리서치(현장 확인) |
| 9 | 매미·거친 숨 소리 미구현, 물소리·새는 설계만 되고 코드 미연결 | 계곡길 1,070~2,600 | 산개발 |

## 4. 완료 기준 대조
- **실경 비교(6곳 이상 사진 대조)**: 미충족. 사진 미확보, 시설·암릉 불일치.
- 캐릭터·성능 기준: 이 검수에서는 확인하지 못함. 산개발·산풍경의 실행 검증이 선행되어야 함.

## 5. 다음 단계 권고
1. 대표가 승인하는 대로 산리서치 확보 자료(공공누리 사진 또는 현장 촬영) 확보.
2. 산풍경: 깔딱고개 계단·데크를 기본 코스에 배치, 정상 시설 배치(#1·#2).
3. 산개발: 검증 명령(`npm test`, 캡처 스크립트) 실행 허용 후, 위 지점을 방위까지 맞춰 새로 캡처하여 이 문서를 갱신.
4. 관악산 경험자 확인 후 판정 확정.
