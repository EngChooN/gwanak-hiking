## 대표 결정 반영(설계와 다른 점)
| 결정 | 구현 |
|---|---|
| 실행 키는 E가 아니라 **F** | 알약이 떠 있을 때만 F = 실행(`input.js` `interactKeyId`). 알약이 없으면 F = 정면 보기 그대로. **Q/E 회전은 그대로**(E는 건드리지 않음) |
| 돌 올리기에 "게임 속 돌이에요. 실제 산에서는 돌을 옮기지 않아요" | 알약 부제에 **항상**, 진행 안내 창과 완료 알림에도 넣었다(처음 한 번이 아니라 매번) |
| 키 J·N·Z·X·1~3, 멀티 키(X·G·N·K)와 겹치지 않게 | J 수첩, N 이름표(쌍안경+멀티 공용), Z 스트레칭, X 인사(짧게=인사, 누르고 있으면 메뉴), 1·2·3 = 알약 아래 줄·인사 메뉴. G·K는 멀티 시제품 그대로. `multi-client.js`가 직접 듣던 X·N은 빼고 `input.js`→컨트롤러가 맡는다(두 번 처리 방지) |

## 만든 것
- 공통 규칙(§①): 15m 마커(`ix-marker`), 4m(정상석·스탬프 6m) + 시선 ±70° 알약, 6.5m 밖에서 사라짐(깜빡임 방지), 후보 여럿이면 점수(거리+각도) 하나만·같은 자리 행동은 아래 줄로 쌓임(돌탑 공터: F 스탬프 + **2** 돌 올리기). 앉기·차·일시정지·달리기(2.2m/s 초과)·행동 중·창 열림·쌍안경/폰에서는 일반 알약 숨김. 새로 뜰 때 작은 틱(재표시 1.5초). `aria-live`, 움직임 줄이기 설정이면 도장·호흡 애니메이션 생략.
  - 모바일: 오른쪽 둥근 큰 단추(지름 84, 아래 줄은 56) + 이름표. 휴대폰 카메라 화면 안은 줌 단추 위 알약. 키보드 화면은 조작줄 아래 가운데.
- 안내판(§②): 코스 이정표 11곳 + 해설 3곳(계곡·연주암·응진전/말바위) + 정상 안내판(정상석·연주대 두 쪽). 가운데 패널(모바일은 바닥 시트, 가로 휴대폰은 오른쪽 시트), 걸으면 닫힘, 칩 3종(확인됨/전해지는 이야기/추정), 출처 한 줄, **"직접 정리한 설명이며 현장 안내판 글이 아닙니다"** 항상 표시. 이정표는 지명 행 + 화살표(내 시선 기준 회전), 바위 쪽 이정표(모자봉·학바위 능선·소머리바위)는 둘째 쪽에 한 줄 설명. 닫기: F·Esc·✕·바깥 터치, 시트는 아래로 끌어 닫기, ←→ 쪽 넘김은 창 안에서만.
- 스탬프 6곳 + 수첩(J): 6m 안 F → 붉은 도장 알림(새 스탬프 n/6·일주문 기준 거리·해발·진행 막대), 6/6이면 알림 대신 완등 카드. 수첩은 6칸·고도 단면·찍은 시각·"다음 · n.nkm 앞". 저장은 `localStorage`(`gwanak-interaction:v1`, 새로고침 뒤에도 유지, 깨진 값은 버림).
- 정상 인증: 정상석 스탬프가 곧 인증(`정상 인증 · 스탬프 찍기`). **완등 카드 1080×1350 PNG**("온라인 체험 기록 · 실제 등산 기록이 아닙니다" 고정, 값은 `state.elapsed·distance·ascent`). 사진은 마지막 정상석 앞 인증샷 → 없으면 정상 풍경 자동 촬영 → 없으면 일러스트. 인증샷은 기존 P·Space·Y 흐름 그대로이고, 정상석 6m 안에서 폰 화면에 「인증샷 틀 켜기」 알약이 떠 틀(크림 테두리·배지·아래 띠)을 켜면 **저장 사진에도 구워 넣는다**(끄면 깨끗한 사진). 모바일은 `navigator.share`(지원할 때) + 저장.
- 쌍안경 이름표(§③): 랜드마크 17곳. 방위 띠(±25°)·시야 안 이름표(계단식 최대 3줄)·시야 밖 가장자리 알약(최대 2)·가운데 맞춤(±1.2°) 금색 강조 + 상세 카드(F = 자세히 패널). **인천 쪽 3곳은 방향만**(점선·점 없음·"멀리 인천 방향"), 시선 가림 미확인 4곳(청계·광교·남한·수리)은 "추정", 북한·도봉·계양은 "가장 맑은 날만", 날씨 가시거리(맑음 25km … 안개 1.5km)보다 멀면 흐림 + "지금은 안 보여요". 남한산 높이는 적지 않음. **정상 부근(해발 560m 이상 또는 정상 구역)에서만** 이름표가 뜬다(계곡에서 거짓 이름표를 보이지 않게). N = 이름표 끄기(방위 띠는 남김), 모바일은 쌍안경 화면의 「이름표」 단추.
  - **진북 방위 → 앱 좌표(동 +x, 남 +z)**: `bearingToDirection(b) = (sin b, −cos b)`(북 −z, 동 +x, 남 +z). 카메라 heading(앞 = (−sin h, −cos h))의 방위는 `−h`. 서 있는 **실제 위치**에서 위경도→앱 좌표(`geographicToLocal`)로 거리·방위를 다시 계산하므로 정상 어디서든 맞다. 테스트: 17곳 방위가 자료 §③ 표와 0.2° 이내, 앱 좌표로 본 방위도 0.45° 이내, 거리·고각(곡률+굴절 k=0.13) 일치.
- 산길 행동(§⑥): 약수 한 모금(체력 +15, 3.4초, 쿨다운 20초)·손 담그기(+5, 3.2초, 쿨다운 20초)·돌 올리기(효과 없음, 2.8초, 내 돌 n개)·스트레칭 Z(+10, 4초, 쿨다운 30초). 이동하면 취소(소리 예약도 취소), 끝까지 해야 효과 지급. 진행 안내 창 + 막대, 스트레칭은 호흡 원, 손 담그기는 푸른 비네트, 카메라 숙임/올림(약수 −0.26rad·눈 −22cm 등). 소리는 시안의 임시 합성음(`interaction-sound.js`).
  - 손 담그기 자리는 자료 §④의 평상·벤치 3곳(s=1,540·1,710·2,156)으로 **추정**이다(물가까지 내려갈 수 있는지 미확인).
- 정상 자유 이동 구역: 정상 둘레 소품(스탬프함·정상 안내판·응진전 안내판)의 걷기 막기 반경(`collisionRadius` + 여유 .15 + 몸 .25)을 `SUMMIT_BLOCKERS`로 적용. 안쪽에서 바깥으로는 나올 수 있다.
- 멀티: 인사 메뉴(X 누르고 있기, 1 인사·2 손 흔들기·3 같이 셀카)·가까운 사람 4m 알약 "인사하기"·N 이름표를 시제품(`multi-client.js`)에 연결. **서버 연결은 하지 않았다**(같은 브라우저 창끼리).
- 구간 이동: `jump()`가 `interaction.reset()`을 불러 진행 중 행동·패널을 정리한다. 구간 이동 버튼과 알약·패널이 같이 떠도 충돌 없음(화면 27). 검수용으로 `hiking.jumpNear(소품id,{back,face,along})`를 구간 이동 켜진 때만 추가.
- 조작줄: 「수첩 J」「스트레칭 Z」 단추(키보드 화면). 터치 화면은 조작줄이 꽉 차 왼쪽 아래(가로는 오른쪽) 둥근 단추로 둔다. 도움말 창에 F·2·3·J·Z·N·X 설명 추가.

## 설계 제안값과 다르게 확인된 점 (산기획 확인 필요)
- **스태미나 효과가 너무 작다.** 서 있으면 스태미나가 초당 8씩 차오른다(`movement.js recover(…,8,dt)`). 약수 +15는 약 2초 쉬는 것과 같고 행동 3.4초 동안 이미 약 27이 찬다. 게임 감각이 필요하면 효과를 키우거나(예: +40) 달리기 소모 감소 같은 지속 효과로 바꾸는 것을 제안한다. 수치는 `interaction-data.js` `ACTIONS` 한 곳에서 바꾼다.
- 스탬프 위치·약수터·돌탑·정상 안내판 문구는 모두 지도·자료 기준이고 현장 확인 전이다(`status`·📍 그대로). 약수터는 "식수"라고 쓰지 않는다.

## 못 한 것 / 남은 점
- 설계의 "시선 돌림 0.4초", 손이 들어와 물에 잠기는 연출, 바닥 돌 금색 윤곽·돌이 실제로 탑에 얹히는 모습은 **만들지 않았다**(카메라 숙임·진행 창·소리만). 돌 올리기는 돌탑에 돌 모델을 더하지 않고 수만 센다. 필요하면 후속.
- 소리는 임시 합성음이고 사람 귀 검수 전이다. 소리 설명 자막(설정)은 넣지 않았다.
- 안내판 이정표의 옆길 화살표 방향은 추정이다. 이정표 1,071m는 기존 쉼터 이정표가 맡아 읽기 알약이 없다.
- 이름표는 시선 가림(DEM 시선 검사)을 하지 않았다(자료 문서의 미확인 항목 그대로 "추정" 표기).
- 실제 휴대폰·터치 기기, GPU 성능은 측정하지 않았다(헤드리스 크롬). 프레임 비용은 알약 후보 약 25곳 거리 계산 + 15m 안 마커 투영이라 작지만 숫자는 재지 않았다.
- 쌍안경 이름표는 가로 화면 비율 기준으로 정렬했고, 세로 휴대폰 쌍안경 화면은 `max-width:700px` 규칙만 넣고 캡처하지 않았다.
