# after3 후속 코드 — 실행 검증 대기

산개발 / 2026-11-03. 커밋·push 없음. 목표 달성 미확인.

## 반영 내용

- 정적 루트: 배치 후 `updateMatrixWorld(true)` 1회, 로컬·월드 자동 갱신 비활성. 설치된 three.js r180은 `matrixWorldAutoUpdate=false`여도 자식을 순회하므로 정적 루트의 `updateMatrixWorld` 진입을 차단했다. `freezeStatic` 재호출 시 원래 메서드를 복원하고 새 배치를 반영한다. 카메라·등산객·스켈레톤·태양에는 적용하지 않는다.
- 노드/제출 감소: 식생 모델 내부의 같은 재질·호환 속성 메시를 캐시 생성 시 병합한다. 바위는 기존 공통 화강암 재질 기준으로 병합한다. 도시는 512m 공간별·공유 재질로 병합하여 컬링한다. 도시 분할로 노드가 늘 수 있으므로 **전체 노드 수 감소를 실측했다고 주장하지 않는다**. 로딩 후 `__hikingMetrics.landscape.sceneNodes`를 제공한다.
- 종류별 계측: 실제 `renderBufferDirect` 전후 `renderer.info` 차이를 집계한다. 인스턴스 수·재질 그룹·drawRange가 반영되며, 기본·SSAO 깊이/법선·그림자를 분리한다. Sprite 등 별도 제출은 전체 카운터와의 잔차로 기록한다. `rendering.breakdown`은 최근 프레임, `performance.breakdown`은 측정 구간 평균/최대다. 분해 평균 합과 전체 평균을 대조할 수 있다.
- 상시 지형: 원본 8m DEM·2m 보행 청크·충돌/접지는 유지한다. 상시 화면 메시만 높음 16m, 균형 32m, 낮음 64m 격자를 사용한다. 마지막 행/열을 보존한다. 단순화 지형과 길·청크 경계의 관통/틈은 화면 검증이 필요하다.
- 도시: 높음에서 청크 AABB까지 2km 이내는 원래 외피, 그 밖과 균형/낮음은 원래 건물 범위·높이의 상자 외피다. 실제 건물 윤곽의 세부는 단순화된다. 건물 수나 원자료를 삭제하지 않는다.
- 숲·바위: 보이는 청크를 가까운 순서로 배정하고 기본 패스 삼각형 예산을 높음 30만, 균형 12만, 낮음 6만으로 제한한다. 먼저 낮은 LOD로 내리고 최저 LOD도 남은 예산을 넘으면 해당 청크를 숨긴다. **숲/바위가 경계에서 나타나고 사라질 위험이 있어 시각 검증 전 확정 품질로 취급하지 않는다.** 잔여 예산 때문에 소나무 아틀라스를 400m보다 일찍 강제 선택하지 않는다.
- 소나무: `pine_tree_01`에만 400m LOD3를 추가했다. 다른 자산 ID에 소나무 사진을 전용하지 않는다. 8방향 셀을 인스턴스별 관찰 방위에서 원래 yaw를 빼서 선택하고 GPU 수직 빌보드로 그린다. 한 변 12.726641404m, 피벗 496/512, sRGB, alphaTest .5, unlit, 그림자 투사 없음, 청크 공유 재질이다. 셀별 밉이 없는 PNG이므로 밉 생성을 끄고 선형 필터를 사용한다. 거리 LOD는 기존 청크 중심 방식이며 히스테리시스를 10%로 맞췄다. **개체 피벗별 전환 거리를 완전히 구현한 것은 아니다.**

## 분해표와 전후 수치

## 검증

`git diff --check` 통과. 변경 JS·추가 테스트는 `node --check` 구문 검사 통과(실행하지 않는 파싱). 정적 루트 자식 순회가 0회인지 확인하는 기존 테스트를 강화하고, 종류/패스별 제출 합계와 프레임 평균 집계 테스트를 추가했다. npm test는 실행하지 않았다. 이전 43/43은 after2 결과이며 이번 코드 통과 결과가 아니다.

브라우저는 about:blank 한 탭으로 확인됐다. 이번 서버를 시작하지 않아 새 화면을 캡처하지 않았다. 기존 after2 화면을 after3 검증 화면으로 재사용하지 않았다.

## 가정

정적 루트와 상위 좌표계는 배치 후 고정이다. 이동·재부모화 뒤에는 `freezeStatic`을 다시 호출해야 한다. 도시 상자 외피와 지형 화면 단순화는 실측/외형 검수를 위한 후보이다. 나무 아틀라스는 로컬 자산 규격을 따르며 현지 수종·풍경 검증을 대신하지 않는다.
