## 4. 거리·고도 의존 규칙

### 4.1 물소리 — 계곡 중심선과의 거리 `d`(m)
- `물소리_dB = 구간 목표(−38) − 20·log10(max(d,5)/5)` (거리 2배당 −6 dB). 합성 후 **−58 dBFS 미만이면 게인 0으로 끊는다**.
- 계곡 중심선 거리 `d`는 데이터가 없어 경로 위 추정 표를 선형 보간한다(`STREAM_DISTANCE_M`, 추정):
  `0 m: 60 / 800: 30 / 1070: 15 / 1500: 8 / 2000: 5 / 2595: 8 / 2800: 20 / 3000: 45 / 3246: 90`.
  → 구간 1 끝에서 서서히 켜지고, 구간 2 한가운데가 최대, 구간 3 앞 400 m 안에 사라진다.
- 좌우: 계곡이 경로 한쪽에 있다고 보고 패닝 −0.2 고정. 위치 데이터가 생기면 `StereoPannerNode` 값을 계곡 방위에서 계산(자리만 둠).
- 고주파 감쇠: `fc = 9000 / (1 + d/20)` Hz(최저 1.2 kHz)로 로우패스.

### 4.2 바람 — 고도 `h`(m)와 능선 노출 `e`(0~1)
- 숲 바람: `dB = −50 + 8·clamp((h−100)/(560−100), 0, 1)`(구간 1 −50 → 구간 5 끝 −42). 구간 6에서 `e`가 오르면 `×(1−e)`로 사라진다.
- 능선 강풍: `e = smoothstep(580, 640, h) × 노출계수`, 노출계수 구간 6 = 0.6, 구간 7 = 1.0(추정; 응진전·너럭바위는 사방이 트임). `dB = −48 + 15·e` → 최대 −33.
- 음색: `e`가 클수록 로우패스 컷오프 1.2 kHz→3.5 kHz로 열고, 돌풍 게인 변조(±2.5 dB, 주기 7~14 s 무작위)를 능선 강풍에만 얹는다.
- 숲 바람과 능선 강풍은 같은 녹음의 서로 다른 시각 24초 조각이라 위상이 겹치지 않는다.

## 6. 구간 전환 크로스페이드

- 곡선: 등전력(`cos/sin`). 게인은 `GainNode.gain.setTargetAtTime(target, now, τ)`, `τ = 페이드시간/3`.
- 구간 안에서 연속으로 바뀌는 값(물소리 거리, 바람 고도·노출)은 매 프레임이 아니라 **0.25 s마다** 목표를 갱신하고 `τ = 0.25 s`로 따라가 계단 소리를 막는다.
- 경계별 시간(초). 거리가 아닌 시간으로 통일:

| 경계 | 사라짐 | 나타남 | 비고 |
|---|---|---|---|
| 1→2 | 먼 도시 12 | 물소리: 거리 규칙으로 이미 서서히 켜짐 | |
| 2→3 | 물소리: 거리 규칙(앞 400 m) | 숲 바람 6 | |
| 3→4 | 새 6(간헐 주기 변경) | 까마귀 시작 | |
| 5→6 | 숲 바람 8 | 능선 강풍 8, 정상 웅성임 8 | 고도 규칙과 합쳐 급변 없음 |
| 6→7 | — | 목탁(응진전 60 m 안), 웅성임 −44로 6 | |

- 위치가 한 번에 바뀌는 경우(데모 시작 지점, 체크포인트 이동, GPX 교체): 모든 레이어를 **1.5 s 짧은 크로스페이드**로 새 구간 값에 맞춘다. 무작위 시작 위치 루프만 재시작.
- 일시정지·화면 이탈·탭 숨김: 환경음 버스 0.25 s에 걸쳐 0, 간헐음 타이머 정지. 복귀 때 0.5 s 페이드인.

## 7. 발소리와의 믹스 균형 (발소리가 묻히지 않게)

기존 발소리(`public/sounds`, 산디자인 2026-11-03 측정): 계단·암반 피크 −4~−6 dBFS(0.3 s RMS −21~−24), 돌길 −11~0, **흙·데크는 피크 −21~−25, 0.3 s RMS −38~−49로 매우 작다.** 환경음이 −30대면 흙 발소리가 묻힌다.

1. **합계 예산**(§3): 흙·데크 많은 구간 1~5는 −37 dBFS RMS 이하, 계단·암반인 6~7은 −32 이하. 기준은 **걸음 피크 − 환경음 RMS ≥ 12 dB**(흙 피크 −25 → 환경음 −37 이하).
2. **발소리 쪽 요청(산개발)**: 재질별 목표 피크로 정규화하는 게인을 발소리에도 둔다 — 흙·데크 −17, 돌길 −14, 계단·암반 −8 dBFS. 기존 −6 dBFS 소프트 리미터는 그대로. 재질표는 발소리 설정 한 곳에 둔다. 적용하면 흙 걸음 여유가 20 dB 이상이 된다.
3. 환경음 버스 하이패스 60 Hz(노트북 스피커 먹먹함 방지). 숲 바람은 200 Hz 이하 로우쉘프 −3 dB.
4. **걸음 덕킹(보조)**: 걸음마다 환경음 버스를 −2 dB(어택 10 ms, 릴리즈 250 ms)로 순간 내린다. 환경음 합계가 −34 dBFS를 넘는 구간(6~7)에서만 켠다. 설정 `DUCK`로 끌 수 있음.
5. 검증: 구간별 `발소리 피크(Analyser) − 환경음 RMS ≥ 12 dB`를 `window.hiking.audio()` 진단에 기록.

## 8. 음소거·볼륨 연동

- 기존 헤더 ♪ 토글(`SOUND_SAVE_KEY = gwanak-hiking:sound:v1`)은 **발소리와 환경음을 함께** 끈다. 끌 때 환경음 버스 0.15 s 페이드 후 소스·간헐음 타이머 정지, 켜면 0.5 s 페이드인 후 현재 구간 값으로 재개.
- 사용자 마스터 볼륨 `userVolume`(0~1, 기본 0.7, 저장 키 `gwanak-hiking:ambient-volume:v1`)은 발소리·환경음 두 버스에 같은 배수(`gain = userVolume²`)로 곱한다. 환경음만 따로 조절하는 슬라이더는 이번 범위 밖.
- 환경음 버스는 발소리와 같은 `AudioContext`, 같은 마스터 앞단에 연결하고 **합산 리미터(−6 dBFS)는 마지막에 하나**만 둔다.
- 첫 입력 전에는 `AudioContext`를 만들지 않는다(발소리와 동일). 디코딩이 끝난 레이어부터 시작, 누락은 콘솔 오류만 남긴다.

## 9. 코드 연결 사양 (산개발 다음 작업)

### 9.1 파일
- 복사: `assets/audio/ambient/gwanak-v1/*.flac` → `public/sounds/ambient/`(바이트 동일, 발소리와 같은 방식). 원본은 assets에 보존.
- 새 모듈 `src/ambient-audio.js`(`AmbientAudio`), 설정 `src/ambient-config.js`(§3~§6 표를 상수로, 한 곳), 테스트 `tests/ambient-audio.test.js`.
- `new AmbientAudio({base, context, destination, enabled, volume, random, onChange})`. `context`는 `FootstepAudio`의 `audio.context`, `destination`은 `audio.master` 앞 환경음 버스.

### 9.2 호출·이벤트
- 매 프레임 `ambient.update({ referenceMetres, elevation, view, paused, dt })`. 내부에서 0.25 s마다 목표 게인 갱신. 구간 id는 `ambientSectionAt(referenceMetres)`.
- 구간이 바뀌면 `window.dispatchEvent(new CustomEvent('hiking:section', {detail:{from, to, referenceMetres, jump}}))` 발행(`jump=true`는 이동·텔레포트 → 1.5 s 크로스페이드).
- 소리 토글은 기존 `hiking:sound`와 함께 `ambient.setEnabled(...)`, 볼륨은 `ambient.setVolume(v)`.
- 진단: `window.hiking.ambient()` → `{section, layers:{name:{gainDb, targetDb, playing}}, sumRmsDb, budgetDb, footstepPeakMinusAmbientDb, dropped, errors}`. `?audioDebug=1`에서 콘솔 `[환경음]`.

### 9.4 테스트(권장)
1. 전 구간 샘플링으로 목표 dB 전력합이 예산 이하.
2. 물소리: `d=5` 최대, 거리 2배당 −6 dB, −58 dB 미만 컷, 구간 3 끝 게인 0.
3. 능선 강풍: 고도 580 m 이하 게인 0, 구간 7 최대. 숲 바람과 구간 6에서 연속.
4. 간헐음: 시드 고정으로 간격 범위·목탁 묶음 8~12타 검사, 직전 같은 파일 반복 없음.
5. 크로스페이드 중 두 레이어 등전력 합 ±1 dB 이내.
6. 음소거 시 모든 레이어 게인 0·타이머 정지, 볼륨 곱 반영.

## 10. 루프 음원 이음매 처리와 규격

모두 모노 32 kHz 16비트 FLAC(무손실). 이음매는 끝 3 s(도시 2 s)를 처음 3 s 위에 등전력 크로스페이드한 뒤 앞 `L`초만 남겨, 마지막 샘플이 원본에서 이어지던 샘플로 곧바로 첫 샘플과 이어지게 했다. `이음매 점프`는 마지막→처음 샘플 차이, `평균 step`은 인접 샘플 평균 변화(점프가 평균 step 정도이면 클릭 없음으로 본다. 숫자 확인이며 청감 확인 전).

| 파일 | 길이 | 샘플레이트 | 용량 | RMS / 피크(dBFS) | 이음매 점프 / 평균 step | 원본 구간 |
|---|---:|---:|---:|---|---|---|
| stream-loop | 24.0 s | 32 kHz | 1,104,813 B | −26.0 / −11.3 | 0.0120 / 0.0204 | river 20~47 s |
| wind-forest-loop | 24.0 s | 32 kHz | 920,250 B | −30.0 / −5.1 | 0.0086 / 0.0083 | wind 190~217 s |
| wind-ridge-loop | 24.0 s | 32 kHz | 840,042 B | −24.0 / −6.5 | 0.0006 / 0.0040 | wind 138~165 s |
