# 고해상도 지형·항공사진 반영 준비

산풍경 · 2026-11-03 · **업무 미완료 / 자료 확보 대기**

## 결과

`docs/실경자료-조사.md`에는 확보 DEM·정사영상·비교 사진이 모두 0건으로 기록돼 있다. 프로젝트에서도 새 고해상도 자료를 확인하지 못했다. 실제 지형 교체·정사영상 혼합·사진 기반 암릉 배치·전후 비교는 수행하지 못했다. 30m 보간을 실제 5m 정밀도로 표시하지 않았다.

`assets/realistic/tools/stage-high-resolution.mjs`를 작성했다. **미실행·미검증 준비 코드**이며 앱에서는 호출하지 않는다. 승인된 로컬 DEM을 프로젝트 좌표계 f32로 사전 변환한 뒤 받는다. GeoTIFF 재투영 도구는 아니다.

- 원자료 및 격자 간격 ≤5m, 출처·이용 조건·SHA256·바이트 수·NoData·좌표·수직 기준·근경 전체 포함을 검사한다. 메타데이터 사실성과 이용 조건 판정은 별도 확인이 필요하다.
- 원본 GPX 표고로 alignRoute를 다시 계산한다. 기존 경로 폭·입구·정상 기준을 보존하고 demCenterY·elevationCorrection·누적 거리·전후 고도 차이를 기록한다.
- 새 `assets/realistic/staged-high-resolution/`에만 쓴다. 동명 폴더가 있으면 실패한다. candidate-manifest는 비교용이며 다른 자산이 없어 독립 실행 패키지가 아니다.
- 현재 DSM과 수직 기준이 다르면 중단한다. DTM/DSM·수관 높이 차이를 상수로 임의 보정하지 않는다. 256MiB 입력 상한은 검토 도구 제한이며 웹 예산이 아니다.

## 입력 규격

다음은 실제 자료가 아닌 예시다. 모든 값은 실제 원자료 및 변환 기록으로 채운다. file은 입력 JSON 기준 상대 경로, sha256은 변환 f32의 해시다. 범위는 기존 근경 전체를 덮어야 한다.

```json
{
  "source": {
    "title": "실제 원자료명", "url": "원문 출처 주소",
    "license": "확인된 이용 조건", "licenseEvidence": "약관 보존 경로",
    "acquiredAt": "실제 취득일", "resolutionMetres": 5,
    "sha256": "변환 f32 SHA256", "terrainRedistributionAllowed": true
  },
  "grid": {
    "file": "near-approved.f32", "format": "float32-little-endian",
    "units": "metres", "north": "-Z",
    "origin": {"lat": 37.46803, "lon": 126.946528},
    "verticalDatum": "실제 확인한 기준",
    "x0": 0, "z0": 0, "width": 2, "height": 2,
    "spacing": 5, "noData": -9999
  }
}
```

## 앱 연결 전 남은 작업

| 항목 | 구현·검증 기준 |
|---|---|
| 자료 | ≤5m 원자료, 좌표계·높이 기준·취득일·재배포 허용 근거 및 변환 전후 체크섬 확보 |
| 지형 LOD | 로더 stride 8/4/2는 spacing에 비례한다. 8m→5m 교체 시 같은 범위 삼각형이 약 2.56배가 될 수 있다. 고정 미터 간격 또는 코스 타일 방식과 경계 봉합 필요 |
| 정사영상 | 허용된 영상에서 월드 좌표가 맞는 RGB 맵 및 숲/암반/맨땅 가중치 생성. 그늘·계절 오분류를 사진 대조로 수정 |
| 암릉 | 연주대·능선 사진의 촬영점·방위 확인, 배치 좌표·치수·매립 깊이·출처 기록. 접지·카메라 충돌 검증 |
| 접지 | 중심·가장자리·청크 경계·급경사에서 surfaceHeight와 메시 높이 및 양발 밑창 오차 검사. elevationCorrection 이중 적용 금지 |
| 성능 | 산개발 기준: 높음 최대 250만·균형 150만 삼각형. 높음 보행 평균 55fps, CPU 4배 균형 30fps 및 50ms 초과 검사 |
| 비교 | 입구·계곡·제4쉼터 참고점·깔딱고개·능선·정상 등 6곳 이상. 촬영점/방위/FOV를 맞춰 실제·전·후 비교표 작성 및 report_image 요약 |

## 검증 상태

파일 읽기와 정적 코드 검토만 수행했다. 스크립트 실행 금지에 따라 도구·테스트·서버·캡처를 실행하지 않았다. 새 화면이 없어 기존 캡처를 이번 전후 증거로 올리지 않았다. 이번 작업에서는 로더·prepare.mjs·near.f32·far.f32·route.json을 변경하지 않았다. 동료의 미커밋 변경은 유지했다.

## 가정

- 조사 문서의 확보 0건을 기준으로 삼았다. 별도 계정·외부 저장소는 확인하지 못했다.
- GPX 337점 및 기존 입구·정상 높이는 검토본 비교 기준으로 유지한다.
- 자료 없이 합성 풍경을 추가하는 것은 실제 재현 기준을 충족하지 못한다.

## 대표 확인 필요

1. 국토정보플랫폼 로그인·필요시 가입 및 ≤5m DEM 확보. 정사영상 키 신청과 저장/가공/재배포 조건 확인.
2. 사용 허용 전망 사진 6곳 이상 또는 승인된 현장 촬영 자료 확보.
3. 아래 명령은 실행하지 않았다. 첫 명령은 자료 확보·재투영·입력 JSON 작성 후 실행한다. 앱 연결은 별도 구현이 필요하다.

```sh
node assets/realistic/tools/stage-high-resolution.mjs /absolute/path/approved-dem.json
npm test
npm run build
npm run dev -- --port 5176
```

커밋·push·배포는 하지 않았다.
