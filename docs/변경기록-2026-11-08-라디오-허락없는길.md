# 변경 기록 — 라디오 조사 범위 변경: 허락 없이 가는 길만 (2026-11-08, 산리서치)

대표 결정: 방송사·외부에 허락 문의를 하지 않는다. 커밋 안 함. 코드(`src/`)는 바꾸지 않았다.

## 바뀐 규칙
- **외부 접속 예외 없음.** 앱이 코드로 외부 방송 주소에 접속하는 예외(직전 보고에서 AGENTS.md §5 예외로 제안했던 것)는 만들지 않는다. `STATIONS`는 빈 채로 둔다.
- **허용 추가:** 사용자가 누르는 하이퍼링크(새 탭, `rel="noopener noreferrer"`, iframe 금지)로 방송사 공식 페이지를 여는 것. 앱이 외부로 요청을 보내지 않으므로 §5 "런타임 외부 접속 없음"과 충돌하지 않는다. 링크는 대표가 브라우저로 열어 확인한 것만 넣는다.
- **음악·소리 파일**은 CC0·CC-BY(곡별 확인)만, 우리 서버(같은 출처)에서만 재생한다. CC-BY 곡은 게임 안 크레딧에 표기한다. NC·SA·ND·FMA-Limited·Pixabay 원본 직접 제공은 쓰지 않는다.
- 허락 문의 후보(`CANDIDATES`)는 문의하지 않으므로 사용하지 않는다(정리는 구현 단계에서).
