# 정상부 시설·숲 혼효 반영 — 산풍경

상태: 코드·연결·회귀 검사·캡처 도구 준비. 실행 검증 및 정상부 캡처 2장은 미완료.

## 반영

- `assets/realistic/summit-config.js`: 시설별 기준점·오프셋·치수·회전, 활엽 60% / 소나무 40% 설정을 한 곳에 둔다.
- `assets/realistic/summit-facilities.js`: 자체 제작 메시. 흰 다면체 레이돔과 받침 건물, 석축 위 작은 기와집과 연등 줄, 너럭바위·관악산 629m 표지석, 원형 H 헬기장, 왼쪽 암릉/헬기장 우회 표지. 문구 아래 위치·치수 추정을 표시한다.
- `assets/realistic/load-landscape.js`: 시설 생성·LOD 갱신과 상태 통계만 추가. 기존 지형·청크·성능 정책은 유지한다. 시설 충돌은 추가하지 않아 GPX 보행·접지 계산은 바꾸지 않는다.
- `src/realistic-models.js`: 식생 로딩에 혼효 변환 1회 추가. 기존 스캔 4종 재사용, 개체 수·좌표 유지, 인스턴스 색상·활엽 크기 1.04배. 활엽 스캔을 신갈나무 실물로 확정 동정하지 않는다.

## 추정 위치·치수

좌표계 X 동쪽, Z 남쪽, Y 위, 단위 m. GPX 끝점의 고도 약 654.5m를 기준으로 하며 표지 문구 629m 때문에 경로나 지형 고도를 변경하지 않는다. 연주암 갈림은 경로 중 Y=581m에 가장 가까운 표본을 사용한다. 모든 시설 바닥은 배치 XZ의 기존 floorHeight를 따른다.

| 자산 | 기준점에서 X/Z 오프셋 | 추정 치수 |
|---|---|---|
| 레이더 | 끝점 −65/+30m | 건물 9×7×6m, 흰 돔 지름 10m |
| 연주대·응진전 | 끝점 +28/−18m | 석축 7×6×5m, 집 6×5×3.5m, 연등 9개 |
| 정상 표지석 | 끝점 +3/0m | 너럭바위 약 8×6×0.8m, 비석 1.4×0.65×2m |
| 헬기장 | 581m 갈림 +14/+4m | 지름 16m, H 약 4×4m |
| 능선 갈림 표지 | 581m 갈림 −3/0m | 지주 2.3m, 판 2×0.65m |

실제 방위·거리·바닥 수평성·석축 윤곽은 미확인. 석축은 기사에서 언급한 절벽 전체 높이를 표현하지 않는다. 원형 공터와 바위는 단순 형상이며 주변 경사와 접합·관통 여부는 캡처 검수가 필요하다. 표지의 왼쪽은 후기의 진행 방향을 뜻하며 실제 갈림 경로는 추가하지 않았다.

## 경량화·삼각형 수

시설은 각각 32m 이내, 재질별 병합, 공유 무텍스처 재질 4개. 거리 기준 AABB, LOD 0/40/120/400m와 10% 히스테리시스. 400m 밖에는 레이더·응진전 실루엣만 유지한다. 그림자 투사 없음.

정확한 삼각형 수는 미측정이다. 생성식의 보수적 계산 상한은 5종 합계 LOD0 **1,600 이하**, LOD1 **1,300 이하**, LOD2 **400 이하**, LOD3 **120 이하**(기본 패스, 표지판 포함)다. 이는 실측 결과가 아니다. 시설 통계 함수 `facilityTriangleCounts()`가 실제 인덱스/3을 계산하여 `landscape.status.summitFacilities.counts`에 노출한다. 연주대 군집 상한 30,000/6,000/1,200/300보다 작게 설계했다.

표지용 자체 CanvasTexture는 512×128 2장, RGBA8 전체 밉 계산 약 699,064바이트 합계. 사진 텍스처는 0장. 4종 나무 GLB·텍스처는 기존 파일을 공유하며 추가 이미지 파일은 없다. 혼효 재배정으로 청크별 자산 묶음 수가 늘 수 있어 전체 드로우콜·fps 준수는 미검증이다. 장면 성능 목표 충족을 주장하지 않는다.

## 자료·이용 조건

참고 링크: [서울시 시민기자 정상부 기사](https://mediahub.seoul.go.kr/archives/2007190), [서울대 코스 후기](https://v.daum.net/v/4b5qyN6FJY). 기사와 이미지 링크를 열었으나 도구가 사진 픽셀을 표시하지 않아 눈으로 사진을 비교하는 검수는 완료하지 못했다. 사진을 내려받거나 텍스처로 사용하지 않았다. 형상은 자체 작성, 나무는 기존 Poly Haven CC0 가공 스캔을 재사용한다(`assets/출처-라이선스.md` 및 기존 나무 인계 참조).

## 검증

`git diff --check` 통과. `tests/summit-facilities.test.mjs`에 5종 배치·LOD 예산·원거리 전환·개체 및 좌표 보존·60:40 배정 검사를 준비했다. 테스트는 실행하지 않았다. 캡처 도구는 정상·갈림 화면 2장과 시설/숲 통계를 `artifacts/summit-facilities/`에 저장하도록 준비했다. 이미지 파일은 아직 생성되지 않았다.

## 가정

임상도 확보 전 활엽:소나무=6:4. 10개 주기로 활엽 6개를 배정하므로 전체 끝부분 최대 9개에서 반올림 오차가 있다. 활엽 색상·크기 조절은 신갈나무 우점의 임시 시각 대용이다. 모든 위치·치수·회전은 후기와 GPX 기준의 설계 추정이며 현장 확인 전이다.

## 대표 확인 필요

상위 자율 진행 지시가 스크립트 실행을 금지하므로 이번 요청의 실행 검증은 수행하지 않았다. 프로젝트 루트에서 다음 명령의 실행 허용이 필요하다.

```sh
PATH=/Users/joonyoung/.nvm/versions/node/v24.22.2/bin:$PATH npm test
PATH=/Users/joonyoung/.nvm/versions/node/v24.22.2/bin:$PATH npm run dev -- --port 5176
# 별도 터미널: 정상부 캡처 2장 + 삼각형 수 JSON
PATH=/Users/joonyoung/.nvm/versions/node/v24.22.2/bin:$PATH BASE_URL=http://127.0.0.1:5176 node scripts/capture-summit-facilities.mjs
```

완료 후 실경 사진과 시설 위치·지형 접합·표지 방향·가독성을 비교하고, 산개발의 성능 측정과 합쳐 드로우콜·전체 패스 예산을 확인해야 한다. 삭제·배포·push·외부 전송 없음.
