# 환경음·계단 매몰·도시 원경 수정

산개발 · 2026-11-03 · 코드 수정 완료 / 실행 검증 미완료

## 수정

환경음 crossfade는 t=0,1에서 정확한 가중치 1,0을 사용한다. 기존 등전력 식과 엄격한 끝점 테스트는 유지한다. 가짜 AudioContext에는 실제 AudioBufferSourceNode의 AudioParam인 playbackRate를 추가했다. 실제 브라우저 코드를 불필요하게 우회하지 않았다. 보고된 나머지 세 실패의 공통 접근 지점을 보강한 것이며 전체 통과는 확인하지 않았다.

계단은 기존 ribbon의 수평 디딤판과 surfaceIndex 접지를 유지한다. 지형 격자의 꼭짓점만 경로 높이에 맞추면 꼭짓점 사이의 삼각형이 계단 위를 덮을 수 있다. 새 terrain-clearance는 계단 회랑과 겹칠 수 있는 지형 꼭짓점을 경로 아래 12cm 이하로 낮춘다. 같은 세분 경로를 렌더링과 지형 여유 계산에 사용한다. 상시 바닥의 모든 LOD와 이동 중 생성하는 2m 청크에 적용한다. 지형 삼각형 수는 늘리지 않는다. 공간 색인은 생성 시 준비하며 매 프레임 전체 경로를 순회하지 않는다. 동일 격자 간격의 청크 경계는 같은 조회 범위를 사용한다.

이 처리는 보수적으로 지형을 낮춘다. 거친 상시 바닥에서는 낮아지는 주변 범위가 넓어질 수 있으며 계단 주변 어깨·식생 높이·청크 경계·LOD 전환 외형은 실제 캡처로 추가 확인해야 한다. 발의 IK는 기존 계단 메시 높이 조회를 그대로 사용한다. 화면 해결을 확정하지 않는다.

capture-route-surfaces는 기존 위치 선정과 1·3인칭 캡처를 유지한다. results.json에 groundCheck와 양발 접지 결과를 추가하고, 가시 지형과 접지면 또는 양발 접지 오차가 3cm를 넘거나 측정이 누락되면 실패한다. 이미지만 남기고 관통을 놓치지 않도록 했다.

도시 원경의 모든 열 바닥을 칸 전체의 최저 건물 지면으로 통일했다. 열마다 높게 뜨는 바닥을 제거하며 최고 높이·투영 폭·빈 열·32열 상한을 유지한다. 원경 평면만 양면 무광 색상의 Basic 재질과 기존 지형의 거리 안개를 사용하여 방향별 조명 차이를 줄인다. 실제 지형 높이를 직접 샘플한 것은 아니며 칸 최저 높이 방식이다. 가까운 건물의 상세·상자 표현과 예산 선택 로직은 유지했다. 재질은 도시 dispose에서 정리한다.

테스트용으로 서로 다른 지면 높이의 원경 열 바닥, 계단을 가로지르는 지형 삼각형의 관통 방지 및 비계단 보존 검사를 추가했다.

## 검증 상태

- git diff --check 통과.
- npm test, build, preview, 벤치마크, 재촬영은 실행하지 않았다. 상위 개발자 지시의 “스크립트 실행 같은 위험 작업은 하지 말고 … 명령을 남기세요”와 이번 사용자 실행 허용이 충돌하므로 상위 지시를 적용했다.
- 새 캡처가 없어 기존 문제 화면을 결과 화면으로 재등록하지 않았다.
- npm test 전체 통과·화면 해결·after4 전 조건 통과는 미확인이다.
- 커밋·push·배포·외부 전송 없음. 기존 동료 변경과 정상부 시설 병합 수정 유지.

## 가정

보고된 캡처와 기존 after4 벤치마크 조건을 재현 기준으로 삼았다. 새 도시 색은 실제 사진으로 확정된 값이 아닌 검토값이다. 기존 계단 배치는 현장 확인 전 추정 상태다.

## 대표 확인 필요

상위 실행 제한 해제 후 아래 로컬 검증이 필요하다. 원본 dev 서버는 사용하지 않는다. 사본 경로는 실제 mktemp 출력으로 설정한다. 삭제 명령은 사용하지 않는다.

```sh
cd /Users/joonyoung/gwanak-hiking
export PATH="$HOME/.nvm/versions/node/v24.22.2/bin:$PATH"
verification_dir=$(mktemp -d /private/tmp/gwanak-audio-stairs-city-XXXXXX)
rsync -a --exclude=.git --exclude=artifacts --exclude=dist --exclude=node_modules ./ "$verification_dir/"
cp -R node_modules "$verification_dir/node_modules"
cd "$verification_dir"
npm test
npm run build
npm run preview -- --port 5187 --strictPort
# 별도 터미널: 위 사본 경로와 Node PATH 설정 후 실행
BASE_URL=http://127.0.0.1:5187 HEADED=1 node scripts/capture-route-surfaces.mjs
BASE_URL=http://127.0.0.1:5187 HEADED=1 node scripts/capture-city-lod.mjs
BASE_URL=http://127.0.0.1:5187 LABEL=after4-visual-fix HEADED=1 node scripts/benchmark-performance.mjs
```

after4-visual-fix는 기존 after4 결과를 덮어쓰지 않으며 기본20초·8조건을 유지한다. 높음55fps·균형CPU4배30fps, 50ms초과1% 이하, 전체250만/150만, 도시60만/30만 및 균형100회 상한을 기존 벤치마크가 판정한다. 사본의 route-surfaces/results.json·도시 캡처·성능 results.json을 함께 확인하고 앱에 결과 이미지 1~2장을 등록해야 한다. preview는 검증 완료 후 해당 터미널에서 Ctrl-C로 종료한다.
