# 울창한 숲·입체 풀·암릉 보강 — 산풍경

작업 폴더: `/Users/pc-2311001/gwanak-hiking`.

## 구현

- `src/realistic-models.js`에서 담당 자산 폴더의 `forest-layers.js`를 연결한다. `main.js`와 타 담당 렌더링·도시·등산객·보행 파일은 수정하지 않았다.
- 등산로 30m 안 교목을 추가한다. 줄기·수관 여유를 고려해 최근접 등산로 반폭 + 4.5m 밖에만 나무를 둔다. 임상도 미확보로 기존 활엽/소나무 60:40 시각값을 유지하며 스캔 모델을 한국 참나무로 확정하지 않는다.
- 30~180m 사면에는 기존 CC0 나무의 저비용 수관 사진판을 추가해 원경 숲을 잇는다. 기존 청크 가림·LOD·삼각형 예산을 그대로 사용한다.
- 기존 관목과 낙엽을 유지하고 절차적 풀잎·고사리/조릿대형 잎을 보충한다. 24m 청크별 InstancedMesh, 공유 geometry/material, 고정 난수 배치다. 낮음/균형/높음은 반경 20/30/40m를 기준으로 청크를 가리고 개수를 22/50/100%로 줄인다. 청크 경계에는 여유 표시가 있다. 매 프레임 행렬을 업로드하지 않으며 GPU가 개체 위치별 위상으로 풀 끝을 흔든다.
- 풀 색의 중복 곱셈을 없앴고 잎을 작은 갈래로 나눴다. 풀 밑동은 실제 근경 지형과 같은 2m 삼각형 보간 높이에 맞췄다. 연속 고도 함수만 사용하면 경사면 풀 일부가 지면에 묻히던 문제를 방지한다.
- 표고 470m 위에 기존 CC0 절리형 암반을 보강하고, 590m 위에는 세로로 긴 노두를 둔다. 정상 주변에는 폭이 넓은 rock_face_01 암반을 추가하고 정상 지면의 화강암 혼합 비중을 높인다. 최근접 노면 반폭 + 7m 밖에 배치하며 기존 시설 보호 검사를 거친다. 풀 밀도는 정상에서 줄여 바위를 드러낸다. 실제 노두 위치·크기의 실측 재현은 아니다.
- 기존 흙·낙엽·풀·화강암의 PBR 및 노멀맵 혼합을 유지하며 이끼 색 패치를 더한다. 새 이미지·스캔 다운로드는 없고 직접 작성한 풀 형상과 기존 CC0 GLB만 쓴다. 출처는 이용조건표에 추가했다.

## 검증 방식

`scripts/capture-scenery-forest.mjs`로 동일 위치·화질·1440×900·DPR 1의 headless Chrome을 각각 실행한다. 장면 준비 뒤 14초 대기하고 10초간 실제 렌더 프레임을 집계한다. 입구·계곡 숲길·능선·정상의 1인칭 4곳, W 보행 중 높음/낮음 3인칭을 측정한다. 전후 원본은 `artifacts/scenery-forest-{before,after}-*.png`, 수치는 같은 이름의 JSON에 있다.

`scripts/report-scenery-forest.mjs`가 전후 위치·화질 일치, 페이지·자산·셰이더 오류, 노면/발 접지 오차, 테스트와 빌드 로그를 확인한 뒤 비교 HTML과 성능 판정 JSON을 생성한다. 최종 수치와 판정은 `artifacts/scenery-forest-validation.json`, `artifacts/관악산-숲풀암릉-전후비교.html`을 기준으로 한다.

추가 회귀 검사는 배치 재현성·노면 비움, 화질/거리별 감소, 바람 셰이더 연결, 이끼 PBR 연결, 삼각형 보간 접지를 다룬다.

## 남은 검증

임상도 수종 비율·한국 수종 형상·현장 개체 위치는 미검증이다. 산리서치 자료를 확보하면 비율·형상을 재검토한다. 실제 관악산을 아는 사람의 현장 경치 확인은 후속이다. 하늘과 서울의 품질은 이번 담당 범위 밖이다. push·배포·삭제는 수행하지 않았다.

계곡 고정 시점의 노면 교차 진단 오차는 최대 0.440009m로 전후 동일하다. 기존 지형/노면 차이이며 이번 범위에서 수정하지 않았다. 발 접지 오차와 구분해 비교 보고서에 명시한다.

테스트 107개·빌드·6조건 성능 판정 통과. 1인칭 4곳은 59.70~60.00fps, 높음/낮음 3인칭 보행은 각각 60.00fps다. 최종 6장 육안 검사에서 공중 파편 없음. 정상 암반 교체 뒤에는 180m 표시 범위 안의 정상만 다시 측정했다. 다른 측정 지점은 범위 밖이다.
