# 변경기록 2026-11-08 — 의견 보내기(등산·흡연장 공용)

담당: 연개발 · 기획 연기획 · 디자인 연디자인(`docs/흡연장/의견보내기-디자인.md`, `src/feedback.css`)

## 무엇을 했나
등산(/hiking/)과 흡연장(/smoking/) 안에서 바로 고장·바라는 점을 남길 수 있게 「💌 의견 보내기」 카드를 붙였습니다.
게임은 아무것도 몰래 보내지 않습니다. 사용자가 「🐙 GitHub에 올리기」를 누를 때만 새 탭(`noopener`)으로 GitHub 이슈 작성 페이지를 내용을 미리 채워 엽니다. 계정이 없는 사람은 「📋 내용 복사」로 복사해서 보냅니다.

## 규칙
- 주소: `https://github.com/EngChooN/gwanak-hiking/issues/new?title=…&body=…&labels=…`
- 제목: `[등산|흡연장] 🐞|💡|💬 내용 앞 40자`(넘으면 `…`, 비면 종류 이름)
- 라벨: `feedback` + (`bug` | `idea` | 한마디는 없음) + (`hiking` | `smoking`)
- 본문: `### 종류` + 내용 + `### 같이 올라가는 정보` 목록. 6000자를 넘으면 정보는 두고 내용 쪽을 자름(`…(잘림)`). 내용 칸은 500자.
- 붙는 정보: 체험 · 주소(경로 + 옵션, `name`·`multi` 지움) · 화면(크기·배율) · 기기(휴대폰/PC·세로/가로) · 브라우저 이름·OS(UA 전체는 넣지 않음) · 체험 상태(등산 시간대·날씨, 흡연장 시간대·같이 피우기 연결 상태) · 빌드 날짜 · 지금 시각(서울).
  체험 상태 함수가 `닉네임`·`채팅`·`방`·`위치`·`ip` 같은 이름을 넘겨도 걸러 냄.
- 복사: `navigator.clipboard.writeText` → 실패하면 `.fb-fallback` 칸에 글을 넣어 `select()`(옛 `execCommand('copy')`도 한 번 시도).
- 입력 막기: 열린 동안 document 잡기(capture) 단계에서 `keydown`·`keypress` 전파를 멈춤(window에 붙은 이동·단축키·Enter 채팅·E·C 키가 안 받음, 글자는 그대로 쳐짐). Esc는 카드 닫기. 열 때 window `blur`를 보내 눌려 있던 키·조이스틱을 놓게 하고, 이동은 `feedbackOpen()`이면 0. 카드 바깥 어두운 곳이 화면 전체를 덮어 새 조이스틱·시점 드래그도 시작되지 않음.
- 휴대폰은 열 때 키보드를 바로 띄우지 않음(PC만 내용 칸에 포커스). 닫으면 원래 포커스로 돌아감.

## 캡처 명령(대표 확인용)
```sh
cd ~/gwanak-hiking && export PATH=$HOME/.nvm/versions/node/v24.22.2/bin:$PATH
npm run dev   # 다른 터미널
# 두 체험 × 세 크기 한 번에(카드 위치·44px·열린 동안 W로 안 걷는지까지 검사) → artifacts/feedback-2026-11-08/
node scripts/capture-feedback.mjs
# 흡연장만 기존 스크립트로: 카드 열기
JS="dispatchEvent(new CustomEvent('lounge:feedback-open'));document.querySelector('.fb-text').value='담배 불이 안 붙어요';document.querySelector('.fb-text').dispatchEvent(new Event('input'));document.querySelector('.fb-info').open=true"
node scripts/capture-smoking.mjs fb-390x844 390 844 "time=day" "$JS" 6000
node scripts/capture-smoking.mjs fb-844x390 844 390 "time=day" "$JS" 6000
node scripts/capture-smoking.mjs fb-1920x1080 1920 1080 "time=day" "$JS" 6000
```
등산은 `/hiking/?start=entrance`에서 설정 탭 → `💌 의견 보내기`(또는 콘솔 `dispatchEvent(new CustomEvent('hiking:feedback-open'))`)를 세 크기로 찍습니다.
