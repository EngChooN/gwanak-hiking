# 등산 스틱·앉기·차 마시기 연결

산풍경 · 2026-11-03

`main.js`는 이번 작업에서 수정하지 않았다. 기존 산개발 연결이 아래 입력을 이미 전달한다.

```js
hiker.update({
  // 기존 클립·stride·stepLength·slope·idleSeconds 입력 유지
  distance: state.steps + state.stepPhase, stride: 1,
  pose: state.pose, running: state.running, speed, dt,
  teaProgress: state.pose === 'tea' ? 1 - state.teaRemaining / 3 : 0,
});
hiker.ground({ moving, phase: state.steps + state.stepPhase, surfaceHeight });
```

독립 제어는 로더 반환 객체의 `hiker.setPose('stand'|'sit'|'tea')`를 사용한다. 이 경우 `update`의 pose 인수를 생략한다. 차는 앉기 전환 완료 후에만 허용한다. `dt`는 초, `stepPhase`는 소수 부분만이 아니라 **누적 걸음 수**(한 걸음당 +1)다. 명시적 `stepPhase`가 없으면 기존 `distance / stride`로 계산한다. 이동 속도는 앱이 정하며 `running`일 때 보폭 1.16배·팔/스틱 앞뒤 진폭 1.35배로 키운다. 앱의 이동 1.6배는 산개발이 처리한다.

`src/realistic-hiker.js`는 `SEATED_EYE_HEIGHT=.85`, `STANDING_EYE_HEIGHT=1.6`, `SIT_SECONDS=.8`, `TEA_SECONDS=3`을 재내보낸다. 현재 전환 높이는 `hiker.eyeHeight`다. 산개발은 1인칭 `floorHeight + hiker.eyeHeight`로 연결하면 앉기/일어나기 0.8초 동안 눈높이도 부드럽게 변한다. 현재 main의 고정 `.85`도 최종 앉은 높이와 같다.

`ground`를 `update` 뒤 매 프레임 호출한다. 스틱·팔 IK, 앉은 골반·발 접지, 소품 배치는 ground에서 최종 처리한다. 외부에서 뼈를 덧쓰기하지 않는다. `hiker.interaction`은 자세 전환율·차 진행률·스틱 팁 좌표 및 접지 오차를 제공한다.

## 자체 제작 자산과 사용 조건

- 소스: `src/hiker-interactions.js`의 `createHikingProps`.
- 제작: 산풍경, 이 프로젝트에서 원기둥/회전체로 직접 제작. 외부 다운로드·사진·텍스처·상표 없음. 새 제3자 라이선스 조건 없음. 프로젝트 소스와 같은 관리 조건.
- 양손 폴: `HikingPole.Left/Right`와 각 `.Grip`, `.Tip`. 그립~팁 기준 길이 1.10m, 지형/팔 도달 보정 때 길이를 조절한다. 손에 들 때 손목을 축에 맞추고 손가락을 굽힌다. 오른손 폴은 왼발, 왼손 폴은 오른발과 접지하고 접지 중 팁의 월드 X/Z를 고정한다.
- 앉을 때 양옆에 폴을 눕히고, 일어설 때 역전환으로 다시 든다. 엉덩이 중심은 지면 +9cm(메시 두께 여유), 발은 지형 표본으로 보정한다.
- `Tea.Cup`: 금속 컵과 차 표면. `Tea.Flask`: 주황 보온병과 마개. 앉았을 때만 보인다. 3초 동안 컵을 입 쪽으로 들어 기울이고 제자리에 내려놓는다.
- 기존 인체·의복·애니메이션 GLB는 변경하지 않았다. 기존 MPFB·Quaternius 자산 조건은 기존 기록표를 따른다.
- 앉을 면 주변 장애물·절벽 회피는 이동 모듈의 책임이며 이번 IK는 전달받은 높이 함수에 맞춘다.
