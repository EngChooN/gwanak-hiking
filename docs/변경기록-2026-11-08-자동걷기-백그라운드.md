# 변경기록 2026-11-08 — 자동 걷기 백그라운드 진행

## 대표 피드백
자동 걷기를 켜 두고 다른 탭·창에서 일하면 등산이 멈춘다. 백그라운드에서도 계속 걸어야 한다.

## 원인
1. `src/main.js`의 `suspend()`가 창 포커스가 빠질 때(`blur`)·탭이 숨을 때 `state.auto=false`로 자동 걷기를 직접 껐다.
2. 탭이 숨으면 브라우저가 `requestAnimationFrame`을 멈춰 메인 루프(`frame`)가 돌지 않았다.

## 바꾼 것 (`src/main.js`)
- `suspend()`는 소리·입력만 정리하고 저장하며, 자동 걷기는 끄지 않는다.
- `frame(now, background)`: 숨은 탭 보충 걸음일 때는 rAF를 다시 걸지 않고, 그리기·사진·성능 집계를 건너뛰고 `finishBackgroundFrame`(HUD 상태·저장)만 한다.
- 숨은 탭 타이머: 작은 워커(Blob) `setInterval` 250ms → 실패하면 일반 `setInterval`. 실제로 흐른 시간을 0.1초씩 나눠 `frame(…, true)`로 따라잡는다(한 번에 최대 60초). 숨는 순간 시계를 다시 잰다.
- 함께 걷기 위치 전송(`multi.update`)도 같은 루프라 숨은 동안에도 상대에게 걷는 모습이 간다.
- 숨은 동안 정상에 닿으면 자동 걷기만 끄고, 완등 카드·기록은 돌아왔을 때 첫 프레임이 띄운다.
- 소리: 숨은 탭에서는 예전처럼 나지 않는다(발소리 재생 중단, 효과음은 `!document.hidden`일 때만).

## 확인
- `npm test` 704개 통과(`tests/rendering-preparation.test.mjs`의 `frame(now)` 위치 찾기만 새 함수 모양에 맞춤).
- 새 e2e `tests/e2e/background-walk.spec.mjs`: 자동 걷기 → blur 뒤에도 auto 유지 → `document.hidden`을 true로 덮고 rAF를 멈춘 8초 동안 4.0m 진행(평소 걷는 속도), 페이지 오류 0.

## 한계
- 휴대폰은 화면을 끄거나 다른 앱으로 가면 OS가 페이지를 얼려 어떤 타이머도 돌지 않는다. 돌아오면 그 자리부터 이어 걷는다(얼어 있던 시간은 걷지 않음).
- 60초 넘게 타이머가 오지 않으면(크롬 장시간 숨김 절전 등) 그 넘는 시간은 건너뛴다.
