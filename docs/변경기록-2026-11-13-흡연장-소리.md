# 변경기록 2026-11-13 — 흡연장 녹음 소리 연결 (연개발)

상위 업무: 흡연장 소리 고치기 — 라이터·담배·캔커피 (리더 연기획) · 2/3단계.
앞 단계: 연디자인이 `public/sounds/lounge/`에 CC0 녹음 10개와 `docs/흡연장/소리목록-2026-11-13.md`를 올림.

## 바뀐 것
- `src/lounge/audio.js`
  - 첫 입력(unlock) 뒤 `BASE_URL/sounds/lounge/` 파일 10개를 fetch → decodeAudioData로 **한 번만** 불러와 버퍼를 둔다(`LOUNGE_FILES`). 같은 AudioContext·마스터·효과음 버스를 쓰므로 소리 꺼짐·거리 감쇠·좌우(pan)·주변 소리 줄이기(duck)를 그대로 따른다.
  - 소리 이름 → 파일(`fileCues`):
    - `lighter` → lighter-open(0초, 크기 1) → lighter-strike(0.2초, 1). strike 파일은 0.12초쯤 '화'라서 '화'가 0.32초(`LIGHTER_LEAD`)에 온다.
    - `inhale` → inhale(0.35).
    - `exhale` → quality별 light=exhale-short · sweet=exhale-mid · deep=exhale-long(0.5). 모르면 short.
    - `can`(자판기 `lounge:spot vending use`) → vending-button(0초, 0.5) → can-drop(0.3초, 0.8) → can-open(1.2초, 0.8) (`CAN_SEQ`).
    - 담배 타는 치이익 → cig-burn.flac 반복 하나를 draw로 크기 조절(`burnGain`, 0~0.15). 녹음이 있으면 합성 치이익·톡톡은 쉰다.
  - 같은 파일을 두 번째부터 낼 때 음높이(재생 속도)를 ±3% 흔든다(`PITCH_SPREAD`). cig-burn은 들이마시기 시작할 때마다 흔든다.
  - 한 소리에 필요한 파일이 하나라도 없으면(불러오기 전·실패) 그 소리 전체를 지금 합성 소리로 낸다. 실패한 파일은 `status().files.errors`에 남는다.
  - `status()`에 `file`·`synth`(파일/합성 재생 횟수)와 `files:{loaded,total,errors,burn}`을 더함. 시험용 `ready()`(불러오기 약속).
  - 크기는 소리목록의 시작값을 쓰고, lighter-strike만 0.8 → 1로 올림(브라우저 측정에서 재 털기보다 6dB 작았음).
- `src/lounge/smoke.js`: 라이터 소리를 불꽃이 보이는 순간(`FLAME_AT` 0.62초)보다 `LIGHTER_LEAD`(0.32초) 먼저 부른다(전에는 불꽃이 보일 때 불러서 합성 '화'가 0.32초 늦었음). NPC가 불 대 주기(lend)도 같은 방식. 화면 동작 시간은 그대로.
- `src/lounge/spots.js`: 캔 떨어지는 시간 `DROP`을 export만 함(테스트가 소리 순서와 대조). 동작은 그대로.
- `tests/lounge-audio-files.test.mjs`(새로, 10개): 파일·문서 일치, 매핑, 캔·라이터 타이밍, 지직 크기, 한 번만 불러오기·BASE_URL, ±3%, 실패 시 합성 대체, 소리 꺼짐 0건, 반복 소스 하나, 거리 감쇠.
- `scripts/verify-lounge-sound.mjs`(새로): 실제 Chrome에서 파일 판/합성 판(파일을 막음)을 각각 띄워 크기 측정·흐름·소리 꺼짐 확인 → `artifacts/smoking/lounge-sound-2026-11-13.json`.

## 확인 못 함 / 남은 점
- **귀로 들어 보지 못함**(이 환경은 소리를 들을 수 없음). 연디자인이 짚은 4가지(성냥 녹음 라이터, 한숨 같은 날숨, 자판기 버튼, cig-burn 반복 이음매)는 대표 미리듣기에서 확인해야 함.
- 합성 대체 소리(파일을 못 불러올 때만 남)는 원래부터 라이터 +2dB·들숨 +9dB·캔 +10dB로 0dB를 넘어 깨질 수 있음(측정). 이번 범위(파일 연결) 밖이라 고치지 않음.
- 실제 휴대폰(아이폰 사파리)에서 디코딩·소리는 안 해 봄. 옛 사파리의 decodeAudioData 콜백 방식은 다루지 않음(등산 발소리와 같은 방식).
- 소리 미리듣기 HTML(기획서 완료 기준 8)은 이번 지시에 없어 만들지 않음.
