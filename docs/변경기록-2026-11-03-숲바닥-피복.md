# 숲 바닥 피복 보강 — 산풍경

상태: 구현·자동 검사 완료. 수정 후 화면과 성능 완료 기준은 미검증.

## 변경

- `assets/realistic/generated/nature/forest-layers.js`에서 저지대 숲 바닥의 기존 낙엽 텍스처 혼합을 55~80%에서 90~98%로 높였다. 낙엽 색 배율은 (.64,.53,.38)에서 (.38,.30,.20)로 낮춰 밝은 바탕이 포기 사이로 드러나는 현상을 줄이도록 했다. 이 수치는 셰이더 혼합 가중치이며 실제 맨땅 면적 감소율이 아니다.
- 이끼 패치를 더 넓게 이어 주고, 기존 바탕색에 녹색을 곱하는 대신 낮은 명도의 저채도 이끼색을 섞었다. 고도 490~610m에서 낙엽 보강이 줄고 암반 가중치가 높은 곳은 보강이 약해진다. 이끼는 460~600m에서 줄어든다.
- 기존 포기의 넓은 하층 잎 표시율을 고정 약 14%에서 공간 패치에 따라 약 22~57%로 바꿨다. 낮은 관목형 잎이 군락으로 섞이도록 했다. 현장 수종을 확인한 관목 모델은 아니다.
- 추가 메시·인스턴스·텍스처 샘플 없이 기존 자원을 사용한다. 포기 최대 높이 약 33cm, 좌표, 길 바깥 배치 여유, 청크, 거리·화질별 개수 조절은 유지했다. 실제 프레임 성능은 별도 측정이 필요하다.
- 등산로 흙·포장 재질은 피복 보강 대상에서 제외한다. 경로·노면 폭과 형상을 변경하지 않았다. 길 가장자리의 지형 재질은 어두워질 수 있어 흙길 폭의 시각적 유지 여부는 캡처 검수가 남아 있다.
- 등산객·걷기 파일은 수정하지 않았다. 기존 공유 작업을 되돌리지 않았다. push·배포·삭제·외부 전송은 하지 않았다.

## 가정

- 기존 로컬 자산과 시각 가정으로 낙엽·이끼·낮은 관목형 하층을 표현한다. 실제 관악산의 수종·계절별 피복 분포나 나무별 수관 위치를 새로 확인한 결과는 아니다.
- 검증 기준 시점은 기존 `scripts/capture-scenery-final.mjs`의 입구·계곡·능선·정상 및 능선 3인칭이다. 전후 기준 화면은 `artifacts/scenery-final-review-*.png`다.
- 명시적으로 요구된 `npm test`·`npm run build`는 실행 허용으로 해석했다. 별도 스크립트 실행과 브라우저 이동·입력은 금지 지시를 따라 보류했다. 따라서 이전 대화의 fps를 이번 변경의 실측값으로 재사용하지 않았다.

## 대표 확인 필요

프로젝트 폴더에서 아래 캡처 명령을 실행해야 수정 후 입구·계곡·능선 화면과 높음 4시점·3인칭 성능을 검증할 수 있다. 스크립트 실행 금지 때문에 이번에는 실행하지 않았다. 기존 127.0.0.1:5176 서버가 수신 중인 것만 확인했다.

```sh
cd /Users/pc-2311001/gwanak-hiking
PATH=/Users/pc-2311001/.nvm/versions/node/v22.17.1/bin:$PATH LABEL=forest-floor ONLY=entrance,valley,ridge,summit,third QUALITY=high node scripts/capture-scenery-final.mjs
```

이 명령은 `artifacts/scenery-final-forest-floor-*.png`와 `artifacts/scenery-final-forest-floor.json`을 생성한다. 입구·계곡·능선을 기존 `scenery-final-review` 화면과 비교해 피복과 흙길 폭을 확인하고, 높음 입구·계곡·능선·정상 각각 45fps 이상, 3인칭 40fps 이상 및 페이지·셰이더 오류 0건을 확인해야 최종 완료다. 아직 수정 후 결과 화면을 확보하지 못해 결과 이미지 첨부도 보류했다.

push·배포·삭제·외부 전송은 요청 범위에 없어 실행 계획이 없다.
