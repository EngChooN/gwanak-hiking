# 구간별 환경음 연결

산개발 / 2026-11-03. 상태: 코드·테스트 작성 및 구문 검사 완료. **전체 테스트·성능 실측·청감·새 화면 검수 미완료**. 커밋·push 없음.

## 선행 상태와 구현

`환경음-구간별-설계.md`와 `assets/audio/ambient/gwanak-v1/` 11개 파일을 확인했다. 구간별 노면 작업은 코드 반영·정적 검사까지 진행돼 있어 그 구간 좌표를 사용해 연결했다. 노면 작업과 after4의 전체 실행 검증은 여전히 대기 상태이며 이번 결과로 대신하지 않는다. 기존 작업 트리의 다른 변경은 보존했다.

- `src/ambient-config.js`: 7구간 목표, 원본 RMS, 전력합 예산, 물소리 거리표, 고도·능선 노출, 간헐음 범위, 전환·덕킹 상수를 모았다. 모두 추정이며 `VERIFIED=false`다.
- `src/ambient-audio.js`: 물·숲 바람·능선 강풍·새·정상 웅성임·먼 도시 루프, 까마귀 교대·목탁 묶음, 지연 다운로드·디코딩, 필터·팬, 전력 공간 크로스페이드를 구현했다. 프레임에서는 초당 4회만 계산한다. 간헐음은 별도 타이머 없이 활성 업데이트 시간으로 진행해 숨김·정지·음소거 동안 멈춘다.
- `src/main.js`: GPX 선분 양 끝 `referenceMetres`를 보간해 노면과 동일한 4,962m 기준을 전달한다. 3D 경로 길이를 단순 비례 환산하지 않는다. 도약은 0.25초 갱신 사이 30m 초과 이동 또는 명시적 `jump`로 판정한다. `hiking:section`·`hiking:sound` 이벤트, 공유 토글·볼륨 저장, 출처 안내, 읽기 진단을 연결했다.
- `src/footstep-audio.js`: 디코딩 때 원본 파일 피크를 한 번 측정해 흙·데크 −17, 돌길 −14, 계단·암릉 −8dBFS로 정규화한다. 기존 변형·급경사·3인칭 보정은 그 뒤에 적용한다. 공유 마스터 앞에 발소리 분석기를 추가했다.
- 공유 AudioContext와 마지막 −6dBFS WaveShaper 리미터 하나를 사용한다. 사용자 볼륨은 공유 마스터에 `volume²`로 한 번만 적용한다. 기본값 0.7이다. `hiking:sound`의 `{volume:0~1}`로 조절·저장하며 별도 슬라이더는 추가하지 않았다.
- 11개 FLAC을 `public/sounds/ambient/`에 복사했다. 총 약5MB이며 첫 입력 전 환경음 다운로드·AudioContext 생성은 없다. 현재 필요한 루프부터 받고 구간5부터 강풍·웅성임·목탁을 준비한다. 원본은 보존했다.

## 전환·진단과 검증 범위

경계 전환은 레이어 전력의 cos²/sin² 보간과 GainNode 평활화를 함께 쓴다. 도시를 포함한 구간2 전환12초, 상부8초, 나머지6초, 도약1.5초다. 설계의 경계별 레이어별 시간이 아닌 전환 전체의 보수적인 공통 시간으로 구현했다. 구간의 연속 거리·고도 변화는 0.25초마다 갱신한다. 목탁 위치는 경로4,860m로 가정하고 거리60m 안·경로4,800m 이후에만 울린다. 목탁 묶음은8~12타이며 간격은1.1초에서0.9초까지 빨라졌다가1.1초로 돌아오는 코사인 곡선을 쓴다.

`window.hiking.ambient()`와 `window.hiking.audio().ambient`에 구간·레이어·목표 전력합·예산·측정 RMS·오류·활성 수가 나온다. `footstepPeakMinusAmbientDb`는 발소리 분석기 피크와 마지막 환경음 분석기 RMS 차이다. 무음·미측정이면 null이다. `normalizedPeakMinusAmbientDb`는 정규화 목표에서 계산한 참고치로 실제 측정값과 구분한다. 짧은 분석기 구간과 4Hz 갱신으로 모든 걸음의 피크를 잡는 것은 아니므로 청감·연속 캡처가 필요하다. 환경음 RMS는 공유 볼륨 앞에서 측정한다. 리미터 뒤 실제 출력과 같은 값으로 해석하지 않는다.

설정 전력합이 예산을 넘으면 최초 구간별 경고와 보정을 적용한다. 전환 중에도 현재 목표 전력합을 제한한다. 이 값은 파일 RMS와 게인의 모델이다. 일회음의 순간 에너지·실제 파일 구간별 RMS·노드 평활화 중 실제 합산은 분석기로 추가 확인해야 한다. 따라서 **발소리가 묻히지 않는다거나 실출력 예산을 지켰다고 확정하지 않는다**.

`tests/ambient-audio.test.mjs`에 경로·고도 전수 목표 예산, 거리 감쇠·컷, 능선 고도, 전환 전력합, 첫 입력 전 지연, 음소거·정지 시계, 도약·복귀, 볼륨 범위, 까마귀 교대, 목탁 묶음·쉼, 원본/사본 동일성 검사를 추가했다. npm test 패턴에 맞춰 `.test.mjs`로 작성했다. **작성만 했으며 실행하지 않았다.**

변경 JS와 테스트의 `node --check` 구문 검사 및 `git diff --check` 통과. 삼각형·드로우콜·텍스처 변경은 없으며 기존 렌더링 예산 수치는 변경하지 않았다. CPU 단계 보고에 `ambient`를 추가했다. 디코딩·필터·분석기 비용이 있으므로 성능 후퇴 없음은 실측 전 미확정이다. 기존 after3 미달과 after4 미측정 상태를 그대로 유지한다.

## 가정

노면 코드 반영을 선행 작업으로 보고 연결을 시작했다. 환경음 거리·사찰 위치·고도 노출·주기·음량은 설계서의 추정이다. 도시 정상 옵션·매미는 꺼져 있다. 실제 관악산 녹음·한국 산새 확인·실제 목탁은 후속 자료 확보와 현장 검증이 필요하다. 출처·사용 조건은 산디자인이 작성한 로컬 기록을 사용했고 이번 작업에서 외부 사이트로 전송하지 않았다.

## 대표 확인 필요

상위 지시의 스크립트 실행 금지로 다음 명령을 실행하지 않았다. 요청한 npm test 통과·성능 예산 후퇴 없음·실제 청감 확인은 완료 조건으로 남아 있다. 새 서버·브라우저를 실행하지 않아 변경된 소리 출처 화면 캡처도 미완료다. 기존 화면을 새 검증 결과로 재사용하지 않았다.

```sh
cd /Users/joonyoung/gwanak-hiking
export PATH="$HOME/.nvm/versions/node/v24.22.2/bin:$PATH"
npm test
npm run build
npm run preview -- --port 5186 --strictPort
# 별도 터미널에서 실행
BASE_URL=http://127.0.0.1:5186 LABEL=ambient-after HEADED=1 node scripts/benchmark-performance.mjs
BASE_URL=http://127.0.0.1:5186 HEADED=1 node scripts/capture-audio.mjs
```

기존 capture-audio는 발소리 캡처 도구이며 환경음 전 구간 자동 검증을 대신하지 않는다. 브라우저에서 구간별 저장 위치를 준비해 계곡·숲·능선·정상, 경계 왕복·도약, 음소거 재개, 볼륨0·0.7·1, 탭 이탈 복귀를 확인해야 한다. 환경음 켬/끔을 같은 위치·기기·화질에서 비교하고 이어폰·스피커에서 발소리 여유12dB와 루프 이음매를 확인한다. 새 화면1장은 소리 출처 안내를 담는다. 서버 종료는 해당 터미널의 Ctrl-C다. 이번에 시작한 프로세스는 없다.
