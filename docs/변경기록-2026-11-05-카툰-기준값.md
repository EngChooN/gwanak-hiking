# 변경 기록 — 카툰 2단계: 참고 사진 팔레트·형태 기준값과 비교 이미지 스크립트 (2026-11-05, 산디자인)

## 결과물
- `docs/카툰-기준값.md`: 낮·노을·밤 팔레트, 형태 기준값, 대상별 대표 사진, 비교 스크립트 사용법. 값마다 근거 파일명을 적었다.
- `docs/카툰-팔레트.json`: 팔레트 원자료. 값마다 근거 파일, 찍은 영역, 개별 색이 들어 있다.
- **스크립트**
  - `scripts/cartoon-palette.mjs`와 `scripts/cartoon-palette-samples.json`: 참고 사진에서 색을 찍는다. 찍은 영역을 표시한 확인 이미지도 만든다.
  - `scripts/cartoon-compare.mjs`와 `scripts/cartoon-compare-presets.json`: 우리 화면 1장과 참고 사진 3장을 2×2로 붙이고, 아래에 기준색 띠를 깐다. 프리셋 11개 가운데 최종 판정 10장에는 `final` 표시를 했다.
  - `scripts/cartoon-ref-sheet.mjs`: 폴더별로 파일명이 붙은 목록 이미지를 만든다.
  - `scripts/lib/ref-image.mjs`: 위 스크립트들의 공용 모듈이다. headless Chrome 캔버스로 처리해서 새 의존성이 없다.
- `.gitignore`: `artifacts/cartoon-compare/`를 추가했다. 참고 사진이 들어간 비교·목록 이미지라 커밋하지 않는다.
- 기준 이미지: `artifacts/cartoon-compare/*-baseline.png`(로컬 전용)에 재작업 전 카툰 화면 11장을 남겼다.

## 확인
- 앱 코드(`src/`)는 바꾸지 않았다.
- 팔레트 영역은 확인 이미지를 보며 두 차례 고쳤다. 하늘·인물·안개에 잘못 걸린 영역은 모두 옮겼다.
- 비교 스크립트로 tree·grass를 찍었다. 콘솔 오류 0, 셰이더 오류 0, 지정 위치(s=1300) 일치를 확인했다.

## 기준 비교에서 본 현재 화면과 참고 사진의 차이 (3단계 참고)
- 나무: 노란 갈색 덩어리에 굵은 검은 외곽선이 둘렀다. 참고는 연두색(#61973b)이고 외곽선이 없다.
- 하늘: 진한 파랑(#3f8fdc)이다. 참고는 옅은 청록(#a2c8d3)이다.
- 그 밖의 항목은 `docs/카툰-기준값.md` §1-4에 정리했다.

## 남은 일과 확인 필요
- **산기획 확인 필요**
  - 도심 불빛: 기획서는 주황인데, 참고 사진은 크림 흰색(#ede7c9)이다.
  - 배경 외곽선: 참고 사진에는 없으니 제거하자는 제안이다.
- 프리셋 자리(s·시선)는 기존 캡처 스크립트의 자리를 옮겨 왔다. 오브젝트가 화면 가운데에 크게 잡히는지는 3단계 담당이 처음 쓸 때 조정한다.
  - 기준 11장은 모두 콘솔·셰이더 오류 0이다.
  - `rock`(s=3600, yaw -30)은 화면에 바위가 잡히지 않고 숲길만 나온다. 바위 담당이 바위가 보이는 자리로 고쳐야 한다.
- 밤 풀·바위는 근거 사진이 1장뿐이라 참고값으로만 둔다.
