# 등산객 모델 수정 준비·인계

산풍경 · 2026-11-03 · 산기획/산개발 전달용

## 현재 결과와 제한

**완료 상태는 구현 준비이며, GLB 수정 완료가 아니다.** 자율 진행 지시에서 스크립트 실행을 위험 작업으로 금지했으므로 변환·테스트·캡처를 실행하지 않았다. 원본 GLB 3개와 기존 IK 코드는 수정하지 않았다. 수정용 코드와 별도 검토본 생성 경로를 준비했다. 새 정면·측면·보행 이미지가 없어 `report_image`에 과거 이미지를 결과로 올리지 않는다.

대표 모자 스크린샷 `171c8651-2301-461c-8c9c-9eb3a3569d98__스크린샷 2026-11-02 오후 11.39.36.png`를 열어 모자가 머리 쪽으로 기울어 보이는 상황을 확인했다. 단일 측면 이미지로 좌우 오프셋과 머리 회전·스킨 영향은 구분할 수 없어 정확한 보정량은 모델 기반 검토가 필요하다.

## 확인한 모델 구조

| 파일 | 확인된 구조 | 수정 방침 |
|---|---|---|
| assets/realistic/models/hiker/Hiker.glb | MPFB 계열 Human, Human.jacket, Human.hat 스킨 메시, mixamorig:Head/LeftHand/RightHand | 본체 기준 수정, 기존 스킨·애니메이션 데이터 보존 |
| assets/hiker-170-lod0.glb | THREE.GLTFExporter 프록시, Hiker170/ArmL/ArmR/HipL/HipR | 별도 프록시 수정, 본체 GLB의 LOD로 오인하지 않음 |
| assets/hiker-170-lod1.glb | 위와 같은 프록시 노드 계층 | LOD1도 동일 노드 계약으로 수정 |

기존 루트 LOD0/1은 MPFB/Mixamo 모델의 단순화본이 아니다. 서로 다른 리그를 하나의 GLB로 덮어쓰면 기존 로더가 깨질 수 있으므로 세 입력을 각각 처리한다. `src/realistic-hiker.js`에서 로더가 뼈 이름의 콜론을 제거한 이름을 사용함도 확인했다. 이번에 원본 MPFB `.blend`나 슬라이더 설정 파일은 프로젝트에서 찾지 못했다.

## 준비 코드

- `scripts/prepare-hiker-revision.mjs`: GLB 버퍼를 읽어 형상·부착 노드만 수정한다. 세 입력을 모두 메모리에서 처리하고 삼각형 상한과 기존 애니메이션·스킨 메타데이터 동일성을 확인한 뒤 별도 검토 폴더에 저장한다. 검토 폴더가 있으면 중지한다. 입력 덮어쓰기·삭제·다운로드를 하지 않는다.
- `scripts/capture-hiker-revision.mjs`: 준비된 본체 검토 GLB를 별도 평면 장면에 표시해 정면+측면 1장과 3인칭 보행 1장을 촬영한다. 양손 노드의 실제 이동을 검사한다. 실행 전이며 실제 등산로 접지 검수를 대신하지 않는다.

출력 예정 폴더: `assets/realistic/models/hiker/review-v1/`. 현재 이 폴더와 아래 파일은 생성하지 않았다.

| 출력 예정 파일 | 대응 원본 |
|---|---|
| Hiker.glb | assets/realistic/models/hiker/Hiker.glb |
| hiker-170-lod0.glb | assets/hiker-170-lod0.glb |
| hiker-170-lod1.glb | assets/hiker-170-lod1.glb |
| revision-report.json | 입력별 전후 삼각형 수·증가율·모자 보정량 |

## 남성 체형·상의

원본 MPFB 성별·근육 슬라이더를 다시 조절하는 작업은 소스 부재로 미완료다. 준비 코드의 임시 대안은 본체와 상의·칼라·지퍼·스트랩에 같은 완만한 몸통 변형을 적용하는 것이다. Y=1.31m 중심 ±0.19m 영역에서 가슴 전방 돌출을 최대 18mm 완화하고 중앙 몸통 폭을 최대 3.5% 넓힌다. +Z가 앞이라는 본체 계약을 따른다. 정점 Y·뼈·동작 키·신발은 보존한다. 노멀은 재계산한다.

이는 **남성 MPFB 재생성 완료를 의미하지 않는다.** 원본 부위·형상·상체 자세에 따라 효과가 다르므로 정면·측면에서 몸과 상의 사이 틈, 가슴 윤곽, 배낭 스트랩 관통을 확인해야 한다. 원본 MPFB가 확보되면 성별 남성·근육 중간값을 시작점으로 상의 핏을 다시 맞추는 것이 우선이다. 임시 수치를 검증된 체형 값으로 채택하지 않는다.

## 모자

본체 모자 `Human.hat` 정점을 Head inverse-bind 좌표로 변환하고 Head 로컬 X/Z 경계 상자 중심을 0에 맞춘다. 높이는 유지한다. 원래 모자의 스킨 속성과 리그 루트 부착을 제거하고 `mixamorig:Head`의 강체 자식으로 옮긴다. Head 회전은 그대로 따라간다. 모자가 직접 애니메이션되는 입력이면 변환을 중단한다.

LOD 프록시는 `Hiker.Head`를 추가해 기존 모자를 상대 높이 0.1125m로 부착한다. 본체와 달리 원래 Head 뼈가 없으므로 이름만 Mixamo로 위장하지 않는다. 챙이 비대칭이면 경계 상자 중심이 착용 중심과 다를 수 있어 위·정면 캡처로 최종 조정해야 한다.

## 스틱 노드 계약

| 항목 | 왼쪽 | 오른쪽 |
|---|---|---|
| 스틱 루트 | HikingPole.Left | HikingPole.Right |
| 그립 기준점 | HikingPole.Left.Grip | HikingPole.Right.Grip |
| 끝 기준점 | HikingPole.Left.Tip | HikingPole.Right.Tip |
| 본체 부모 뼈(GLB 원본) | mixamorig:LeftHand | mixamorig:RightHand |
| three.js 뼈 이름 예상 | mixamorigLeftHand | mixamorigRightHand |
| 프록시 손 노드 | Hiker.Hand.Left (ArmL 자식) | Hiker.Hand.Right (ArmR 자식) |

스틱 전체 길이 **1.175m**(117.5cm). 스틱 로컬 -Y가 끝 방향이다. 그립 원점 `(0,0,0)`, 끝 `(0,-1.10,0)`, 상단 `(0,0.075,0)`으로, 그립~끝 거리는 1.10m이고 상단~끝이 전체 길이다. 본체 손 로컬 `(0,0.055,0)`에 붙이는 초기값을 준비했다. 손가락 사이 그립 중심은 실행 후 교정해야 한다. 원본 클립을 바꾸지 않고 손에 강체 부착하므로 별도 코드 없이 손을 따라 움직인다. 보행 중 스틱 끝을 지면에 고정하는 팔 IK는 이번 준비 코드에 포함되지 않는다.

한 자루는 6각 단면·4링·양끝 마개 **44삼각형**, 한 쌍은 **88삼각형** 추가다. 양쪽은 메시·재질 하나를 공유하고 텍스처는 추가하지 않는다. 재질 이름은 `HikingPole.Graphite`다. 입력의 실제 삼각형 수를 읽고 각 파일마다 전후 증가가 15%를 넘으면 출력 전에 중단한다. 아직 실행 전이므로 실측 전후 수치는 제공할 수 없다.

산개발은 로더 반환 `model.getObjectByName('HikingPole.Left.Grip')` 등으로 기준점을 찾는다. 스틱을 이미 포함한 GLB에는 런타임 스틱을 중복 추가하지 않는다. 월드 기준점은 `updateMatrixWorld(true)` 이후 `getWorldPosition`으로 읽는다. GLB의 +Z 전방, 앱의 모델 Y축 π회전은 기존 로더 그대로 유지한다.

## 호환성·검증

`HIKER_HEIGHT=1.7`, `ANIM_STEP=.6336`은 변경하지 않는다. 기존 Idle/Look/Walk/Stairs/Rock의 채널·샘플러·기존 스킨 데이터는 그대로 두고 출력 전 동일성을 검사한다. 실제 전신 높이, 몸통 수정 영향, 보행 접지와 관통, 스틱의 손 회전·등반 중 교차는 아직 미검증이다. 옛 프록시와 본체를 같은 리그로 바꾸지 않는다.

순서는 검토본 생성 → 보고서 삼각형 확인 → 정면·측면·보행 검수 → 평지·계단·바위 보행 회귀 → 테스트·빌드 → 검토본의 원본 교체다. 현재 런타임 파일은 바꾸지 않았다. 기존 `scripts/probe-hiker.mjs`와 `scripts/capture-hiker-third.mjs`는 원본 경로를 보기 때문에 검토본 승인·연결 뒤에만 최종 결과로 사용할 수 있다.

## 가정

- 원본 MPFB 소스가 없어 본체 변형은 검토용 대안으로 준비했다.
- 기존 두 프록시 LOD는 현재 계층·클립을 보존해야 한다.
- 손 로컬 그립 5.5cm, 117.5cm 길이, 흉부 변형 영역은 실행 후 육안 교정할 초기값이다.
- 추가 폴 형상은 자체 제작이며 외부 자료·새 텍스처·새 라이선스 의존성은 없다.

## 대표 확인 필요

스크립트 실행 금지 지시에 따라 다음 명령은 **요청하거나 실행하지 않았다**. 대표 확인 후 프로젝트 루트에서 순서대로 수행할 명령이다.

```sh
node scripts/prepare-hiker-revision.mjs
npm run dev -- --port 5175
PORT=5175 node scripts/capture-hiker-revision.mjs
npm test
npm run build
```

위 과정과 시각 검수 통과 뒤 원본 교체 명령(현재 실행 금지):

```sh
cp assets/realistic/models/hiker/review-v1/Hiker.glb assets/realistic/models/hiker/Hiker.glb
cp assets/realistic/models/hiker/review-v1/hiker-170-lod0.glb assets/hiker-170-lod0.glb
cp assets/realistic/models/hiker/review-v1/hiker-170-lod1.glb assets/hiker-170-lod1.glb
PORT=5175 node scripts/capture-hiker-third.mjs
```

이후 새 캡처를 `report_image`로 전달하고 본 작업 파일만 선별해 커밋해야 한다. 기존 작업 트리에 다른 담당자의 변경이 많아 일괄 스테이징은 하지 않는다. 삭제·배포·push·외부 전송은 하지 않았다.
