# 관악산공원 일주문·광장 및 구간별 풍경 보정

산풍경 · 2026-11-03. 실제 GPX 출발점 (37.46803, 126.946528)에 자체 제작 문을 배치했다. 건물의 치수·후면·세부 문양, 구간 시설 위치와 계곡 윤곽은 현장 실측 전 추정이다.

## 구현

- `assets/realistic/entrance-scenery.js`: 붉은 원기둥 2개, 주춧돌, 팔작 형태의 사면 지붕과 겹처마, 들린 처마 끝, 기와선, 녹색·청색 공포와 반복 단청 장식, 파란 바탕·흰 글씨 관악산공원 현판. 자체 CanvasTexture 외에 사진 텍스처 없음.
- 문 아래 노랑·주황 차단시설 4개. 중앙 GPX 진행선에는 1m 이상의 통로를 비웠다. 석재 원형 화분 3개와 꽃, 회색 포장 광장. 사진은 정면 비례만 참고했다. 문 폭·높이·회전은 추정이다. 현재 시안은 기둥 간격 6.1m, 처마 최대 폭 10.5m, 용마루 높이 약 5.61m다. 연구 문서의 치수 추정값과도 차이가 있으므로 현장 실측값으로 확정한 수치가 아니다.
- 입구 광장의 기존 장식 바위·나무·풀을 제거하고, 주변 65m 이내 소나무를 기존 CC0 활엽 모델로 재배정했다. 총 개체 수는 증가시키지 않는다. 실제 수종을 동정한 것은 아니다.
- `assets/realistic/section-scenery.js`: 호수공원 정자·수면, 계곡 물·바닥돌, 제1광장 갈림 표지와 벤치, 깔딱고개 중간 벤치, 능선의 연주암 표현을 추가했다. 각 구간의 바닥·나무·바위는 기존 노면과 식생 자산을 재사용한다. 정상 표지석·응진전·레이더·도시 전망은 기존 작업을 재사용한다.
- `assets/realistic/load-landscape.js`: 시설 생성·LOD 갱신·상태 통계와 광장 식생 비우기 연결. 입구 광장은 GPX 첫 점 고도로 수평 접합하고 외곽 10m에서 원지형으로 복귀하며, 정자·연주암·벤치·호수 받침도 국소 지면을 접합해 경사면 관통을 줄인다. 지형 원자료·GPX·계단 형상·보행 속도·실시간 날씨·스틱·앉기·달리기 코드는 변경하지 않았다.
- `src/realistic-models.js`: 기존 활엽 GLB로 입구 수목 재배정. `assets/realistic/generated/nature/forest-layers.js`: 광장 영역에 바람 풀을 생성하지 않는다. 이 생성 파일을 다시 만들 때에도 광장 제외 규칙을 유지해야 한다.
- `src/main.js`: `?entrancePhoto` 검수 화각. GPX 출발점 앞쪽 약 8.8m(왼쪽 0.8m 오프셋), 눈높이 1.6m, 수직 FOV 55도. 일반 보행 카메라와 별도이며 좌표 변경 API는 추가하지 않는다.

## 성능 설계

문·차단시설·화분은 색 재질별 병합. 근경 45m, 단순형 45~150m, 150m 밖 숨김. 포장 광장은 180m 밖 숨김. `src/terrain-base-mask.js`는 준비된 세밀 청크 안의 성긴 기본 지형 삼각형을 가려 포장·계곡 위를 가로지르던 면을 수정한다. 청크 해제 시 원래 인덱스를 복원한다. 추가 그림자 투사 없음. 입구 시설 근경 15,362삼각형/15메시(현판 포함), 단순형 2,318/14메시, 원거리 0. 광장 2,112삼각형. 현판 자체 생성 1024×256 RGBA8+밉 약 1.34MiB(각 LOD 현판 2장 합계 약 2.67MiB). 외부 이미지 파일 0장. 입구 반경 90m에서는 기존 거리 우선 선택에 식생 기본 패스 호출 상한(낮음 180/균형 330/높음 600)을 함께 적용한다. 처음 균형 입구 876회 중 숲이 766회였으므로, 가능한 LOD를 먼저 낮추고 먼 청크부터 제외해 전체 호출 예산을 확보한다. 이 제한은 호수~정상의 기존 LOD 선택에 적용되지 않는다.

구간 시설은 0/40/120m LOD, 계곡 물·돌은 80m 청크·150m 거리 제한. 기존 나무의 인스턴싱·GLB 캐시·LOD를 공유한다. 시설별 예산은 검사했으며 전체 장면은 아래 실측 표로 판단한다.

기존 작업 트리에는 다른 담당자의 대규모 미커밋 변경이 있었다. 전체를 커밋하거나 덮어쓰지 않았다. 산개발이 위 연결 지점과 신규 모듈을 기준으로 통합해야 한다.

현장 실측과 여섯 구간의 실제 사진 픽셀·촬영 위치·화각 대조는 완료되지 않았다. 이번 산리서치 문서의 캡션·본문 기반 특징표를 반영한 시안과 실행 결과를 전달한다. 실제 관악산을 아는 사람의 코스·시설·풍경 검수가 필요하다. 최종 높음 화질·CPU4배 및 긴 청크 경계 시험은 이번 측정 범위에 포함하지 않는다. 전체 자산·렌더 타깃 GPU 메모리 바이트 합계도 이번에는 감사하지 않았으므로 메모리 예산 전체 준수를 주장하지 않는다.

커밋·push·배포·회원가입·결제·외부 메시지 발송은 수행하지 않았다. 기존 개발 서버는 재사용했으며 종료하지 않았다.
