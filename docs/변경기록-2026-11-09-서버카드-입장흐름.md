# 변경 기록 — 서버 카드 고르기 입장 흐름 (등산·흡연장 공용), 2026-11-09

## 흐름
허브(`/`) → 체험 카드(등산 `/hiking/`·흡연장 `/smoking/`) → **(등산만) 산 고르기** → **서버 카드 화면** → 입장.

- 서버 고르기는 게임 안에 들어간 뒤 뜨는 작은 창이 아니라, **게임 화면을 가리는 불투명 전체 화면**(`data-mode=entry`)으로 먼저 뜹니다. 무거운 장면 로딩은 뒤에서 미리 읽고, 카드를 고르면 그 서버 방으로 바로 입장합니다(등산 `hiking:multi-join` + 출발 신호, 흡연장 `multi.join`).
- 서버 카드는 허브 체험 카드와 같은 모양(그림·이름·인원 막대·`들어가기 ▶`)이고 `SERVERS` 표의 서버마다 하나씩 생깁니다. 인원은 `/health`를 5초마다 다시 받습니다. 꽉 참(`n ≥ 정원`)이면 카드가 비활성이고 `꽉 참` 도장이 찍힙니다.
- 닉네임 칸(`gwanak-multi-name` 재사용)과 `혼자 걷기`/`혼자 피우기` 카드(단추)가 같은 화면에 있습니다.

## 직접 링크(`?multi=`)
- 고르기를 건너뛰고(`serverPickMode`='legacy') 그 방으로 바로 들어갑니다.
- 방 키가 서버 카드로 들어온 사람과 같도록 맞췄습니다(산개발 11-08 수정): 빈 `?multi=`와 옛 `gwanak-room-1`은 첫 서버 방(`관악산-1`·`옥상-1`), 흡연장 기본도 `옥상-1`. 서버는 끝 `-1`을 떼어 `hiking:관악산`·`smoking:옥상` 한 방으로 묶습니다.

## 알아 둘 것
- 서버 주소가 없는 빌드/링크에서는 서버 카드 화면에 `혼자 하기`만 보입니다(전에는 `이 브라우저 창끼리` 카드가 있었음). 같은 브라우저 창끼리 시험하려면 `?multi=방&server=off` 직접 링크를 씁니다.
- 커밋·push·배포는 하지 않았습니다.
