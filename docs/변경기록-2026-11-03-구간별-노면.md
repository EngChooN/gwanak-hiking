# 구간별 노면 추정 배정과 150분 보정

산개발 / 2026-11-03. 상태: 구현·정적 검증 완료, 전체 테스트·실측·화면 검수 대기. 커밋·push 없음.

## 적용 범위

기획 `기획-체감자료-반영-2026-11-03.md` §2의 구간 1~7을 반영했다. 환경음·정상 시설·외부 자료 조사는 이번 카드 범위에 넣지 않았다. 작업 중 공유 폴더의 기존 `artifacts/performance-after3/results.json`을 확인했으며, 균형 CPU4배 약24.7fps·최대1,518,929삼각형으로 선행 성능 목표는 미달이다. 높음 정지 최대도4,159,870삼각형이다. 이 자료는 이번 노면 변경을 검증한 결과가 아니며 작성자가 이번 턴에서 실행한 것도 아니다. 선행 완료 조건이 충족됐다고 보고하지 않는다.

설정은 `src/route-surfaces.js`의 `SURFACE_SECTIONS` 한 곳이다. **추정(후기 근거, 현장 확인 전)** 주석과 README 안내를 넣었다. CSV의 A코스 수평 거리 1,070/1,525/651/1,066/157/340/153m를 사용하고 총 4,962m에 대한 실제 투영 수평 전장 차이를 정규화했다. 노면 경계에서 선형 분할하며 원래 GPX 337점과 DSM 정렬 고도는 바꾸지 않는다. 체크포인트의 원래 점 인덱스와 거리는 별도로 보존했다.

CSV 환산 수평 길이는 포장749m, 흙1,679.85m, 돌1,213.05m, 계단1,126.3m, 암반193.8m다. 전체 비율은 약15/34/24/23/4%다. 이 값은 **설정표 산술 합계**이며 실제 3D 길이·현장 실측과 구분한다. 각 구간 안에서는 표에 적힌 재질을 나열 순서대로 연속 배치한다. 해당 순서도 추정이며 실제 계단 시작/끝 위치를 검증한 것이 아니다.

## 이동·ETA·발소리

계단은 기존 0.4198285364m/s·초당1.2걸음 모델을 유지한다. 새 배정의 `STAIR_SECONDS`와 `NONSTAIR_BASE_SECONDS`를 다시 합산해 `SPEED_CALIBRATION = NONSTAIR_BASE_SECONDS / (9000 - STAIR_SECONDS)`로 비계단 보정만 재계산한다. ETA와 실제 이동 모두 같은 `speedFor`를 사용한다. 150분 일치와 실제 이동 루프의 오차는 추가/기존 테스트로 확인하도록 했으며 **이번 실행에서 검증하지 않았다**. 이전 보정 계수와 계단17구간·391.55m 문장은 README에서 교체했다.

포장은 `paved`로 식별하되 돌길과 같은 속도 계수를 사용한다. 발소리 선택/재생 진입점에서 `paved→rock`으로 매핑해 기존 돌길 음원·선택 주머니를 공유한다. 새 음원과 외부 자산은 추가하지 않았다. 바닥은 회색 재질로 구분하고, 돌길·나무계단·암반은 기존 석재·목재·화강암 재질을 사용한다. 기존 로컬 자산의 출처/이용 조건 기록은 유지한다.

## 계단 형상과 성능

연속 경사 띠였던 계단 구간을 수평 디딤판과 챌면으로 만들었다. 수평 폭 최대30cm·단차 최대18cm로 세분하며 20~25% 경사에서는 약6~7.5cm 단차로 중심선을 따른다. 디딤판 높이는 양 끝 중 높은 곳 +1.5cm로 정해 지형 안에 묻히는 부분을 줄였다. 기존 삼각형 기반 `surfaceHeight`가 새 디딤판 높이를 읽어 눈높이·발 접지에 사용한다. 공칭18/30cm 속도 모델과 실제 경사에 맞춘 시각 형상은 구분한다.

단마다 객체를 만들지 않고 기존 100m 이하·재질 경계별 경로 메시 안에 병합했다. 원경·나무 LOD·지형 청크·품질별 성능 상한은 유지했다. 계단 형상으로 제출 삼각형이 추가되므로 **성능 예산 유지의 실측 통과를 주장하지 않는다**. after3 계측의 `등산로` 항목과 전체 최대를 다시 확인해야 한다. 급경사·재질 경계의 단차/연결부·측면 지형 관통과 보행 모양은 화면 검수 대기다.

## 검증 준비와 확인 결과

- 새 테스트: CSV 구간 길이·기획 비율·실제 할당 길이, 원본337점 보존, 구간 시간 합과 전장150분, 포장 속도/발소리 대체, 20~25% 상승·하강 디딤판의 수평성·폭·단차·raycast 높이.
- 기존 테스트 조정: 음원 은행 대응 검사는 포장→돌 매핑을 포함하며 음원35개 검사는 유지한다. 걸음 이벤트는 옛 기본 시작점의 특정 재질 목록 대신 실제 접지 위치의 재질과 비교한다. 실제 이동 루프/ETA 및 계단 cadence 기존 검사는 유지한다.
- `scripts/capture-route-surfaces.mjs`: 실제 경사20~25% 계단 구간을 찾아 같은 위치를 1·3인칭으로 캡처한다. 조건에 맞는 구간이 없으면 임의의 다른 경사를 검증한 것처럼 처리하지 않고 실패한다. `artifacts/route-surfaces/results.json`에 재계산 계수·계단 시간·구간별 시간과 오류를, 같은 폴더에 두 화면을 저장한다. 캡처만으로 시각 통과 판정을 자동 생성하지 않는다.
- 변경 JS의 `node --check`와 `git diff --check`를 통과했다. 이는 구문·공백 검사이고 테스트 실행을 대신하지 않는다. npm test·수치 측정·브라우저 실행·새 화면 보고는 미실시다.

## 가정

구간 경계는 CSV 수평 누적 거리 기준이며 CSV 반올림 오차는 전장 정규화한다. 구간 안 재질의 연속 배치 순서, 계단 치수와 위치는 추정이다. 포장은 기존 돌길 음원을 재사용한다. 앞선 성능 작업은 코드 반영을 마친 것으로 보고 이번 구현을 이어갔으나, after3 검증 완료를 선행 조건으로 하는 업무의 최종 완료는 아직 보류한다.

## 대표 확인 필요

사용자 지시에 테스트·측정 직접 실행 요청이 있지만, 현재 상위 개발자 지시의 “스크립트 실행 같은 위험 작업은 하지 말고 … 명령을 남기세요”가 유지돼 아래 명령은 실행하지 않았다. 확인 질문은 올리지 않았다. 서버를 시작하지 않았으므로 이번 턴에서 종료할 서버는 없다.

```sh
cd /Users/joonyoung/gwanak-hiking
export PATH="$HOME/.nvm/versions/node/v24.22.2/bin:$PATH"
npm test
npm run dev -- --port 5176
# 별도 터미널: 선행 성능 검증 및 새 노면의 예산 확인
LABEL=after3 HEADED=1 node scripts/benchmark-performance.mjs
BASE_URL=http://127.0.0.1:5176 HEADED=1 node scripts/capture-route-surfaces.mjs
# 개발 서버 터미널에서 Ctrl-C로 종료
```

실행 결과에서 전체 테스트 통과, 실제 이동135~165분·ETA 일치, 성능 예산, 계단1·3인칭 외형을 확인한 뒤 보고서를 갱신하고 화면을 첨부해야 한다. 커밋·push 금지는 유지한다.
