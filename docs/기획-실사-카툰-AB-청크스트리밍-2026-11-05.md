# 기획: 실사·카툰 A/B 모드 + 200m 청크 스트리밍 (2026-11-05)

작성: 산기획 · 상태: 진행 중 (자율 진행, 대표 부재)

## 1. 목표
1. **A/B 모드**: 첫 화면(순수 HTML/CSS)에서 `실사(realistic)` / `애니메이션(toon)` 선택 → `localStorage`에 저장 → 선택한 모드의 코드·에셋만 네트워크로 받는다.
2. **청크 스트리밍**: 지형·길·식생을 200m 격자 파일로 나눠 내보내고, 카메라 주변 청크만 불러오며 멀어진 청크는 씬에서 빼고 geometry·material·texture를 `dispose()`한다.
3. **카툰 비주얼**: 젤다 BotW(툰 음영·부드러운 외곽선·덩어리 식생) + 신카이(블룸·시간대 색보정·푸른 그림자·파스텔 도심 원경·밤 창문 불빛).
4. **테스트**: 실사 모드 기존 테스트 100% 통과 + 청크 로딩 완료 대기 + 카툰용 Playwright 세트와 새 기준 스냅샷.

## 2. 공통 규약 (모든 담당이 이 이름을 그대로 쓴다)

### 2.1 모드 결정 — `src/graphics-style.js` (산개발)
- 키: `GRAPHICS_STYLE_KEY = 'gwanak-graphics-style'`, 값 `'realistic' | 'toon'`.
- 우선순위: `?style=realistic|toon` → localStorage → 선택 화면.
- **자동화 브라우저(navigator.webdriver)·`?style` 없음 → `realistic`** (기존 40여 개 캡처·검증 스크립트를 그대로 통과시키기 위한 기본값).
- `window.hiking.style` 에 현재 모드 노출. `document.documentElement.dataset.style` 도 설정.

### 2.2 진입점 — `src/boot.js` (산개발) / 선택 화면 마크업 — `index.html` (산디자인)
- `index.html`의 `<script type="module" src="/src/boot.js">` 하나만 둔다. boot.js는 three를 import하지 않는다.
- 선택 화면 DOM: `#style-chooser` (버튼 `[data-style="realistic"]`, `[data-style="toon"]`, 기억 체크 `#style-remember`). boot.js는 `resolveStyle()` → 필요하면 `#style-chooser`를 보여 주고 클릭을 기다린 뒤 → `import('./main.js')`.
- 바꾸기: 지도(M) 대화상자 안 "그래픽 모드 바꾸기" 버튼 → localStorage 지우고 새로고침.

### 2.3 코드 분할
- 실사 전용: `assets/realistic/terrain-material.js`(PBR 셰이더), PBR 텍스처 로드, HDR, SSAO.
- 카툰 전용: `src/toon/**` — main.js는 `style==='toon'`일 때만 `await import('./toon/index.js')`.
- 공용 로직(경로·높이·시설 배치·이동)은 그대로 공유. `loadLandscape({..., style, materialFactory})`로 재질만 갈아 끼운다.
- 실사 모드에서 `/assets/toon/`·`src/toon` 청크, 카툰 모드에서 `*-diff.jpg`·`*-nor_gl.png`·`*-rough.jpg`·`.hdr`·`/assets/realistic/generated/nature/`가 **요청되지 않아야** 한다 (`scripts/verify-style-network.mjs`로 검사).

### 2.4 에셋 디렉터리
| 경로 | 내용 | 모드 |
|---|---|---|
| `assets/shared/chunks/index.json` | 200m 청크 목록 | 공용 |
| `assets/shared/chunks/terrain/{i}_{j}.f32` | 청크 높이(원본 near 격자 표본 그대로, 경계 1칸 포함) | 공용 |
| `assets/shared/chunks/route/{i}_{j}.json` | 그 청크를 지나는 등산로 점(OSM/GPX 경로 인덱스 범위) | 공용 |
| `assets/shared/chunks/vegetation/{i}_{j}.json` | 식생 배치(종류·x·z·scale·yaw) | 공용 |
| `assets/realistic/**` | 기존 PBR 텍스처·GLB (변경 없음) | 실사 |
| `assets/toon/nature/*.glb`, `assets/toon/models/hiker/Hiker.glb` | 텍스처를 뺀 단색(평균색)·정점색 GLB | 카툰 |
| `assets/toon/gradients/*.png` | 3단 gradientMap | 카툰 |

`index.json`: `{schemaVersion:1, chunkSize:200, spacing, origin:{x0,z0}, cols, rows, chunks:[{id:'i_j', i, j, x0, z0, files:{terrain, route, vegetation}, counts:{...}}]}`

### 2.5 청크 스트리머 — `src/chunk-stream.js` (산리서치)
```js
createChunkStreamer({chunkSize=200, radius=1, unloadRadius=radius+1, load:async(chunk,signal)=>Object3D|null, attach:(obj,chunk)=>void, chunks:index.chunks})
  .update(position)          // 대기열 갱신, 프레임당 최대 1개 attach
  .ready(position?) -> Promise // 해당 위치의 radius 안 청크가 모두 붙으면 resolve
  .status() -> {loaded, pending, inFlight, disposed:{geometries,materials,textures}, ids:[]}
  .dispose()
disposeObject3D(root, {keep:Set}) // geometry·material·texture를 dispose. userData.shared===true 또는 keep에 든 자원은 건너뜀
```
- 언로드 히스테리시스: `unloadRadius`(기본 radius+1) 밖으로 나간 청크만 해제 → 경계에서 왕복해도 깜빡이지 않는다.
- 로딩 중 청크가 범위를 벗어나면 `AbortController`로 취소.

### 2.6 카툰 모듈 인터페이스 — `src/toon/index.js` (산풍경)
```js
export async function createToonStyle({renderer, scene, camera, mobile}) => {
  materialFactory,                 // loadLandscape용: {terrain(), trail(kind), basic(color), water()} — fetch 없음
  toonify(root, {kind}),           // Standard/Physical → MeshToonMaterial 변환(색·정점색·alphaTest·instancing 유지)
  createSky(), updateSky(env, sunVector, moonVector),
  styleCity({material, nightLights}),  // 파스텔 매트 + 밤 창문 불빛
  patchFoliage(material),          // 기존 바람 버텍스 셰이더 유지 + 바람결 색 물결 프래그먼트
  pipeline: {resize(quality,w,h,dpr), update(env), render()},  // RenderPass→Outline→Bloom→Grade→Output
  status
}
```
- `env`는 `src/environment.js`의 `environment.update(dt)` 결과(시각·날씨·night·elevation) 그대로.

### 2.7 아트 디렉션 수치 (카툰)
- 음영: MeshToonMaterial + 3단 gradientMap (NearestFilter, 값 예: 0.35 / 0.7 / 1.0).
- 외곽선: 화면 공간 깊이·법선 가장자리 검출 1패스, 두께 1px(고화질 1.5px), 색 낮 `#3b2f2a`(어두운 갈색)·밤 `#1d2a44`(남색), 거리별로 옅어짐(원경 0).
- 식생: 잎 텍스처 대신 덩어리 단색 + 위쪽 밝게/아래쪽 어둡게 그라데이션; 풀밭은 바람 방향 사인 물결 색(연두↔청록).
- 블룸: 낮 threshold 0.85 / strength 0.35, 노을 0.7 / 0.6, 밤 0.55 / 0.9 (별·창문·가로등).
- 색보정: 낮 청량(채도 1.15, 하늘 `#4fa8e8`), 노을 앰버 `#ffb36b`+보라 `#8a6bbf`, 밤 네이비 `#16224a`. 그림자 영역 틴트 청록 `#5f8fb0`.
- 도심: MeshBasic 파스텔(먼지 낀 `#c9c3d6`~`#e6d8c8`), 거리 안개 강하게, 밤에 창문 격자 셰이더로 노란 `#ffd27a` 불빛(건물마다 무작위 켜짐 35~60%).

## 3. 범위 밖 / 가정
- 보행·시설 배치용 **높이 조회는 기존 near 격자(1.1MB, 렌더 자원 아님)를 전역 색인으로 유지**한다. 스트리밍·해제 대상은 WebGL 자원(지형 메시·식생 인스턴스·풀·텍스처)이다. 정상 시설 배치·계단 몸체가 처음부터 정확한 높이를 써야 하고, 실사 모드 기존 동작 100% 유지가 조건이라서다.
- 서울 원경(도시 건물 14+14+4 파일)은 정상 전망용이라 기존 방식(원경 스트리밍) 유지. 카툰 모드는 같은 자료를 파스텔 재질로 그린다.
- 실제 배포·push는 대표 확인 후.
