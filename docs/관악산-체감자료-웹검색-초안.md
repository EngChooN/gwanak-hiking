# 관악산 실제 등산 체감 — 웹 검색 초안

작성: 산기획 · 2026-11-03 · 공개 웹 검색 결과 요약. 산리서치가 구간별로 보강할 예정(현장 검증 전).

## 우리 코스(관악산공원 입구 → 호수공원 → 계곡길 → 제4야영장 → 깔딱고개 → 연주대)와 맞는 내용

| 구간 | 웹에서 확인된 느낌 | 게임 반영 포인트 |
|---|---|---|
| 입구~호수공원 | 서울대 정문 옆 관악산 입구에서 출발. 갈림길에서 좌측으로 가서 호수공원을 지나 계곡길로 감 | 평탄한 정비길, 호수·사람 많음 |
| 계곡길~제4야영장 | "잘 정비된 전형적인 계곡길" | 물소리, 돌길, 완만한 오르막 |
| 깔딱고개 | 연주대 시작점~정상 약 2km에 85분 정도. 계단과 바위가 많아 힘들게 느껴짐 | 계단 비율과 경사를 높이고 걸음을 느리게, 숨소리 추가 검토 |
| 능선·정상부 | 정상부 바위가 "갓을 쓴 듯한" 형상. 화강암 암릉이 대표 경관(육봉·팔봉능선) | 암릉 노멀맵, 바위 실루엣 |
| 연주대 | 절벽 위에 석축을 쌓고 작은 기와집을 올림(비둘기집을 닮았다고 함). 정상 조망이 좋음 | 시설 모델링 1순위 |
| 정상 | 표지석은 629m(인터넷에는 632m). 흰 공 모양 기상 레이더(레이돔) 때문에 출입 불가 구역이 있음 | 레이돔을 랜드마크로, 표지석은 너럭바위 위 |
| 공통 | 주말에 붐빔, 정상 CCTV, 길이 미끄러움, 겨울에는 아이젠 필요 | 혼잡 정도, 노면 재질 |
