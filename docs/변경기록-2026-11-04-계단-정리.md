# 변경 기록 2026-11-04 — 계단 정리(정상 계단 제거·코스 계단 지면 밀착)

2차 품질 개선 요구 1·4번입니다. 담당은 산풍경입니다.

## 1. 정상 계단 제거 (요구 1)
- `src/route-surfaces.js`: 7구간(정상 직전 153m)의 노면을 `암릉 60% + 계단 40%`에서 `암릉 60% + 돌길 40%`로 바꿨습니다.
  - 정상석 앞 나무·돌 계단이 있던 코스 5,001~5,067m(HUD 표시 약 5,027~5,093m)는 이제 바위·흙 맨 지면입니다.
- 정상 자유 이동 구역, 정상석·스탬프함(stamp-6)·정상 안내판의 자리는 경로점과 정상석 기준이라 그대로입니다.
  - `tests/summit-free.test.mjs`, `tests/interaction-props.test.mjs` 모두 통과했습니다.
- 계단 걸음 소리·속도는 노면 재질을 따르므로, 이 구간은 자동으로 돌길·암릉 걸음으로 바뀝니다.
- 남은 계단 구간은 3곳이고 모두 3,073~4,691m에 있습니다(돌계단 2곳, 나무계단 1곳). 정상 150m 안에는 계단 단이 없습니다(테스트로 확인).

## 2. 떠 있는 계단 제거 (요구 4)
- **지형 비우기 방식 변경** (`assets/realistic/terrain-clearance.js`)
  - 예전 방식: 디딤판 주변 2m 삼각형을 그 안의 가장 낮은 단보다 0.12m 아래로 파냈습니다. 그래서 경사 계단 아래와 옆에 최대 1m가 넘는 도랑이 생겨 계단이 떠 보였습니다.
  - 지금 방식: 꼭짓점을 주변 경로 구간의 경사면들(노면 띠의 실제 가로 방향을 따름) 중 최솟값보다 0.12m 아래로만 낮춥니다.
    - 곧은 계단은 경사선 바로 아래까지만 낮추고, V자로 꺾이는 곳도 지형이 디딤판을 뚫지 않습니다.
- **계단 몸체 추가** (새 파일 `assets/realistic/stair-base.js`)
  - 디딤판마다 양옆 측벽을 땅까지 내리고, 계단 띠 양 끝은 끝면으로 막았습니다.
  - 측벽은 드러난 높이의 절반만큼 바깥으로 비스듬히 내려(최대 0.6m) 둔덕처럼 땅과 만납니다. 아래 끝은 지면보다 0.12m 아래에 묻힙니다.
  - 측벽 재질은 돌계단이 돌, 나무계단이 흙입니다.
  - 걷는 면(노면 띠)과 충돌 대상은 바꾸지 않았습니다.
  - 크기: 계단 3,575단, 메시 16개, 삼각형 21,464개입니다. 100m 이상 떨어지면 일반 절두체 컬링으로 빠집니다.
- `load-landscape.js` 연결
  - `status.stairBase`에 개수를 넣었습니다.
  - `stairBaseCheck(ground?)`로 전 계단을 검사할 수 있고, `stairBaseLayout()`을 공개했습니다.

## 3. 자동 검사
- `tests/stair-base.test.mjs`
  - 정상 7구간에 계단이 없는지 확인합니다.
  - 실제 코스(route.json)의 모든 계단 구간을 성토 1.2m, 절토 2m, 굴곡 ±1.5m 합성 지형에서 검사합니다. 기준은 측벽·끝면 아래 끝과 지면 사이 틈 0.05m 이하, 지형이 디딤판 위로 솟지 않음, 측벽이 디딤판 위로 올라오지 않음입니다.
  - 걷는 면 높이와 디딤판 높이의 차이가 0.01m 미만인지 확인합니다.
- 브라우저 실측 (`scripts/capture-stairs.mjs`, 결과 `artifacts/v2/stairs/results-after.json`)
  - 실제 최종 2m 지형으로 전 계단 3,575단을 검사했습니다. 틈 최대 **−0.011m**(전부 땅속), 지형은 디딤판보다 최소 **0.136m 아래**에 있습니다. 검사 시간은 178ms입니다.
  - 장면 6곳에서는 지금 올라온 청크 기준 걷기 지형(walking-ground)으로 다시 쟀습니다. 틈 최대 −0.011m이고, 빠진 표본은 0입니다.
  - 모든 장면에서 콘솔 오류와 셰이더 오류는 0건입니다.
- `npm test` 372개 통과, `npm run build` 통과.
