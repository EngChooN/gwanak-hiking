# 변경 기록 · 2026-11-08 · 함께 걷기 서버(1차: 직접 만든 WebSocket)

작성: 산개발 · 상위 업무: 함께 걷기 서버 붙이기 1/3단계 (랩장 산기획) · 커밋·push·배포 안 함

## 무엇이 문제였나
- 함께 걷기는 같은 브라우저 창끼리(BroadcastChannel)만 됐습니다. 휴대폰과 PC처럼 **서로 다른 기기에서는 서로 보이지 않았습니다.**
- 들어가는 방법이 주소(`?multi=`)뿐이었습니다. §3 규칙("모든 기능은 HUD 버튼으로")에 어긋났습니다.
- 동물이 놀라 달아나는 반응은 각자 화면에서만 일어났습니다. 그래서 같은 방 사람끼리 화면이 달랐습니다.
- 작업 중 발견: 같이 셀카를 수락한 쪽을 요청자 옆으로 옮길 때, 산길에서는 **정상으로 순간이동**했습니다. 코스 투영이 정상 앞 130m만 찾았기 때문입니다.

## 바꾼 것
### 서버 (`server/`)
- `ws.mjs`: Node 내장 `http`·`crypto`로 만든 최소 WebSocket입니다. 핸드셰이크, 텍스트 프레임, 마스킹 해제, 길이 125·126·127, ping/pong, close를 다룹니다. 바이너리·조각난 메시지는 1003으로 닫고, 4KB 넘는 프레임은 1009로 닫습니다. 못 받고 쌓인 데이터가 1MB를 넘으면 끊습니다.
- `rooms.mjs`(순수 모듈): 소켓·파일·타이머가 없어 시험에서 바로 부릅니다.
  - **방 배정:** 한 방 20명입니다. 차면 `방이름-2`, `-3` … 으로 보내고, 빈자리가 생기면 기본 방부터 채웁니다.
  - **임시 ID:** 서버가 발급하고, 받은 메시지의 `id`는 서버가 덮어씁니다(사칭 방지).
  - **속도 제한:** 위치는 초당 15회, 그 밖의 메시지는 초당 20회까지 받습니다.
  - **순간이동 거부:** 위치는 `여유 2m + 12m/s × 경과 시간`까지 움직일 수 있습니다. 그보다 크면 버립니다. 구간 이동 표시(`FLAG.jump`)가 붙은 이동은 1초에 한 번 허용합니다. 표시 없이 3초 넘게 같은 자리를 보내면 다시 맞춰 줍니다(정상 클라이언트가 표시를 빠뜨린 경우).
  - **10Hz 스냅샷:** 바뀐 위치만 하나로 묶어 방 전원에게 보냅니다(JSON은 한 번만 만듭니다). 3초마다 이름 목록도 함께 보냅니다.
  - **중계:** 인사·손 흔들기는 방 전체에, 셀카 요청·수락·거절·끝은 받는 사람에게만 보냅니다. 다른 방에는 가지 않습니다.
  - **동물 놀람 중계:** `{zone,slot,i,kind,at,x,z}`를 받습니다. 같은 방에서 같은 동물은 30초에 한 번만 중계합니다(먼저 온 것).
  - **이름 재검사:** `sanitizeName`을 재사용하고, 금칙어는 환경 변수로 받습니다. 방 이름은 영문·숫자·한글·`-`·`_`, 24자로 정리합니다.
  - **신고:** JSONL로 남기고, 같은 사람이 같은 대상을 거듭 신고하면 한 번만 셉니다. 서로 다른 3명이 24시간 안에 신고하면 이름표를 24시간 숨기고 다른 방으로 옮깁니다. 숨김은 같은 곳(IP 해시)에서 다시 들어와도 이어집니다.
  - **재접속:** 60초 안에 resume 토큰으로 다시 붙으면 같은 ID·같은 방입니다.
- `multi-server.mjs`
  - **열기:** http로만 열고, `/health`는 200과 방 수·접속자 수를 돌려줍니다. 업그레이드는 경로를 보지 않습니다.
  - **환경 변수:** `PORT`·`HOST`·`DATA_DIR`·`ALLOWED_ORIGINS`·`TRUST_PROXY`·`MAX_PER_ROOM`·`MAX_CLIENTS`·`MAX_PER_IP`·`BANNED_WORDS`.
  - **연결 관리:** 20초마다 ping을 보내고 두 번 답이 없으면 끊습니다. 10초 안에 첫 인사(hello)가 없으면 끊습니다.
  - **기록:** 1분 요약 로그를 남기고, 90일 지난 신고는 시작할 때와 하루마다 지웁니다. SIGTERM을 받으면 정상 종료합니다.
  - **IP:** 프로세스마다 바뀌는 비밀 값으로 해시한 값만 메모리에 둡니다. 디스크와 로그에는 쓰지 않습니다.
- `Dockerfile`(node:24-alpine, 의존성 없음, `/data` 볼륨, HEALTHCHECK, `USER node`)과 `Dockerfile.dockerignore`(필요한 파일 4개만 보냄). 빌드·실행은 하지 않았습니다.
- `package.json`: `npm run server`와 `npm run multi:server`(같은 명령).

### 클라이언트
- `src/multi-transport.js`
  - **`createWebSocketTransport(url,{room,name})`:** BroadcastChannel과 같은 `{send,onmessage,close}` 모양에 `onstatus`·`status`·`info`가 더해졌습니다. 서버의 묶음(snap)은 풀어서 한 줄씩 넘기므로 `multi-client.js`가 받는 메시지는 예전과 같습니다.
  - **재접속:** 0.5초부터 두 배씩, 최대 15초까지 늘리며 ±20% 흔들어 다시 붙습니다. 이때 resume 토큰을 보냅니다. '꽉 참'이면 30초 뒤에 다시 시도합니다. 연결이 거부되면 error만 오고 close가 오지 않는 구현(Node 22)도 처리합니다.
- **`multiServerUrl`:** `?server=`를 먼저 보고, 없으면 `VITE_MULTI_SERVER_URL`을 봅니다. 둘 다 없거나 `off`이면 null(= BroadcastChannel)입니다. `https://`는 `wss://`로, `http://`는 `ws://`로 바꿉니다. 그래서 터널 주소를 그대로 붙여 넣어도 됩니다.
- `src/multi-client.js`
  - **상태:** `hiking:multi-status {state,room,count,transport}`를 바뀔 때만 보냅니다. 연결 상태는 화면 위 알림으로도 띄웁니다. 다시 연결 중·꽉 참은 계속 띄워 두고, 연결됨·끊김은 잠깐 띄웁니다. 산디자인 HUD가 생기면(`body[data-multi-entry]`) 이 알림은 띄우지 않습니다. 패널 아래 줄에도 상태를 씁니다.
  - **ID:** 서버가 준 ID를 씁니다(`createSocial`의 `id`는 함수도 받도록 바꿨습니다).
  - **순간이동 표시:** 0.1초에 2m 넘게 옮기면 `FLAG.jump`를 붙입니다.
  - **신고:** 서버로도 보냅니다.
  - **이름표 숨김:** 숨김 표시(`h`)가 붙은 사람은 이름표에 이름을 쓰지 않습니다.
  - **방 재배정:** `moved`를 받으면 목록을 비웁니다.
  - **나가기:** `dispose()`가 화면 요소·모델·수신기를 떼고 연결을 닫습니다.
  - **배낭 버튼:** HUD로 들어와도 배낭 → 함께 걷기 버튼이 보이게 `nb-multi`를 붙였습니다.
- `src/main.js`: `hiking:multi-join {room,name}` / `hiking:multi-leave`를 받아 주소 없이도 중간에 참가하고 나갑니다. 여러 번 눌러도 차례대로 처리합니다. `src/multi-entry-ui.js`가 생기면 `import.meta.glob`으로 자동으로 불러와 `installMultiEntry({serverUrl})`를 부르고, 현재 상태를 한 번 다시 보냅니다. 파일이 없어도 빌드는 됩니다. 같이 셀카 자리를 옮길 때 코스 전체에서 가장 가까운 지점을 찾게 고쳤습니다(`projectToRoute(x,z,0)`).
- `src/summit.js`: `projectToRoute(x,z,from)`에 찾기 시작점을 받는 인자를 더했습니다. 기본값은 예전과 같습니다.
- `src/device-profile.js`: `multiFullCap`(휴대폰 2, PC 4).

### 동물 놀람 중계 (`src/trail-world.js`)
- **보내기:** 출현 동물(id가 `구역@시간칸#칸번호`)이 이 화면에서 달아나기 시작하면 `hiking:animal-startle`을 보냅니다. 대상은 토끼 달아남, 까치 날아오름, 다람쥐가 모자에서 달아남, 고양이가 쓰다듬기 뒤 떠남입니다. 임시 동물(벤치 고양이)과 검수용으로 부른 동물은 보내지 않습니다.
- **받기:** `hiking:animal-remote`를 받으면 같은 동물이 같은 반응을 합니다. 방향은 보낸 사람 자리의 반대쪽이고, 늦게 받은 만큼(최대 0.5초) 앞당깁니다. 그 동물이 지금 보이지 않으면 같은 시간 동안(다람쥐 40초·고양이 60초·토끼 40초) 나오지 않게 합니다. 받은 반응은 다시 보내지 않습니다.
- 출현 목록과 배회 계획(결정적 난수)은 건드리지 않았습니다. 같은 구역·시간 칸이면 여전히 같은 동물입니다.

## 가정
- 서로 다른 신고자는 **접속 ID 기준**으로 셉니다. 시험이 모두 127.0.0.1이라 IP 기준으로는 셀 수 없었습니다. 운영에서 IP 기준으로 바꿀지는 검토가 필요합니다.
- 숨김 상태인 사람이 다시 들어오면 원래 방은 피합니다.
- 서버 전체 동시 접속은 400명, 같은 IP는 32명으로 잡았습니다(같은 와이파이 여러 사람을 생각했습니다).
- `ALLOWED_ORIGINS`가 비어 있으면 모두 허용하고 경고를 냅니다. Origin 머리말이 없는 접속(앱·시험 도구)도 허용합니다.
- HUD 참가 화면은 산디자인 몫입니다. 그 전에는 패널 아래 줄과 화면 위 알림으로 상태를 보여 줍니다.
- 주소에 `multi`가 있을 때만 자동 저장을 끕니다(예전과 같음). HUD로 중간에 참가하면 저장은 그대로 합니다.
