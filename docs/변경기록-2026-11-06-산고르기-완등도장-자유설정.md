## 무엇을 만들었나

### 1. 산 고르기(첫 화면)
- 들어오면 `어느 산에 오를까요?` 화면이 뜹니다. 산 목록은 `src/mountains.js` 배열이고, 지금은 관악산 한 곳입니다. 산을 더 넣으면 카드가 늘어납니다(세로는 아래로, 가로·PC는 옆으로). 산이 한 곳이면 옆에 `⛰ 다음 산 준비 중` 점선 칸이 있습니다.
- 카드: 계절 그림(나무 색 = 계절, 하늘 = 낮·노을·밤), 이름·632 m·코스, 완등 도장 자리, 거리 5.1 km · 예상 2시간 30분 · 스탬프 6곳 · 난이도 보통, 기록 한 줄, `▶ 오르기`(이어할 기록이 있으면 `▶ 이어 오르기`)와 `🎛 자유 설정`.
  - 스탬프 수는 사양 시안의 5곳이 아니라 게임 안 실제 스탬프 수(`STAMPS`, 정상석 포함 6곳)를 씁니다.
- 로딩은 이 화면 뒤에서 예전처럼 진행합니다(메모리 변화 없음). `▶ 오르기`가 출발 신호(`hiking:start`)를 보내고, 로딩이 덜 끝났으면 로딩 화면이 보였다가 끝나면 바로 출발합니다.
- 건너뛰기: `?pick=off`. 자동화 브라우저(Playwright)는 `?pick=on`일 때만 보이게 해서 기존 점검 스크립트가 그대로 돕니다.
- 산 고르기 화면이 떠 있는 동안 뒤 로딩 카드는 감춥니다(글자가 비쳐 보이던 문제).

### 2. '등산 완료' 도장
- 정상에 닿아 정상 도착 창이 뜨는 순간 `localStorage`의 `gwanak-summits`에 `{first, count, bestSec, last}`를 저장합니다.
- 도장은 SVG 한 장입니다(두 줄 원·관악산·등산 완료·처음 오른 날짜, 두 번째부터 `×n`). 그림 파일이 없어 메모리 부담이 없습니다.
- 찍히는 곳: 산 고르기 카드, 지도(M) 오른쪽 아래(부제 `… · 등산 완료`와 기록 한 줄), 정상 도착 창(1.2초 찍히는 동작 + 휴대폰 진동 15ms + `🎛 자유 설정이 열렸어요 · 열어 보기 ›`), 설정 탭 자유 설정 항목(작은 도장).
- **가장 빠른 기록은 처음부터 오른 경우만 셉니다.** `?start=demo|summit`, 지도의 545m 출발, 구간 이동, 자유 설정의 중간 지점 출발은 완등 횟수는 세지만 시간은 넣지 않습니다(`state.shortcut`). 중간 출발로 `0:00:01` 같은 기록이 생기던 것을 막았습니다.
- 구간 이동으로 바로 정상에 가면 도착 창이 뜨지 않으므로 완등으로 치지 않습니다.
- 개발 버전에는 설정 탭 개발용 칸에 `🧽 완등 기록 지우기`가 있습니다.

### 3. 자유 설정판
- 설정 탭 맨 위 `🎛 자유 설정` 항목 → 옆 시트(`data-sheet="free"`). 산 고르기 카드, 정상 도착 창, 지도(`🎛 자유 설정에서 더 고르기`), 직접 고른 상태의 시각·날씨 꼬리표에서도 같은 판이 열립니다.
- 칸: 날씨 5(맑음·흐림·비·눈·안개) · 시간 3(낮·노을·밤) · 계절 4(봄 벚꽃·여름·가을 단풍·겨울 눈) · 출발 지점 8(구간 이동 목록 + 정상) · `현재 그대로`.
  - 고른 칸은 빨강, 실제 값 칸은 점선 + `지금` 표시. 같은 칸을 다시 누르면 그 칸만 실제 값으로 돌아갑니다.
- **바로 적용, 다시 로딩 없음, 일시정지 없음.**
  - 시간: 기존 `?time=` 처리를 그대로 씁니다. `daytime.js`에 덮어쓰기 하나(`setTimeOverride`)를 두고, 환경·밤 조명·도심 불빛 세 곳이 `?time=`과 같은 길로 읽습니다. 낮 = 12:00, 노을 = 그날 해 높이 3°가 되는 시각(11/6은 17:10), 밤 = −14° 아래(11/6은 18:40). 날짜마다 계산해서 여름에도 노을이 노을로 보입니다.
  - 날씨: 기존 `?weather=` 처리(weather.js)에 `setOverride(kind)`를 더했습니다. 고른 동안에도 실제 날씨는 10분마다 받아 `지금` 표시에 씁니다. 지우면 실제(또는 `?weather=`) 날씨로 돌아갑니다.
  - 계절: `hiking:free-settings`의 `season` → 산풍경의 계절 전환(1~2초).
- 출발 지점: 고른 뒤 `📍 여기서 다시 출발`을 눌러야 옮겨 갑니다. 진행 기록(걸은 거리·시간)은 새로 시작하고 완등 도장은 그대로입니다. 산 고르기에서 고르면 `▶ 이대로 오르기`로 그 자리에서 출발합니다.
- 저장: 고른 값은 `sessionStorage`(같은 탭에서 다시 열려도 유지 — 아이폰이 탭을 다시 열어도 그대로). 새로 들어오면 현재 그대로입니다.
- 잠김: 빈 도장 자리, `정상까지 x km · 스탬프 n / 6`, 흐린 미리보기(누를 수 없음). 산 고르기 카드의 `🔒 자유 설정`은 `🔒 연주대에서 완등 도장을 받으면 열려요` 알림만 2.6초 띄웁니다.
