# 확정값 반영 및 산풍경 자산 통합

담당: 산개발 · 2026-11-02

- 기획서 3-1 공식 목표 150분, 허용 135~165분(일시정지 제외)을 적용했다. 기존 2시간 비교를 폐기했다.
- Tobler·노면 비율·4700m 경로를 유지하고 전체 속도 계수 .6572를 곱했다. 보정 전 98.5775분/150분이 근거다. 시뮬레이션은 8999.77초(150.00분), 정상 접근 22.94분이다.
- 데크 평탄 .95·데크 계단 .75를 게임·자산 데이터·생성기에 반영했다.
- 제1광장·아카시아동산·제4쉼터·연주샘·제3깔딱고개는 임시 거리 비율 16/32/55/78/92%에 배치했다. 위치·고도는 실측 확인 대기다. 안정 ID를 방문 기록에 저장하고 이어하기 안내에 지점명을 사용한다. 기존 숫자 인덱스는 장소 오인을 막기 위해 비우되 위치·시간은 보존한다.
- 산풍경 로더와 정상 접근 LOD1·캐릭터 LOD0 GLB를 게임에 연결했다. 정상 접근 전의 합성 청크를 경계에서 잘라 중첩을 피하고 캐릭터 여유 반경을 .25m로 맞췄다. 배포 빌드에 GLB·manifest·data 복사를 추가했다.
- 거리 기반 동작 5종과 발바닥 지지 높이·두 관절 보정을 연결했다. 112단 × 5동작 × 8위상에서 메쉬 발바닥 높이를 검사했다. 실제 GLB 단 윗면과 바닥 높이를 별도 광선 교차로 대조했다.
- npm test 11개와 빌드 통과. 브라우저 결과 및 캡처는 artifacts/browser-verification.json, 통합 보고서는 artifacts/구현-검증-보고.html을 참조한다.

실제 GPX·DEM·노면 교체 후 시간 계수를 재산정한다. 경험자의 실경·스케일 판정과 보급형 모바일 실기기 검사는 남아 있다. 비교용 인증 풍경·하늘·시설 키트는 게임 장면에 추가하지 않았으며, 발소리 음원은 포함하지 않았다.
