## 0. 먼저 알아둘 점
- **관악산 멧토끼 서식·출현을 직접 보여 주는 공공 자료는 찾지 못했습니다.** 그래서 토끼의 모든 구간은 **est**입니다.
  - 서울시 2006년 보도(1997년 산림생태계 조사 인용): 관악산 포유류 10종으로 다람쥐·청설모·너구리가 나오고, **멧토끼는 청계산 12종 목록에만** 있습니다. 즉 관악산 목록에서는 이름이 확인되지 않았습니다(종 전체 목록은 못 읽음).
  - 2019년 환경단체 답사기는 멧토끼 같은 중·소형 포유류가 살 것이라고 "짐작"만 적었습니다(관찰 기록 아님).
  - 북한산 무인카메라 조사 논문 요약에서는 멧토끼가 확인되지 않았고, 국립생물자원관 2015년 자료에는 산림 변화로 멧토끼가 줄었다는 추정이 있습니다(요약만 확인).
- **활동 시간대·선호 환경은 한국 멧토끼 직접 자료를 못 찾았습니다.** 검색에 나온 것은 다른 종(중국멧토끼는 야행성·개활지·덤불, 일본 토끼는 야간 활동)이거나 일반 설명(식생이 풍부하고 관목이 많은 곳)이었습니다. 아래 시간대·환경은 **est**입니다.
- 까치·산고양이도 이 산의 직접 자료는 없습니다(§1-2). 기존 `즐길거리-실제자료-2026-11-06.md` 결론을 그대로 따릅니다.
- 한계: 검색 결과의 요약 문장만 근거로 했고, 논문·보도 전문은 열지 못했습니다. 코드 `est:true` 표시와 앱 문구는 "게임 속 배치"로 하기를 권합니다.
