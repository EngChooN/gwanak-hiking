## 다시 만들기
```sh
cd ~/gwanak-hiking && export PATH=$HOME/.nvm/versions/node/v24.22.2/bin:$PATH
node scripts/promo/record-reels-smoking.mjs          # 장면 녹화(약 4분). 키를 주면 일부만: … 0 5a 7
```

- 개발 서버는 `BASE_URL`(기본 `http://127.0.0.1:5173`). 꺼져 있으면 녹화 스크립트가 그 포트로 잠시 켰다 끕니다.
- 같이 피우기(장면 4·7) 멀티 서버는 스크립트가 `127.0.0.1:8791`에 직접 띄웁니다(공개 터널 안 씀, 허용 주소 = 개발 서버 주소).

## 녹화 (`scripts/promo/record-reels-smoking.mjs`)
- shots.json을 `check-shots.mjs`와 같은 순서·시계로 돌립니다(준비 JS → 대기 → 시점 0부터 actions).
- **화면:** playwright `recordVideo`와 CDP 화면 중계는 배율과 상관없이 405×720(CSS 픽셀)로만 내보냅니다. 그래서 창을 1080×1920·배율 1로 열고, 녹화 브라우저 안에서만 다음 두 가지를 바꿨습니다.
  - viewport 메타를 `width=405, 확대 2.6667`로 바꿉니다.
  - `devicePixelRatio`를 2.6667로 알려 줍니다.
  - 게임은 휴대폰과 똑같이 405×720·DPR 2.6667·3D 607×1080으로 인식합니다. 프레임은 글자까지 선명한 1080×1920이 초당 60장 나오고, 30fps로 솎아서 저장합니다.
- **같이 피우기가 '연결 중'에서 멈추던 문제:** 처음에는 응답 HTML을 route로 바꿨습니다. 그러자 크롬이 그 페이지를 공개 주소로 보고, Local Network Access 검사로 127.0.0.1 WebSocket을 막았습니다. 그래서 HTML은 그대로 두고, 페이지 안에서 메타 값만 바꾸는 방식으로 고쳤습니다.
- **소리:** 스피커로 가는 모든 오디오 노드를 같은 AudioContext의 MediaStream 출구에도 잇고(`scripts/reels-record.mjs`와 같은 방법), MediaRecorder(opus)로 녹음합니다. 흡연장은 첫 입력 때 소리를 켜므로, 페이지가 뜨자마자 pointerdown을 보내 옥상 바람이 시점 0에 제 크기가 되게 했습니다. **11장면 모두 소리가 담겼습니다.**
- **장면 8 (화면에서만 한 연출):** 금연 수첩이 위 30~490px에 떠서 인스타 위쪽 가림 영역(220px)에 걸렸습니다. 녹화 페이지에만 `.lg-note{transform:translateY(84px)}` style을 넣어 수첩을 255~705px로 내렸습니다. 엔딩 밑에 깔 바람 소리를 위해 5초 더 녹화합니다.

## 편집 (`scripts/promo/edit-reels.mjs`)
- 크롬 안에서 canvas(1080×1920)와 `captureStream(0)`, MediaRecorder(`video/mp4;codecs=avc1.640028,mp4a.40.2`, 12Mbps)로 실시간 녹화합니다. 프레임은 시간표대로 `requestFrame` 합니다(이번 실행에서 늦은 프레임 0개).
- **장면 순서와 길이:** shots.json clip 순서 그대로입니다(장면 0은 점프 컷 2개, 5a·5b·5c를 이어서 장면 5). 그 뒤에 엔딩 4.5초를 붙여 모두 41.5초입니다.
- **장면 사이:** 컷 전환입니다. 소리만 12ms 페이드로 이어서 딸깍 소리를 막았습니다. 엔딩은 장면 8 녹음의 뒷부분(옥상 바람)을 1.6초 동안 줄여 끝냅니다. 배경 음악은 없습니다.
- **리미터:** 지포·꿀모금·캔 따기 순간이 +4dB까지 올라가 찢어졌습니다. 그래서 끝단에만 리미터를 걸었습니다(threshold −6dB, ratio 20). 결과 피크는 0dB 이하입니다.
- **자막:**
  - `reels-overlay.html`을 같은 출처 정적 서버로 열고, `reelsOverlay.show()` 뒤 투명 PNG로 찍어 얹습니다. 장면 처음 5프레임 동안 나타납니다.
  - 장면 6은 칩 4장을 0·1.25·2.5·3.75초에 바꿉니다(촬영 scene.set과 같은 시각).
  - **장면 4 자막은 '점심 먹고 온 친구와 / 인사하고 수다 떨고'로 바꿨습니다.** 연공간이 NPC 대신 같이 피우기 인사로 찍었는데, 오버레이 표에는 아직 '불 빌리고…'가 남아 있었기 때문입니다.
  - **장면 1은 자막 띠만 235px 올렸습니다.** 원래 자리에서는 입장 카드의 '옷 고르기' 단추를 덮었기 때문입니다.
  - **엔딩 주소는 `engchoon.github.io/` 뒤에서 줄을 바꿉니다.** 원래는 단어 중간(`hikin|g`)에서 끊겼습니다.
- **엔딩 주소:** `engchoon.github.io/gwanak-hiking/smoking/`입니다(공개 GitHub Pages 주소이고, 멀티 서버 주소는 아닙니다). 바꾸려면 `--url`을 씁니다.
- **확인:** 완성 파일을 크롬 `<video>`로 다시 열어 크기와 길이를 재고, 장면마다 1장씩 캡처합니다. ffprobe가 있으면 그 값도 `reels-timeline.json`에 적습니다.
  - 정적 서버는 Range 요청을 받아야 합니다. 받지 않으면 크롬이 조각 MP4 길이를 3~5초로 잘못 읽습니다.
  - 녹화기는 timeslice 없이 한 덩어리로 받습니다.

## 확인한 것
- ffprobe: h264 High 1080×1920, 평균 29.9fps, aac 48kHz 2ch, 길이 41.64~41.90초. 크롬 `<video>`도 1080×1920이고 같은 길이를 읽었습니다(mvhd 41,642ms, mfra 있음).
- 장면 캡처 10장으로 확인한 것:
  - 장면 0~9가 모두 들어 있고, 장면마다 해당 기능이 보입니다.
  - 장면 0과 엔딩에 '가상 흡연장 · 진짜 담배 없음 · 금연 응원' 띠가 있습니다.
  - 닉네임은 동동·하늘만 나오고, 서버 주소는 보이지 않습니다(장면 4·7 위 칩은 🟢 2만).
- 소리: 초마다 잰 RMS는 바람 −25~−33dB, 효과음 −6~−10dB이고, 피크는 0dB 이하입니다.
- `npm test`: 821개 모두 통과했습니다.
