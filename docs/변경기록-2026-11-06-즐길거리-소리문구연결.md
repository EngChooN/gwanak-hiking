# 변경 기록 — 즐길거리 소리·말풍선 문구 연결 (2026-11-06, 산개발)

상위 업무: 자동걷기 즐길거리 6종 구현(산기획) 마무리 단계입니다. 산디자인이 넘긴 「산개발 인계」 1~6번과 「⑥ 산개발 연결」 1~3번(`docs/변경기록-2026-11-06-즐길거리-디자인-효과음.md`), 산리서치 제안 1건을 넣었습니다.

## 무엇이 문제였나

- **'소리 꺼짐'인데도 즐길거리 소리가 났습니다.** `trail-world.js`의 `tone()`이 자기 AudioContext를 따로 만들어 스피커로 바로 내보냈습니다. 그래서 찍찍·야옹·깍깍·헥헥·찌릿은 소리 켜기/끄기와 음량을 따르지 않았습니다.
- 산디자인이 만든 효과음 파일 11개(`public/sounds/trail/`)와 말풍선 문구(`src/trail-lines.js`)는 코드 어디에서도 쓰이지 않았습니다.

## 무엇을 바꿨나

### 1. 효과음은 모두 발소리와 같은 길로 — `src/trail-sound.js`(새 파일)
- AudioContext를 만들지 않고, 발소리가 쓰는 AudioContext와 마스터 게인(`audio.master` = 사용자 음량, 리미터 포함)에 효과음 버스 하나를 붙입니다.
- **소리 꺼짐:** 버스 게인이 바로 0이 되고, 재생 중인 소리는 0.05초 안에 멈춥니다. 꺼져 있는 동안에는 재생 자체를 시작하지 않습니다. 화면이 가려져도(탭 전환) 같이 멈춥니다.
- **아이폰 사파리:** AudioContext는 사용자가 화면을 터치하거나 키를 누를 때 `main.js`가 만든 것만 씁니다. 그래서 첫 입력 전에는 소리가 나지 않습니다(사파리 제한과 같은 조건). 실제 아이폰으로는 확인하지 못했고, 자동 검사에서 "입력 전 0건 → 입력 뒤 재생"만 확인했습니다. 아이폰의 무음 스위치를 켜 두면 발소리처럼 즐길거리 소리도 나지 않습니다.
- `trail-world.js`의 합성음 `tone()`은 지웠습니다. 이제 즐길거리 쪽에는 합성음이 없습니다.

### 2. 효과음 파일 연결 (`TRAIL_SFX` 표대로, `${BASE_URL}sounds/trail/`)
| 소리 | 나는 때 |
|---|---|
| 찍찍 `squeak` | 다람쥐가 쳐다볼 때, 모자에 오를 때, 달아날 때 |
| 야옹 `meow` | 고양이가 쳐다볼 때, 냥펀치, 벤치 옆자리에 올 때 |
| 깍깍 `caw` | 까치가 날아오를 때, 배낭에 탈 때, 떠날 때 |
| 치이익 `airgun` | 에어건 펑(`airgun-blast`) |
| 바삭 `crunch` | 초콜릿 먹을 때(`choco-eaten`) |
| 후우 `whoo` | 벤치 영혼 말풍선과 함께 |
| 헥헥 `pant` | 헥헥 1.5초, 터벅터벅 중 가끔 |
| 찌릿 `zap` | 쥐 번개(0.5초에 한 번까지) |
| 비명 `scream` | 쥐가 나는 순간 한 번 |
| 뒹굴 `roll` | 쥐 동안 1.5초마다. 발끝 당기기를 누르거나 쥐가 끝나면 0.1초 페이드로 바로 멈춤 |
| 뽕짝 라디오 `radio` | 산스장 18m 안에서 반복, 가까울수록 크게(18m에서 0). 자동걷기로 지나갈 때도 들림. 18m 밖이거나 산스장 모형을 떼면 멈춤 |

- 짧은 소리 10개(약 0.8MB)는 첫 입력 뒤 한 번에 받아 둡니다. 라디오(345KB)는 산스장 모형을 만들 때 받기 시작합니다.
- 재생 속도는 표의 `rate` 범위 안에서 흔듭니다. 음량은 표의 `db`값입니다.

### 3. 말풍선 문구 → `pickLine('자리')`
- `hiker-acts.js`·`trail-world.js`에 고정으로 적혀 있던 문구를 모두 `pickLine()`으로 바꿨습니다. 같은 자리에서 바로 전 문구는 다시 나오지 않습니다.
- 아직 안 뜨던 9개를 넣었습니다.
  - `squirrel.hat`: 다람쥐가 모자에 올라앉을 때
  - `squirrel.heavy`: 그 뒤 2.3초
  - `choco.squirrel`: 초콜릿을 먹을 때 다람쥐가 8m 안에 있으면 1.9초 뒤 "…(침)"
  - `bench.cat`: 고양이가 벤치 옆자리에 올 때
  - `magpie.rider`: 까치가 배낭에 타고 2초 뒤
  - `airgun.shine`: 모자가 돌아온 뒤 "신발 반짝 ✨"
  - `gym-radio`: 산스장 18m 안에 들어설 때 라디오 위에 "♪ 뽕짝 ♪"
  - `gym-bar.kick`: 철봉 2.7초 "버둥버둥"
  - `bench.back`: 벤치에서 일어날 때 영혼이 돌아오며 "쏙!"
- ⑥ 헥헥·쥐 문구 5개(`pant.start`, `cramp.start`, `cramp.zap`, `cramp.release`, `cramp.done`)는 문구 표에 없어서, 산풍경이 쓴 그대로를 `TRAIL_LINES`에 옮겨 같은 방식으로 띄웁니다.
- **겹침 규칙:** 다람쥐가 쳐다볼 때, 까치가 날아오를 때, 라디오처럼 자주 생기는 장면은 다른 말풍선이 떠 있으면 건너뜁니다(`quiet`).

### 4. 말풍선 다시 튀어나오기
- 연달아 말할 때도 등장 움직임이 다시 돌게 했습니다. 방법은 `classList.remove('on')`, 리플로, 클래스 다시 넣기 순서입니다.

### 5. 간식 칩 0개
- `renderSnack()`에서 `#choco-count`에 `data-n`을 넣습니다. 0개일 때는 `trail-hud.css`가 흐리게 그립니다.

### 6. 계곡 고양이 est 표시
- `src/interaction-data.js`의 `CAT_SPOTS`에서 `cat-junction`(1,078m)과 `cat-pavilion`(2,404m)에 `est:true`와 메모를 붙였습니다. 먹이 주기 동작은 만들지 않았습니다.
