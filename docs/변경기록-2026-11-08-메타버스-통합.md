# 변경 기록 — 2026-11-08 온라인 메타버스 통합 1단계 (산개발)

상위 업무: 온라인 메타버스 허브로 통합(등산·흡연장 한 프로젝트, 고르기 화면) · 1/3단계. 기획서 결정 1~4·6을 구현했습니다. 커밋·push·배포는 하지 않았습니다.

## 무엇을 바꿨나

### 1. Vite 다중 페이지 (`/` · `/hiking/` · `/smoking/`)
- `vite.config.js`에 `PAGES`(main·hiking·smoking)를 두고 `build.rollupOptions.input`으로 세 페이지를 빌드합니다. `base`(BASE_PATH)는 세 페이지가 같이 씁니다.
- 원래 `index.html`(등산)은 `hiking/index.html`로 옮겼습니다(git mv). 내용은 같고 진입 스크립트 경로도 `/src/main.js` 그대로입니다.
- 새 `index.html` = 허브 임시 화면(링크 두 개 「⛰ 온라인 등산」 「🚬 온라인 흡연장」). 정식 화면은 산디자인이 `src/hub/`에 만듭니다.
- `smoking/index.html` = 흡연장 index.html(진입 `/src/lounge/main.js`).
- 에셋은 `public/`·`assets/` 한 벌. 흡연장의 동동이 뼈대 주소를 `${import.meta.env.BASE_URL}assets/toon/models/hiker/HikerRig.glb`로 바꿔 등산과 같은 파일을 받습니다(흡연장 `public/assets/toon/…/HikerRig.glb` 사본은 등산 `assets/toon/…`과 바이트까지 같아 옮기지 않음). 흡연장 public의 나머지 파일은 등산 public과 같아 그대로 씁니다.
- `scripts/copy-assets.mjs`는 그대로(세 페이지 모두 같은 assets 경로). `scripts/deploy-pages.mjs`는 빌드 결과에 `index.html`·`hiking/index.html`·`smoking/index.html`이 다 있는지 검사하고 없으면 멈춥니다.
- 등산을 루트 주소(`/?…`)로 열던 점검·캡처 스크립트(`scripts/capture-*`·`verify-*`·`measure-*`·`probe-*` 등 80여 개)와 e2e(`tests/e2e/toon.spec.mjs`)를 `/hiking/?…`로 바꿨습니다.

### 2. 흡연장 옮기기 (`~/online-smoking` → 이 저장소, 복사)
- `src/lounge/**` 17개, 테스트 6개(`core`·`moment-record`·`npc-social`·`spots-scene` → `tests/lounge-*.test.mjs`로 이름 앞에 `lounge-`, `smoke-feel`·`smoke-run`은 그대로), 문서 4개(`docs/흡연장/기획서-온라인흡연장-v1.md`·`기획서-맛과상호작용-v2.md`·`결과보고-v2.md`·`점검표-v2.md`), 캡처 스크립트 `scripts/capture-smoking.mjs`(주소 `/smoking/`).
- 공용 파일 사본(`src/toon/**`·`hiker-*`·`daytime` 등)은 옮기지 않았습니다. `src/lounge/`의 import는 `../toon/…` 등 등산 원본을 그대로 가리킵니다.
- `src/device-profile.js` 비교: 다른 점은 등산 쪽에만 있는 `multiFullCap`(함께 걷기 모델 수) 한 줄뿐이었습니다. 흡연장에는 이 값을 읽는 곳이 없고, 흡연장에만 있는 설정은 없어서 **옵션 추가 없이 등산 최신본을 그대로** 씁니다.
- `~/online-smoking` 폴더는 지우지 않았습니다.

### 3. 옛 주소 넘기기
- `src/hub/legacy-redirect.js` `legacyHikingTarget(search,hash,base)`: 루트에 등산 옵션(기획 지정 `multi`·`server`·`start`·`season`·`time`·`weather`·`pick`·`dev`와 예전에 쓰던 `quality`·`startMode`·`name`·`sim`·`fov`·`style`·`tone` 등)이 하나라도 있으면 쿼리·해시 그대로 `<base>hiking/…` 주소를 돌려줍니다. `src/hub/main.js`가 `location.replace`로 넘깁니다(뒤로 가기에 허브가 남지 않음). 넘기는 동안 허브가 깜빡이지 않게 `hub-ready` 전에는 본문을 숨깁니다.
- 등산과 상관없는 쿼리(`?utm_source=…`)나 쿼리 없음 → 허브를 보여 줍니다.

### 4. AGENTS.md
- §0 「저장소 구성」(세 페이지·옛 주소·에셋/공용 코드 한 벌·흡연장 폴더 보존), §5 실행(Node 24, 테스트 655개, 주소 옵션은 `/hiking/` 뒤에), §6 코드 지도(허브·흡연장 줄, device-profile 메모), §7 상태, §8 결정 한 줄, §10 「온라인 흡연장」(흡연장 AGENTS.md를 합침: 브랜드 기준 **옷만 바꿈**·회사원 옷 4종, 실행·콘솔·테스트·코드 지도·흡연장 결정 기록)을 더했습니다.
