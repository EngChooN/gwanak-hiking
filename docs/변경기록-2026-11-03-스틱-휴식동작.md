# 양손 스틱·앉기·차 마시기

산풍경 · 2026-11-03

## 구현

- `src/realistic-hiker.js`: 로더 반환 `setPose`, 자세 보간과 팔/다리 IK, 반대 발과 교차하는 스틱 접지 앵커, 경사 높이 보정, 달릴 때 보폭·팔 진폭 확대, 양옆 스틱 내려놓기/회수, 컵 들어 마시기/내려놓기.
- `src/hiker-ik.js`: 월드 목표를 캐릭터 루트 로컬 회전으로 변환하는 `poleRotation`. 루트가 회전한 산길에서도 실제 팁 노드가 지면 목표와 일치한다.
- `src/hiker-interactions.js`: 0.8초 앉기/일어나기, 약 3초 차 동작, 직접 제작한 폴 2개·컵·보온병, 앉은 눈높이 0.85m 및 전환 높이.
- 내려놓은 폴은 양 끝뿐 아니라 중간 지형 지지점도 검사해 계단 디딤판 위에 걸쳐 놓는다.
- 앉을 때 발목은 바인드 월드 방향을 유지하고 실제 밑창 표본으로 4회 접지를 보정한다. 골반 중심 지면 여유 9cm는 메시 두께를 고려한 설계값이다.
- 기존 GLB·사진·외부 자산은 추가/변경하지 않았다. 소품 출처는 자료 기록표 §9 및 연결 문서에 기록했다.
- `main.js`는 이번 작업에서 수정하지 않았다. 산개발의 기존 pose/running/speed/dt/terrain 입력과 호환된다.

## 검증

- `npm test`: 148개 통과. 새 동작 테스트 5개와 회전 방향별 팁 회귀 테스트 1개 추가.
- `npm run build`: 통과. 로그: `artifacts/hiker-interactions-tests.log`, `artifacts/hiker-interactions-build.log`.
- 확대 GLB 장면에서 실제 부츠 메시 전체 정점을 검사했다. 평지/경사 앉기와 차 자세의 최저 밑창 지면 간격은 1mm 미만, 골반 중심은 지면 약 9cm.
- `scripts/capture-hiker-props.mjs`: 확대 화면·신발 메시 접지·골반 높이·40fps 기준 자동 검사.
- `scripts/verify-hiker-interactions.mjs`: 실제 앱의 걷기/달리기는 키보드 이동 입력을 사용하고, 자세 래퍼로 대상 동작을 지정한다. 차는 중간 자세를 고정 촬영한다. 각 장면 5초 평균 40fps 이상, 실제 팁/그립 노드 오차 2mm 미만을 검사한다. 검증 탭에서만 Vite 자동 새로고침을 비활성화했다.
- 걷기/달리기/앉기/차/계단 경사 보행/계단 경사 앉기 원본 PNG와 측정 JSON은 `artifacts/hiker-interactions/`에 저장한다.
- 0.8초/3초 완료와 중단은 단위 테스트로 검증했다. FPS는 이 맥 Chrome headless, 1280×900, 균형 화질의 표본이며 전체 코스 최저값이나 다른 기기를 보장하지 않는다.

## 산개발 인계

`docs/캐릭터-상호작용-연결.md` 참조. `hiker.update` 다음 `hiker.ground` 순서를 유지한다. 현재 main이 보내는 `pose`, `teaProgress`, `running`, `speed`, `dt`, `surfaceHeight`를 그대로 쓴다. 누적 걸음 수를 `stepPhase`로 직접 넣거나 기존 `distance: steps+stepPhase, stride:1`을 유지한다.

1인칭은 지면 + `hiker.eyeHeight`를 쓰면 전환 중 높이도 보간된다. 고정 최종 높이는 내보낸 `SEATED_EYE_HEIGHT=.85`다. 현재 main의 앉은 `.85`와 같다. 최종 통합·시점 확인은 main 담당 산개발에게 넘긴다.

push·배포·삭제 없음.
