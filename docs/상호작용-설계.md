## 0. 먼저 정할 것 — E 키 충돌
`src/input.js`를 확인하니 지시에 적힌 키 외에 이미 쓰는 키가 있다: **Q/E(둘러보기 회전)**, T(차), P(휴대폰), Y·Tab(셀카), /(도움말), Shift(달리기), +/−(줌), 방향키.
- **E는 지금 "오른쪽 둘러보기 회전"**이다. 제안(추천): **상호작용 표시가 떠 있을 때만 E=실행**, 표시가 없으면 기존 회전 그대로. Q·마우스 드래그·모바일 조이스틱은 영향 없음.
- 대안: ② Q/E 회전을 없애고 드래그만 남김 / ③ 실행 키를 새 글자로(기획서의 "E 키"와 달라짐). → **대표님 결정 필요**(결정 전까지 ①로 설계).

### 키 배정표
| 키 | 역할 | 상태 |
|---|---|---|
| **E** | 상호작용 실행(표시가 있을 때) | 신규(위 조건) |
| **J** | 스탬프 수첩 열기/닫기 | 신규 |
| **N** | 이름표 켜기/끄기(쌍안경 랜드마크·다른 사람) | 신규 |
| **Z** | 스트레칭·숨 고르기(서 있을 때 어디서나) | 신규 |
| **X 누르고 있기** | 인사 메뉴(멀티). 누른 채 1·2·3 또는 마우스 | 신규 |
| **1·2·3** | 한 지점 행동이 여럿일 때 2·3번째 선택 / 인사 메뉴 항목 | 신규(목록이 뜰 때만 반응) |
| Enter·Esc | 창 안에서만 저장·닫기 | 기존 대화상자 규칙 |
| 인증샷 | 새 키 없음: 기존 P(폰)·Space(셔터)·Y(셀카) | 그대로 |
쓰지 않는 키: W A S D ↑↓←→ Q V C T B P Y Tab F L M R H Space Esc / Shift + −.

## ① 공통 규칙: 가까이 가면 표시 → E·버튼 실행
**하나의 알약(pill)**으로 모든 상호작용을 시작한다. 모양은 현재 HUD 패널(#173e36 유리, 금색 #e4d6aa 키 칸).
| 항목 | 값(첫 제안) |
|---|---|
| 멀리 | 15m 안에서 월드 위 **작은 마커**(점/“i”). 눌러도 반응 없음. 이미 한 곳은 안 보임 |
| 알약 표시 | 4m 안 + 시선 ±70° 안. 정상석·스탬프는 6m. **6.5m 밖으로 나가야 사라짐**(깜빡임 방지) |
| 후보 여럿 | 점수=거리+시선 각도, **하나만** 표시. 같은 지점 행동은 세로로 쌓임(E=맨 위, 숫자키=아래) |
| 위치 | PC: 화면 아래 가운데, 하단 조작줄 바로 위(좌 지표 패널·우 컴퍼스와 안 겹침). 모바일: 오른쪽 조작줄 위 지름 84px 둥근 단추 + 이름표(둘러보기 드래그 영역과 겹치지 않음). 휴대폰 화면 안: 줌 단추 위 같은 알약 |
| 상태 5종 | 사용 가능 / 이미 함(초록 ✓, 다시 가능) / 잠김(회색+**이유 한 줄**) / 여러 개 쌓임 / 터치(키 글자 대신 손가락) |
| 숨기는 때 | 앉기·차 마시기·일시정지·창 열림·달리기(2.2m/s 초과)·행동 진행 중. 쌍안경·폰 중엔 일반 알약 숨김 |
| 자동 걷기(R) | 알약은 뜸. E를 누르면 자동 걷기 멈추고 행동 실행, 끝나도 자동 재개 안 함 |
| 마우스 고정 | PC는 E가 기본, 알약 아래 작은 E 힌트 상시. 클릭은 고정 해제 때 |
| 소리 | 표시 시 아주 작은 틱, 실행 시 행동별 소리. 재표시 쿨다운 1.5초 |
| 접근성 | 알약 `aria-live=polite`, 움직임 줄이기 설정이면 링·도장 애니메이션 생략 |

## ② 안내판 읽기 화면
- 가운데 **패널 하나**(폭 760, 글자 21px, 줄 간격 1.75). 뒤 풍경 보이게 어둡게 20%만. 시간·날씨·소리는 계속 흐르고, **걸으면 닫힘**. 닫기: E·Esc·✕·시트 밖 터치.
- 구성: 머리글(안내판 · 이름 / 쪽 번호), 제목, 본문 2~4문장, **칩 3종**(확인됨 초록 / 전해지는 이야기 금색 / 추정 주황), 출처 한 줄, 이전·다음(←→, 창 안에서만)·닫기.
- **“직접 정리한 설명이며 현장 안내판 글이 아닙니다”**를 항상 표기(산리서치: 실제 안내판 글처럼 표시 금지).
- 이정표 변형: 같은 패널에 화살표 행으로 **지명만**(GPX 이정표 12곳 표). 화살표는 내가 보는 방향 기준으로 계산.
- 모바일: 바닥 시트(글자 16px, 단추 48px), 아래로 끌어 닫기, 조이스틱 움직이면 내려감.
- 글 규칙: 창건·유래는 “전해집니다”까지만, 정상석 629m는 “표기 값”. 외부 문장은 옮기지 않음(공공누리 4유형).

## ③ 쌍안경 랜드마크 이름표
8배율 시야 폭이 약 7°(4배 13°)라 이름표만으로는 못 찾는다 → **네 층**:
1. **방위 띠**(렌즈 위, 폭 760): 현재 방향 빨간 선, 랜드마크 금색 ▼+이름. 시야 ±25°.
2. **시야 안 이름표**: 점 + 선 + 이름(+거리·높이). 겹치면 위로 계단식, 최대 6개.
3. **시야 밖 가장자리 알약**(최대 2개): “◀ 63빌딩 · 22° 왼쪽”.
4. **가운데 맞춤(±1.2°)**: 금색 강조 + 상세 카드(방위·거리·높이·보이는 조건), **E = 자세히(②의 패널)**.
- 가시거리 밖(인천 쪽 15~17번, 29~46km): 점선 알약 “방향만”(점·선 없음). 비·안개로 날씨 가시거리가 거리보다 짧으면 흐리게 + “지금은 안 보여요”.
- 시선 가림 미확인 대상(청계산·광교산·남한산·수리산)은 **추정** 칩. 남한산 높이는 원문 미확인이라 상세 카드에서 높이 줄 제외. 건물 좌표는 대표점이라 한 줄 단서.
- N 으로 이름표 끔(방위 띠는 남김). 방위는 진북 시계방향 → 앱 좌표(동 +x, 남 +z) 변환 필요(산개발).

## ④ 스탬프
- 6곳: 일주문(門) · 인공폭포(瀑) · 팔각정(亭) · 돌탑 공터(塔) · 연주암 갈림길(庵) · 연주대 정상석(臺). 예비 2곳(깔딱고개 벤치·무명폭포)은 수첩에 안 보임.
- **획득**: 6m 안에서 E → 도장 “탁”(0.75초, 움직임 줄이기 시 페이드) → 위쪽 가운데 알림 3.2초(새 스탬프 n/6, 이름, 일주문 기준 거리·해발, 진행 막대). 소리: 낮은 도장음 + 맑은 두 음. 6/6이면 알림 대신 완등 카드.
- **수첩(J)**: 베이지 종이 위 6칸(붉은 도장+이름+찍은 시각·거리·해발 / 미획득은 점선+“n.nkm 앞”), 위쪽 진행 막대, 아래 고도 단면 띠. 6/6에서 「완등 기록 카드 보기」 활성. 모바일 2열 3행.
- 놓친 스탬프는 벌점·알림 없이 위치만 안내. 저장은 localStorage(id·시각·날씨).
- 아래에 “스탬프 위치는 지도 기준 후보 · 현장 표지와 다를 수 있어요”(현장 확인 전).

## ⑤ 인증샷 틀과 완등 기록 카드
**인증샷 틀**: 정상석 6m 안 + 폰 켬 → 폰 화면 알약 「인증샷 틀 켜기」. 틀=크림색 얇은 테두리 + 「정상 인증」 배지 + 아래 띠(장소·날짜·시각·날씨·닉네임). 폰 위 단추줄에 「▢ 틀」 토글 추가(격자 옆). **저장 사진에 구워 넣는 옵션**이며 끄면 깨끗한 사진. 정상석이 안 보이면 “정상석이 보이게 서 보세요”.
**완등 카드** 1080×1350(4:5) PNG, 시안 페이지의 캔버스가 실제 저장 그림과 같다(저장 버튼이 진짜 내려받기).
| 값 | 출처 |
|---|---|
| 날짜 | 완등 순간 기기 날짜 |
| 걸은 시간 | `state.elapsed`(일시정지 제외) |
| 거리 | `state.distance`(진행 패널과 같은 5,093m 기준) |
| 오른 높이 | `state.ascent` 누적 |
| 사진 | 마지막 정상 인증샷 → 없으면 정상 풍경 자동 촬영 → 없으면 일러스트 |
| 스탬프 | 6개 작은 도장 |
| 고정 문구 | “온라인 체험 기록 · 실제 등산 기록이 아닙니다” |
닉네임 기본 “산길 손님”(서버 계정명 사용 안 함). 모바일은 `navigator.share(files)` 먼저, 실패 시 내려받기. 사진은 기기에만 저장. 카드의 샘플 수치(02:41:08, +574m)는 예시.

## ⑥ 산길 행동(화면 연출·소리)
공통: ①의 알약으로 시작, **이동 입력으로 취소**(차 마시기와 동일), 끝까지 해야 효과 지급, 연출 2~4초. 소리는 환경음 위 +3~6dB, 행동 중 다른 소리 −3dB 2초(덕킹), 물소리는 지점에서 3D. 설정에 “소리 설명 자막”(기본 꺼짐).
| 행동 | 시작 | 연출 | 효과 | 소리(임시 합성음, 시안에서 ▶) |
|---|---|---|---|---|
| 약수 한 모금 | 약수터 코스 260m(E) | 시선 돌림 0.4s → 허리 숙이듯 카메라 −25cm → 물 뜨기 1.2s → 마시기 0.8s → “후” | 스테미너 +15 | 졸졸 루프, 물 뜨는 첨벙, 꿀꺽×2, 숨 |
| 손 담그기 | 계곡 접근 지점(E) | 시선 −20°, 아래서 손이 들어와 물에 잠김, 잔물결 링, 약한 푸른 비네트 → 손 빼며 물방울 3개 | +5 | 첨벙+기포, 손 잠긴 동안 물소리 고음 −6dB, 물방울 |
| 돌 올리기 | 돌탑 공터 3,774m(스탬프와 같은 자리 → 2번째 줄 숫자 2) | 바닥 돌 금색 윤곽 → 집기 0.8s → 올리기(카메라 +12°) → 얹고 살짝 흔들림 → 멈춤, “오늘 내 돌 n개” | 없음 | 자갈 긁힘, 돌 딱×2, 작은 숨 |
| 스트레칭 | Z(어디서나) / 쉼터·정상 E | 팔 올리며 카메라 +8°, 들이마시기 1.8s·내쉬기 1.8s, 호흡 원이 박자 안내 | +10 | 들숨·날숨 노이즈, 바람 +2dB 스웰 |
- 효과 수치·쿨다운(약수터 20초 등)은 **첫 제안값**, 게임 감각으로 조정 필요.
- **문구 주의**: 약수터 물이 지금 나오는지·식수 가능한지 미확인 → “약수 한 모금(게임 속 회복)”으로만 쓰고 “먹어도 되는 물” 표현 금지. 돌탑에는 “게임 속 돌이에요. 실제 산에서는 돌을 옮기지 않아요” 문구를 넣을지 대표님 취향 확인.
- 소리는 합성음이라 최종 음원(CC0 선별 또는 합성 다듬기)과 귀 검수는 별도.

## ⑦ 멀티: 이름표·인사·손 흔들기·같이 셀카
- **이름표**: 20m 안 풀 이름표(상태 점 + 닉네임 + 거리), 20~60m 작은 이름(투명 82%), 60m+ 없음(지도 M 점만). 상태 점: 초록 걷는 중 / 금색 쉬는 중 / 회색 자리 비움(10초). 지형에 가려져도 0.5 투명으로 표시.
- **인사 메뉴(X 누르고 있기)**: 화면 가운데 3원 — 인사(1) · 손 흔들기(2) · 같이 셀카(3). 대상=가장 가까운 사람(시선 우선), 없으면 “주변 모두에게”. 시선 중앙 4m 안의 사람은 ①의 알약 **“인사하기 E”**. 모바일은 👋 단추 → 바닥 시트.
- **받는 쪽**: 인사·손 흔들기는 위쪽 작은 칩 + 머리 위 말풍선 3초. **같이 셀카 요청**은 카드(E 수락), 8초 무응답 시 조용히 사라짐(상대에겐 거절로 안 보임).
- **같이 셀카**: 수락 → 둘이 나란히 서고 폰 셀카 화면 자동 전환 → 3·2·1 → 각자 시점으로 저장. 정상석 앞이면 틀에 두 닉네임.
- **개인정보·안전**: 닉네임만(8자, 기본 “산길 손님 1234”), **자유 글 채팅 없음**(고정 인사만), N=이름표 끄기, 설정 “혼자 걷기”, 이름표 길게 누름/우클릭=「숨기기·신고」, 인사 8m 안만, 쿨다운(인사 5초·셀카 요청 20초), 위치는 같은 방 안에만·정확 좌표 대신 코스 위 거리+옆 이탈만 전송 제안. 서버 방식·비용·신고 처리는 대표님 결정 뒤.

## 구현 인계 제안 (산개발)
- 새 모듈 `src/interaction-ui.js/.css`를 `gadget-ui.js`와 같은 방식으로: `hiking:state`에 `interact:{id,verb,label,key,state:'ready|done|locked',reason,progress,extra:[…]}`를 싣고, UI는 `hiking:command`로 `interact`·`interact-2`·`stamps-toggle`·`labels-toggle`·`stretch`·`emote-menu`를 되돌림.
- `input.js`: E는 `state.interact`가 있을 때만 command, 없으면 기존 `turn`. 새 키 J·N·Z·X·1·2·3은 `KEY_COMMANDS`에 추가(대화상자·입력창 포커스 때 무시).
- 폰 화면: `gadget-ui.js`의 `phone-top` 단추줄에 「▢ 틀」, `phone-bar` 위 알약 자리 추가. 틀은 `hiking:photo` 저장 때 캔버스에 합성.
- 크기는 기존 `--u` 비율(최소 14px·44px 터치) 사용. 시안은 1920×1080 기준 px = u.
