# 변경 기록 — 2026-11-05 등산객 가슴 남성형으로

## 문제
3인칭에서 등산객 상의 가슴이 여성형으로 봉긋하게 보였다. 원본 MPFB 몸(`Hiker.glb`)이 가슴 양쪽(x ±7.5cm, 높이 1.255m)을 가운데보다 약 1.5cm 앞으로 내밀고 있었고, 상의도 그 모양을 따라갔다. GLB 원본 체형 슬라이더 소스는 없어 지금까지 고쳐진 적이 없었다(`docs/등산객-모델수정-인계.md` 참고).

## 수정
- `src/realistic-hiker.js` `flattenChest`: 모델을 불러올 때 몸·상의·칼라·지퍼·어깨끈의 앞면 정점을 가슴 양쪽 중심으로 최대 13mm 뒤로 누른다(타원 반경 7.5×8.5cm, 부드러운 감쇠). 모든 겹이 같은 양만큼 움직여 몸과 옷 사이 간격은 그대로이고, 노멀은 같은 기울기로 돌린다.
- 형상에 표시를 남겨 함께 걷기에서 모델을 여러 개 복제해도 한 번만 적용된다.
- 쌍안경 위치는 수정된 상의 앞면을 기준으로 다시 잰다.
