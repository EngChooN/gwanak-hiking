## 무엇을 바꿨나

### 1. 고정 자리 → 출현 구역
- 예전: 다람쥐 5·까치 4(`interactionProps.spawns`), 고양이 3(`CAT_SPOTS`) 고정 자리에 서 있었습니다.

- 시간대(새벽·낮·한낮·해질녘·밤)와 계절 가중은 `ANIMAL_TIME`·`ANIMAL_SEASON`(산디자인 §2 표). 예: 토끼 새벽·해질녘 ×2, 한낮 ×0.4 / 다람쥐 겨울 ×0.1.
- 동물별 배회 수치는 `ANIMAL_STYLE`(속도·한 번 거리·멈춤·가로지르기 확률·나무 타기·짧은 비행).

### 2. 결정적 출현(멀티 대비) — `src/animal-zones.js` (새 파일, three.js 없는 순수 함수)
- 구역 id + 5분 시간 칸(`TRAIL_RULES.animalSlot` 300초, 실제 시계)으로 씨앗을 만들어 자리·종류·움직임을 정합니다. 같은 방 사람은 서버 없이 같은 동물을 봅니다.
- 배회는 "시간의 함수"입니다. 다리(leg) 목록을 씨앗으로 만들고 지금 시각의 자리를 계산하므로, 늦게 들어온 사람도 같은 시각에 같은 자리를 봅니다.
- 다가갔을 때의 반응(쳐다보기·달아나기 등)은 각자 화면에서만 합니다. 반응이 끝나면 계획 자리까지 걸어서 따라잡습니다(순간 이동 없음).
- 시간대·계절은 시간 칸이 바뀔 때 그 화면의 게임 시각·계절로 읽습니다. 두 사람이 `?time=`을 다르게 두면 종류가 다를 수 있습니다.

### 3. 동물별 배회 동작 (`src/trail-world.js`)
| 동물 | 평소 | 가끔 |
|---|---|---|
| 다람쥐 | 짧게 뛰고(2.8~3.6m/s) 멈춰 두리번 | 6m 안 나무 밑동으로 뛰어가 줄기를 타고 올라 사라짐(나무가 없으면 덤불로 뛰어듦) → 구역 안 다른 자리에서 다시 나타남. 등산로 가로지르기 6% |
| 토끼 | 깡충 4~7번 → 풀 뜯기 4~9초 → 두리번 2~3초 | 가로지르기 10% |
| 까치 | 땅에서 종종걸음 → 쪼기 | 25%로 6~15m 짧은 비행(포물선 2~4m), 날아서 가로지르기 20% |
| 고양이 | 느리게 어슬렁(0.5m/s) → 오래 앉기 8~25초 | 가로지르기 4%, 길 한가운데서 잠깐 멈춤 |
- 모두 지형 높이에 붙습니다(`surfaceHeight`). 다람쥐 나무 타기를 위해 근경 나무 격자에 `nearest(x,z,r)`를 더하고 `landscape.treeNear`로 열었습니다(`assets/realistic/near-trees.js`, `load-landscape.js` 한 줄).
- 기존 반응은 그대로입니다: 다람쥐 쳐다보기·모자 오르기, 까치 날아오르기·모자 타기, 고양이 쓰다듬기·벤치 옆자리. 모자 자리는 여전히 한 마리만.
- 동시 상한 `LIMITS.trailAnimals`(3)를 그대로 지킵니다. 모형은 가까운 3마리만 만듭니다.
- 동물 묶음의 회전 순서를 `YXZ`로 바꿨습니다. 예전 까치 쪼기(`rotation.x`)가 방향에 따라 옆으로 기울던 것을 바로잡았습니다.

### 4. 멧토끼
- 모델은 산디자인 `hare()` 그대로, 크기만 1.35배(몸길이 약 0.5m, 멧토끼 크기)로 씁니다. 1.15배는 가을 풀에 묻혀 거의 안 보였습니다.
- 반응: 8m 안이면 귀 쫑긋·얼어붙음(1.2초) → 3m 안이면 깡충 달아남(5m/s, 3.5초) → 그 사이 거리면 경계하며 풀 뜯기. 20초 넘게 가만히 있으면 달아난 쪽에서 다시 나타나 슬금슬금 5m까지 다가와 풀을 뜯습니다.
- 문구 6개(`hare.alert`·`thump`·`flee`·`munch`·`return`·`look`)를 `trail-lines.js`에 넣었습니다. 소리 글자 10자 규칙 때문에 '(귀가 먼저 알았다)'는 '(귀가 먼저!)'로 줄였습니다. '귀가… 나보다 길다'는 구역마다 한 번만.
- 효과음 3개(풀 뜯기·뒷발 '툭'·풀잎 스침)를 `scripts/make-trail-sfx.mjs`로 합성해 `public/sounds/trail/`에 넣었습니다(CC0, 기존 파일은 바이트 그대로). 출처 문서 두 곳에 기록했습니다.

### 7. 함께 고친 것
- 상호작용 칩이 가로 화면에서 노치 쪽으로 삐져나갈 수 있었습니다. 칩 상자를 처음 한 번만 재서 안전 영역 값이 나중에 바뀌면 반영되지 않았습니다. 이제 1초마다 다시 잽니다(`src/trail-hud.js`).
- `trail.play('pet-cat', 없는 id)`가 오류를 내던 것을 아무것도 하지 않게 고쳤습니다(고양이가 이미 떠난 경우).
- 검수 도구: `hiking.trail.spawns()`(이번 칸 출현 목록), `hiking.trail.summon(종류,{ahead,offset})`(앞에 불러내기, 광장에서는 광장 구역에).
