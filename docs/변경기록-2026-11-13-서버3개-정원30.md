# 변경 기록 2026-11-13 — 함께 걷기 서버 체험마다 3개·정원 30명

대표 지시: "서버가 게임별로 한 개씩밖에 없고 20명밖에 안 들어가는데, 최대 30명씩 서버 3개씩은 있어야 할 것 같다."

## 바꾼 것

| 무엇 | 전 | 후 | 파일 |
|---|---|---|---|
| 서버 목록 | 등산 `관악산 1서버`, 흡연장 `옥상 1서버` | 등산 `관악산 1·2·3서버`, 흡연장 `옥상 1·2·3서버` | `src/multi-protocol.js` `SERVERS` |
| 정원 | 20명 | 30명 | `SERVER_MAX`, `server/rooms.mjs` `maxPerRoom`, `server/multi-server.mjs` `MAX_PER_ROOM` 기본값 |
| 터널 뒤 접속 수 세기 | `multi:up`이 `TRUST_PROXY`를 안 켜 모든 사람이 127.0.0.1 한 곳으로 셈 → 같은 곳 제한 32명에 **두 체험 전체가 묶임** | `multi:up`이 `TRUST_PROXY=1`·`HOST=127.0.0.1`로 서버를 켬(CF-Connecting-IP로 셈, 머리글 위조 막으려고 이 맥 안에서만 기다림) | `scripts/multi-up.mjs` |
| 서버 고르기 창(낮은 화면) | 줄 하나가 높아(약 125px) 가로 휴대폰에서 3서버째·혼자 단추가 화면 밖 | 높이 540px 이하에서 줄을 납작하게(이름·인원 왼쪽, 들어가기 오른쪽, 막대 아래). 세로 키보드에서는 안내 글을 접고, 가로 키보드(260px 이하)는 서버 목록만 안에서 스크롤 | `src/server-pick.css` |

- '서버'는 실제 컴퓨터가 아니라 한 서버 프로그램 안의 방입니다. 2·3서버 방 키는 `hiking:관악산-2`·`-3`(1서버는 예전처럼 `hiking:관악산`). 옛 링크 `?multi=관악산-1`은 그대로 1서버.
- 목록에 없는 번호(`?multi=관악산-7`)는 1서버로 봅니다. 예전에는 `?multi=관악산-3`도 1서버였는데, 이제 3서버입니다.
- 서버가 꽉 차면 예전처럼 `full`로 거절하고, 서버 카드 화면이 '방금 꽉 찼어요'를 띄웁니다. 다른 서버로 자동으로 넘기지는 않습니다(사용자가 고름).
- 신고로 숨겨진 사람은 서버 방에서는 지금처럼 다른 방으로 옮기지 않고 이름만 숨깁니다.

## 확인

- `npm test` 821개 모두 통과(서버 목록·정원·`/health` 3줄·31명째 -2·30명째 full·2·3서버 방 키 시험을 고침).
- `scripts/verify-server-pick.mjs` 32항목 모두 통과. 새 항목: 1서버가 꽉 차도 2·3서버는 열림, 2·3서버로 들어가면 각자 다른 방(`관악산-2`·`-3`).
- `scripts/capture-server-pick.mjs` 89항목 모두 통과(처음에는 가로·키보드 12항목이 화면 밖으로 실패 → CSS 고친 뒤 통과). 캡처 `artifacts/server-pick/`.
- 부하 시험(가짜 180명 = 2체험 × 3서버 × 30명, 초당 10번 위치, 20초): 180명 모두 들어감, 서버+가짜 접속 프로세스 CPU 약 13%, 한 사람이 받는 양 약 23KB/s, 서버가 내보내는 전체 약 34Mbps.
- 화면 성능은 새로 재지 않음. 11-04 PC 측정(`artifacts/multi/multi-perf.json`)에서 광장 60명 59fps·20명 58fps였고, 휴대폰은 모델 2명·나머지 캡슐(`device-profile.js` `multiFullCap`)이라 30명도 같은 구조입니다.

## 남은 것·주의

- **꽉 찬 서버의 데이터 양:** 30명 방에서는 한 사람이 초당 약 23KB(1시간 약 80MB)를 받습니다. 휴대폰 데이터 요금제 사용자에게는 부담일 수 있습니다. 줄이려면 먼 사람 위치를 덜 자주 보내는 방법이 있습니다(이번에는 안 함).
- **맥 업로드:** 6개 서버가 모두 차면 맥이 터널로 약 34Mbps를 내보냅니다. 집 인터넷 업로드 속도를 넘으면 모두 끊겨 보입니다.
- 배포(사이트에 서버 3줄이 보이려면)와 서버 다시 켜기는 대표 지시 뒤에 합니다.
