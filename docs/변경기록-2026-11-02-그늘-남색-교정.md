# 그늘 남색 편향 교정·발소리 재확인 — 산개발

기준: 산기획의 ‘그늘진 사면·바위가 남색으로 떠 보임’ 수정 지시. 지목된 artifacts/look-neutral-fov70.png와 같은 경로 위치·카메라·Neutral·수직 FOV 70°·1366×768·고화질 구도로 비교한다.

## 원인과 수정

수정 전에는 지면 반구 반사광이 없었고 HDRI 색이 그대로 간접광으로 들어갔다. 화면 배경의 천정색은 배경 전용이며 직접 조명으로 쓰지 않았다. 4:1도 원래 RGB 비가 아닌 GPU 기준 카드 선형 휘도 기여 비였다. HDRI의 푸른 색 편향과 어두운 녹색 정점 알베도가 곱해지고 Neutral 저휘도 응답이 채도 차이를 두드러지게 했다.

- src/indirect-light.js: HDRI의 방향별 휘도를 유지하고 원래 색 차이 기여 1% + 저채도 반사색 99%로 교정. 천정 간접광 #D5D6D3, 지면 반사색 #ABA8A2.
- src/rendering.js: 회갈색 아래쪽을 가진 HemisphereLight 추가. HDRI+반구광을 합친 간접광과 직사광을 GPU에서 다시 교정.
- src/look-calibration.js: 수평 18% 카드에 대해 직사광만, 간접광(HDRI+반구광)만 별도 측정. 실제 기여 휘도 4.0000004:1. 고정 노출 1.656102 (수정 전 1.654725).
- src/terrain.js: 지면 정점색의 선형 휘도는 유지하고 색 차이만 25%로 축소. 숲 잎·캐릭터·배경 하늘에 화면 전체 탈색을 하지 않음.
- 태양 29°·142°, 배경 하늘·헤이즈·보행·GPX 좌표·카메라·그림자 방향은 유지.

## 전후 픽셀 측정

수정 전 PNG/JSON은 새 코드로 덮어쓰지 않고 보존했다. 수정 후 카메라 배열·위치·yaw/pitch와 FOV가 동일한지 자동 대조했다. 정지 아바타 포즈, 고화질이 안정된 뒤 캡처한다.

scripts/measure-shadows.py에 공개한 고정 ROI: 그늘 사면 좌/우, 그늘 바위 좌/우 4곳(43,608픽셀), 양지 사면·바위 2곳(3,400픽셀). HUD·캐릭터·하늘·표면 경계가 섞이지 않도록 수정 전 이미지에서 표본을 선정했다. 평균 픽셀 HSV S와 평균 RGB의 HSV는 구분해 계산한다.

- 그늘 평균 RGB: (32.816,49.735,70.554) → (45.668,46.618,39.234)
- 그늘 픽셀 채도 평균: 0.544809 → 0.163643. 평균 RGB의 HSV 채도 0.534881 → 0.158384.
- 양지 평균 RGB: (137.910,137.993,125.366) → (144.269,137.833,121.924)
- 양지 픽셀 채도 평균: 0.093973 → 0.154888.
- 그늘 4곳 모두 픽셀 S 평균 및 평균 RGB의 S ≤0.25 통과. 유채색(S>0.05) 중 H 200~250° 비율 0%.

## 이어 진행한 발소리 카드

src/footstep-audio.js에 AudioContext 구현이 이미 있고 main.js에서 hiking:step에 연결되어 있음을 확인했다. 사용자 입력 전에는 AudioContext를 생성하지 않는 설계다. 새 최종 빌드에서 capture-audio.mjs 재검증 통과: 첫 입력 생성·35개 디코딩·출력 파형·실제 12걸음=12회·약 0.833초·13개 변형·직전 2개 제외·재질 변경·토글 저장/복구·이탈 정지.

계단 화면·변형 번호·시간 로그·13개 미리 듣기를 포함한 발소리 보고도 같은 빌드로 갱신했다. 통나무는 GPX에 해당 구간이 없어 이벤트 하네스로 검사한다. 실제 스피커로 들었다고 주장하지 않는다.

## 가정

그늘 반사색은 실측한 관악산 사진의 값이 아니라 이번 지시를 위한 저채도 설정이다. 4:1 간접광에 지면 반구 반사광도 포함한다. 고정 대표 구도 표본을 검사한 것으로 모든 시점·소재의 현장 실사 승인을 뜻하지 않는다. 촬영 전후 위치·화각은 같고 회색카드 기준 고정 노출 차이는 매우 작다.
