# 기획: 체감자료 조사 결과 반영 (2026-11-03)

작성: 산기획 · 근거: `관악산-체감자료-구간별.md`, `실경자료-조사.md` (산리서치, 2026-11-03)

## 1. 판단 요약
- 정량 자료(계단 수·노면 비율·구간 시간)는 공개 웹에 없다. **기다리지 않고**, 후기의 정성 서술로 구간별 "추정 배정"을 먼저 넣는다. 모든 값은 `추정(후기 근거, 현장 확인 전)`으로 표기하고 한 곳(설정 표)에서 바꿀 수 있게 한다.
- 체감 차이가 크고 근거가 ✅인 것부터: ① 구간별 노면 ② 구간별 환경음 ③ 정상부 시설. 수종은 비율만 조정(임상도 확보 전).
- 로그인·인증키·현장 촬영이 필요한 자료(DEM 5m, VWorld 정사영상, 임상도 이용허락, 현장 계단 수)는 대표 확인 목록으로 넘긴다.

## 4. 정상부 시설 (자료 ✅)
기상레이더 돔(축구공형, 흰색), 연주대 석축 위 응진전(작은 기와집·연등), 너럭바위 위 표지석 "관악산 629m", 연주암 갈림 헬기장, 깔딱고개 능선 갈림 표지(왼쪽 암릉 비권장/헬기장 우회). 위치·치수는 추정 배치이며 화면에 "추정" 기록을 남긴다.

## 5. 완료 기준
- 노면: 구간별 배정이 설정 표 한 곳에 있고, 전체 시간 135~165분, 기존 테스트 전부 통과 + 구간별 배정 테스트 추가.
- 환경음: 구간 전환 시 끊김 없는 크로스페이드, 음원 라이선스(CC0 또는 출처표시 가능) 기록, 음소거·볼륨이 함께 적용.
- 시설: 경량화 규격(`풍경자산-경량화-규격.md`) 안의 삼각형 수, 정상 화면 캡처 2장.
- 성능: 위 작업 뒤에도 `성능-측정과-렌더링-예산.md` 목표를 후퇴시키지 않는다.
