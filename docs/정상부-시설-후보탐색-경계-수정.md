# 정상부 시설 후보 탐색·바위·경계 수정 — 산풍경

## 결과

구현 수정 완료, 실행 검증 미완료. 새 결과 화면은 없으며 완료 기준 통과로 판정하지 않는다.

1. 레이돔·응진전 위치를 고정 장거리 좌표에서 지형 후보 탐색으로 바꿨다. 정상에서 15~35m, 방위 278~322°를 1m·2° 간격으로 조사한다. 중심 지면이 정상보다 6m 이상 낮은 후보를 제외하고, 정상보다 2m 넘게 높은 후보도 제외한다. 두 시설 방위 차 24° 이상·중심 거리 15m 이상·표지석과 11m 초과 간격을 확보하는 쌍 중 정상 고도·25m 거리·좌우 방위에 가까운 조합을 선택한다.
2. 후보 쌍이 없으면 results.json의 시설 정보에 `placementVerified: false`, `placementStatus: 조건 충족 후보 없음·임시 배치`를 기록한다. 이때 기본 임시 좌표는 정상에서 약 26m·24m다. 실제 지형에서 후보가 선택되는지와 본체 가시성은 캡처 검증이 필요하다. 조건 실패를 정상 고도로 지형을 올리는 방식으로 숨기지 않는다.
3. 받침 내부·외곽 경계는 해당 기초 높이를 직접 반환한다. 다른 시설의 전이 영역이 겹쳐 높이가 더해지던 문제를 제거했다. 외부 연결은 가장 강한 단일 전이 효과를 사용한다. 기존 외곽 16방향의 엄격한 동등성 검사는 유지하고, 인접 시설 순서를 뒤집어도 동일 높이가 나오는 회귀 검사를 추가했다.
4. 바위 인스턴스 생성 전에 모든 LOD의 실제 메시 경계로 원점 기준 보수적 구 반경을 구한다. 배치의 회전·크기·비균일 확대를 고려해 시설 받침과 25cm 여유 안에서 겹치는 바위를 제외한다. 전부 제외된 청크는 렌더·식생 갱신 목록에 등록하지 않는다. 기존 갈림 표지판 모델은 변경하지 않았다.
5. 시설 도형·LOD·삼각형 예산 검사는 유지했다. 기존 거리 조건 `표지석 거리 + 30m 초과`를 15~35m·고도 차·간격 조건으로 대체했다.

## 확인

- 산기획 제공 사본의 results.json에서 레이돔 y=587.08m, 응진전 y=615.94m를 확인했다.
- `git diff --check` 통과.
- npm test·빌드·preview·새 캡처 미실행. 후보 선택·바위 관통 해소·시설 본체 가시성·갈림 화면 유지·실행 삼각형 수는 미검증이다.
- 새 `mktemp` 사본: `/private/tmp/gwanak-facilities-candidates.HQvthf`. .git·node_modules·dist·artifacts를 제외해 복사하고 의존성은 원본 node_modules로 연결했다. 삭제·커밋·push는 하지 않았다.

## 가정

- 시설 배치는 실측 전 추정이다. 좌우 방위 차와 지형 고도는 가시성의 후보 기준이며 실제 화면 확인을 대신하지 않는다.
- 바위 제거는 메시 전체를 포함하는 보수적 구 범위로 판단해 받침 주변 바위 일부도 제외될 수 있다.

## 대표 확인 필요

랩 리드가 로컬 확인을 명시적으로 허용했지만, 상위 개발 지시의 “스크립트 실행 같은 위험 작업은 하지 말고 … 그 명령을 남기세요”가 적용되어 실행하지 못했다. 제한 해제 후 아래 명령을 실행하고 산출물을 직접 검수해야 한다.

```sh
cd /private/tmp/gwanak-facilities-candidates.HQvthf
npm test
npm run build
npm run preview -- --port 5183 --strictPort
```

preview가 실행 중인 별도 터미널:

```sh
cd /private/tmp/gwanak-facilities-candidates.HQvthf
BASE_URL=http://127.0.0.1:5183 node scripts/capture-summit-facilities.mjs
```

5183이 사용 중이면 빈 포트로 바꾸고 BASE_URL도 함께 바꾼다. `artifacts/summit-facilities/results.json`의 시설 후보 선택 상태·높이·예산, `summit.png`의 시설 3종 본체와 바위 관통, `junction.png`의 표지판을 확인해야 한다. 이번 수정 결과 화면은 생성되지 않아 첨부하지 않았다.
