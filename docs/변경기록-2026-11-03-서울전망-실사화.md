# 서울 전망 실사화 — 산개발 · 2026-11-03

서울 담당 범위의 도시 렌더링·데이터를 보강했다. `assets/realistic/load-landscape.js`에서는 서울 지면·도로·물·랜드마크 연결부만 수정했다. main.js, 숲·하늘·빛·보행 파일은 수정하지 않았다. 시작부터 있던 타 담당 변경은 보존했다.

- OSM 높이·층수·용도를 원자료에서 복원해 건물 DB를 재생성. 미상 높이는 용도별 시각 추정으로 표시한다. 아파트·업무·저층 주택·산업 건물의 외벽·창문 간격·지붕색을 구분했다. 창문은 화면 픽셀 미분으로 원경에서 평균화한다.
- 높음 원경은 125m 공간별 대표 건물을 고르고 실제 건물 경계의 입체 상자를 통합한다. 전 도시 30만 삼각형, 근·중경 49개 메시+원경 1개 제출 상한. 낮음·균형은 기존 방향별 실루엣을 유지하되 정점색을 반영한다. OSM ID가 겹치는 건물 137개는 렌더링 추가 시 제거한다.
- 북쪽 서울 OSM 도로·토지이용·공원 21,785개 확보. 도로 12,256개(교량 태그 1,211개 구간), 지면 폴리곤 9,188개. 남쪽 확장 취득 실패는 audit에 남겼다. 교량 수는 다리 개수가 아닌 분할된 OSM way 구간 수다.
- 전체 초록 지면을 시가지 회갈색·공원과 산림 녹색·도로 짙은 회색으로 구분. 건물 인근 지면 보조 마스크는 추정이다. 한강은 HDR 환경을 반영하는 저거칠기 수면으로 변경했다. 실시간 평면 반사나 물결 시뮬레이션은 추가하지 않았다.
- 63빌딩 345.6°/8.56km, 남산타워 10.2°/11.98km, 롯데월드타워 58.5°/14.34km로 산리서치와 수치 검증. 판상 금빛 타워·전망대와 안테나·곡선으로 좁아지는 타워를 자체 근사했다. 북한산 기준 6.1°/24.11km. 남산·북한산은 기존 원경 DSM을 유지한다.
- 이름표 기본 숨김, L키로 전환. 화면 오른쪽 아래에 출처·ODbL·L키 안내를 표시한다.

재생성: `node scripts/fetch-seoul-surface.mjs` → `node scripts/prepare-seoul-scenery.mjs`. 원본 전체 prepare를 다시 실행한 경우에도 두 번째 명령으로 서울 마스크·연구 방위를 재적용한다. 없는 확장 원자료는 audit.surfaceMissing으로 기록한다.

검증: `npm test`, `npm run build`, `LABEL=after node scripts/capture-scenery-seoul.mjs`. 결과는 artifacts/scenery-seoul-*.json 및 로그. 서울 3시점 전후 캡처는 같은 경로 지점·방위·55° 세로 화각·1440×900이다. 정상 북쪽 기존 바위 가림과 북동쪽 검은 식생 조각은 담당 밖의 기존 현상으로 그대로 남겼다. 보조 inspection 캡처가 있다면 앱 소스 파일을 수정하지 않고 진단 브라우저에서만 카메라를 동쪽 35m·북쪽 35m·위 3m 이동한 시점이며 성능 합격의 기본 시점과 구분한다.

push·배포·원본 파일 삭제는 하지 않았다. 현장 경험자의 실제 경치 검수와 사진 대조는 여전히 필요하다.

한강 보완 전 중간 검증: 113개 테스트·빌드 통과. 북쪽 48.94fps, 북동쪽 49.06fps, 능선 서쪽 47.47fps. 셰이더·실행 오류 없음. 도시 삼각형 33,108–135,804개, 제출 1–10회. 이전 동일 시점 48.14–48.74fps와 비교하는 10초 측정이며 수 fps 차이를 장기 성능 향상으로 해석하지 않는다.

주변 산 DEM 추가 점검: 남산 기준 좌표의 원경 높이는 242.68m로 타워 밑동 243m와 일치한다. 산리서치의 북한산 대표 좌표는 DEM 340.03m로 백운대 정상 좌표가 아니다. 그 점에 836.5m 산을 임의로 만들지 않았다. 반경 3.5km의 160m 격자 최고점은 위도 37.659044 / 경도 126.978180, 787.56m, 정상 관측점 기준 3.00° / 23.77km다. 30m DSM을 160m로 샘플한 값이라 실제 정상 표고보다 낮을 수 있다. 원자료와 대표점의 차이를 `artifacts/scenery-seoul-mountain-check.json`에 남겼다.

한강 누락 추가 수정: 보조 검수에서 기존 물 DB의 한강 relation 152336·3769500이 tags-only여서 본류가 전혀 생성되지 않음을 확인했다. 공식 OSM API `/relation/{id}/full.json`으로 경계 way/node를 받아 geometry를 복원하고 섬을 hole로 보존했다. `streamWater()`는 경계를 만들지 못한 tags-only 항목을 중복 집합에 넣지 않도록 수정했다. `node scripts/fetch-seoul-water.mjs`로 재생성한다. 물 원본·가공 파일 및 출처를 기록했다. 이 수정 뒤 전체 테스트·빌드와 최종 캡처를 다시 실행했다.

동시 작업 주의: 캡처 진행 중 타 담당의 풀 크기·수목색 보강 파일과 테스트가 추가되었다. 산개발은 해당 파일을 수정하지 않았다. 전후 비교는 서울 도시 영역을 중심으로 해석하며, 근경 풀·숲 차이를 서울 변경의 효과로 보지 않는다.

한강 보완 후 최종 검증: 테스트 118개·빌드 통과. 1440×900 높음, 북쪽 49.64fps·북동쪽 49.34fps·서쪽 48.14fps로 모두 45fps 이상이다. 런타임·셰이더 오류 없음. 이름표 기본 숨김과 L키 켜기/끄기 확인. `artifacts/scenery-seoul-after.json`이 최종 기본 시점 기록이다.
