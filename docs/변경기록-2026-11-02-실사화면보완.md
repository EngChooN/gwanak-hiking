# 지형 노면·숲 밀도·정상 암반 보완

산풍경 / 2026-11-02 / /Users/pc-2311001/gwanak-hiking

이번 기록은 이전 ‘숲·바위·배치’ 인계의 배치 개수·가시 거리·재질 설명을 대체한다. push·배포 없음.

- 지형의 흙 가중치 0, 완경사 낙엽·풀과 어두운 초록 바닥, 급경사·상부 회색 암반으로 구분. 흙은 별도 등산로 리본에 유지.
- 경사·표고 가정으로 나무 134,888그루, 축소 묘목 사진판 관목 7,651개. 추가 숲은 LOD2 사진판으로 하부·중원경을 채운다. 1,400m 밖은 초록 지형색으로 연결한다. 128m 청크 유지.
- 바위 982개. Rock Face 01·02, Mountainside, Boulder 집중 배치 및 정상 평탄화 어깨의 낮은 암반 추가. Rock 09는 3.3cm 원본 크기에 맞춰 기존 배율을 65배 보정.
- 암반 재질은 기존 granite PBR을 사용하고 색을 회색으로 정리. 바위 범위의 9개 지면 표본 중 최저점까지 supportDrop을 적용해 넓은 스캔이 경사 위로 뜨는 현상을 줄임.
- 정상 경로와 DSM 형상은 유지. 추가 암반은 충돌체나 이동 경로를 바꾸지 않는 시각 보완이다.
- 추가 사진판에서 같은 URL의 중복 LOD는 생략. 인스턴스 지면 고도는 한 번만 재계산. 원본 GLB 27개 자체는 변경하지 않음.
- 안개색 #94ADBD, 8/12km 잔존 대비 68/55%, 도시 건물색 #78878b. 기존 더 짙은 안개를 고정한 테스트의 기대값을 새 요구에 맞게 수정. 태양·노출 교정은 유지.

검증 증거: artifacts/landscape-verification.json, assets/realistic/generated/nature/verification.json, artifacts/landscape-{entrance,ridge,summit-north,summit-east,third}.png. 최종 수치는 artifacts/관악산-실사화면-전후비교.html 참조.

3인칭은 W 입력 중 캡처한다. 전후 4시점은 같은 경로 위치·방위, 3인칭 보완 전 사진은 기존 hiker-third-flat-walk.png로 위치가 다르므로 참고 비교다.

기존 Poly Haven CC0 자산과 PBR·직접 구운 사진판만 재사용. 새로운 다운로드 없음. DSM에서 수관 높이를 추정하지 않았으며 현장 수종·암종·개체 위치·숲 밀도 일치는 미검증이다. 사진판은 카메라 방향에 따라 평면성이 드러날 수 있다.

재현 순서:

```sh
node assets/realistic/tools/enhance-landscape.mjs
node assets/realistic/tools/verify-nature.mjs
# 별도 터미널에서 npm run dev -- --port 5176

```
