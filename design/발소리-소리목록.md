계단 간격 (2026-11-02 갱신: 계단 걸음 1초 1.2걸음)
- 걸음 간격 = 1 ÷ 1.2 ≈ **0.83초**. 소리 길이(0.2~0.3초) 뒤 약 0.5초가 비므로 발소리끼리 겹치지 않고, 꼬리(울림)만 짧게 남깁니다. 평지(약 2걸음/초, 0.5초 간격)보다 느린 박자가 "한 단씩 오른다"는 느낌을 줍니다.
- 소리 쪽에서 속도를 맞추지 않고 걸음 이벤트마다 한 번 재생합니다(기존 규칙 유지). 걸음 속도가 바뀌면 간격도 자동으로 따라갑니다.
- **변형 5→8**: 112단을 오르면 약 93초 동안 같은 재질이 이어집니다. 5변형이면 평균 4초(5걸음)마다 같은 소리가 돌아와 반복이 귀에 띕니다. 8변형이면 약 7초 주기. 여기에 음높이 ±4%·음량 ±1.5dB 흔들기와 "직전 2개 변형 제외" 규칙(계단만 연속 금지 범위를 1→2로 확대)을 씁니다.
- 한 단씩 왼발·오른발 번갈아 좌우 팬 ±8%(계단은 발이 단마다 다르게 닿으므로 유지).
- 단 높이가 높은(20cm 이상) 단은 −0dB→+1dB, 낮은 단은 그대로. 계단 구간 끝 평지 첫 걸음은 기존대로 흙/돌길 소리.
- 진동: 계단 15ms, 간격 0.83초라 초당 2회 상한(0.5초) 안에 있어 건너뛰지 않음.

공통 규칙
- 발소리는 **실제 걸음마다 한 번**(시뮬레이션의 걸음 이벤트에 맞춤). 걸음 간격은 이동 모델이 결정하므로 소리 쪽에서 속도를 바꾸지 않습니다.
- 같은 변형을 연속 두 번 쓰지 않고, 음높이 ±4%·음량 ±1.5dB를 무작위로 흔듭니다.
- 왼발·오른발 좌우 팬 ±8%(헤드폰 느낌만 주는 정도).
- 재질 경계에서는 해당 걸음부터 바로 바꿉니다(크로스페이드 없음). 계단은 오를 때만 단 소리, 평지 진입 첫 걸음은 흙/돌길로.
- 서 있거나 일시정지 중에는 발소리 없음. 3인칭 둘러보기에서 캐릭터가 걸을 때도 같은 소리(거리감 있게 −3dB).
- 오르막 경사가 클수록 약간 무겁게(경사 10% 이상이면 음량 +1dB, 저역 +1.5dB).

## 1-1. 계단 소리 만들기와 확인 기준 (2026-11-02, 산기획 우회 지시 반영)

계단 오르기 녹음 대신 **한 걸음짜리 CC0 음원을 가공**해 만들었습니다. 가공 스크립트는 `design/tools/make_stairs.py`(재실행하면 같은 결과)이고, 원본은 모두 CC0라 변형·상업 이용에 제한이 없습니다.

| 계단 종류 | 변형(파일) | 원본 | 가공 |
|---|---|---|---|
| 돌계단 | stone-stair-01~06 (6) | Fantozzi Stone L/R 3종×2 | 피치 −3~−10%(무거운 디딤), 220Hz 이하 +4dB, 0.28초로 자르고 끝 45ms 페이드, 초반 음량 통일, 피크 −3dBFS 이하, 모노 |
| 통나무계단 | log-stair-01~03 (3) | 두꺼운 나무판 wood01~03 | 피치 −12%, 저역 +5dB, 0.3초 이내로 자름, 같은 음량·피크 처리 |
| 통나무계단 | log-stair-04~07 (4) | 나무 계단 클립 0180에서 한 걸음씩 잘라냄 | 피치 −5%, 저역 +5dB, 0.3초, 같은 처리 |

- 최소 4변형 기준: 돌 6, 통나무 7로 충족. 재질당 원본은 모두 다른 걸음이며 돌 6은 독립 원본 6개, 통나무는 독립 원본 7개(서로 다른 걸음)입니다.
- 계산으로 확인한 값: 길이 돌 0.28초, 통나무 0.24~0.30초(목표 0.2~0.3초 이내). 피크 −2.7~−7.6dBFS(클리핑 없음), 끝 샘플 진폭 0.001 이하(딱 끊기는 소리 없음). 변형끼리 파형 상관은 돌 최대 0.14(충분히 다름), 통나무 최대 0.80(wood01~03이 모두 저역 울림이라 서로 닮음).
- 한계: **귀로 확인한 게 아닙니다.** 통나무 01~03은 저역이 95% 이상이라 "퉁" 소리뿐이고 또렷한 딛는 소리가 약합니다. 04~07은 실내 슬리퍼 클립 기반이라 가볍습니다. 실제 계단 느낌은 귀 검수 후 피치·저역 값(스크립트 상단 숫자)을 조정합니다. 돌 계단은 원래 돌길 소리라 계단 특유의 울림이 없으므로 짧은 리버브(실외, 0.1초 이내)를 앱에서 넣을지 검수 때 결정합니다.

### 같은 소리가 연속으로 나지 않는지 확인 기준 (1.2걸음/초, 간격 약 0.83초)
1. **규칙**: 한 계단 종류의 변형 N개(돌 6, 통나무 7)에서, 직전 2걸음에 쓴 변형은 제외하고 고른다. 최소 반복 간격은 3걸음(약 2.5초)이며 N≥4에서 항상 성립한다.
2. **자동 검사(시뮬레이션)**: 1.2걸음/초로 112단(약 93초) × 1000회 돌려, 같은 변형이 직전 2걸음 안에 다시 나온 횟수가 **0**이고, 변형별 사용률이 (1/N)±5%p 안이어야 통과.
3. **귀 검사**: 112단 구간을 처음 입장부터 끝까지 한 번 걸어 보고, "같은 소리 두 번 연속" 또는 "박자가 기계처럼 규칙적" 느낌이 있으면 불합격. 음높이 ±4%·음량 ±1.5dB 흔들기를 켠 상태로 들을 것.
4. **짧은 구간**: 계단이 8단 미만인 구간은 변형 4개만으로 같은 규칙을 지켜도 되지만, 구간이 끝난 뒤 다음 구간 첫 걸음은 직전 변형을 제외하지 않는다(재질이 다르므로).
5. 왼발·오른발 팬을 번갈아 쓰므로, 같은 변형이 2걸음 건너 같은 쪽 귀에 다시 오는 경우도 그 변형만 −2dB로 낮춰 둔다(선택).

## 3. 배경음과 섞는 규칙

배경 층 (3개 루프, 각 40~90초, 끝을 겹쳐 이음)
1. 숲 공기(새·벌레, 바람 약함) — 숲 구간
2. 능선 바람(넓은 바람, 나뭇잎 적음) — 능선·전망 구간
3. 물소리(계곡) — 서울대 계곡 구간, 거리에 따라 페이드

믹스 기준 (마스터 −6dBFS 피크 상한)

| 층 | 기본 음량 | 비고 |
|---|---|---|
| 발소리 | 0dB (기준) | 사용자에게 가장 가까운 소리 |
| 숲·능선 배경 | −14dB | 발소리가 한 걸음마다 묻히지 않을 만큼 |
| 바람(고도 연동) | −20dB → 정상 −10dB | 고도가 오를수록 점점 커짐 |
| 물소리 | −18dB, 계곡에서 멀어지면 0까지 | 15초에 걸쳐 페이드 |
| UI 효과(체크포인트 알림) | −8dB | 짧은 차임 |

- 발소리마다 배경음을 낮췄다 올리는 더킹은 쓰지 않고, 배경음을 처음부터 낮게 유지합니다(펌핑 느낌 방지).
- 일시정지: 배경음은 −10dB로 줄여 유지, 발소리는 정지. 3인칭 둘러보기에서는 바람 +2dB로 풍경 분위기를 살림.
- 자동 걷기 중에도 소리 규칙은 같습니다.
- 소리 켜기·끄기는 메뉴(♪)에서, 상태는 저장. 처음 입장은 소리 켠 상태, 브라우저 자동재생 정책 때문에 첫 터치/키 입력 뒤에 재생 시작.
- 화면 잠금·앱 전환 시 소리 즉시 정지.

## 4. 모바일 진동(선택) 규칙

- 설정에서 **기본 꺼짐**, 켜면 동작. `navigator.vibrate`를 지원하는 기기에서만 메뉴에 표시(iOS 사파리 등 미지원 기기는 항목 숨김).
- 걸음마다: 흙·데크 평탄 10ms, 돌길 12ms, 계단 15ms, 암릉 18ms 짧은 한 번.
- 빠르게 연속되면 배터리·불쾌감을 줄이도록 **초당 최대 2회**(보통 걸음은 2걸음/초 안팎이므로 초과 시 건너뜀).
- 일시정지·자동 걷기 꺼짐·체크포인트 도착에는 각각 20ms/한 번, 정상 도착은 30-60-30ms 패턴 1회.
- 저전력 모드나 `prefers-reduced-motion`에서는 자동 꺼짐.
